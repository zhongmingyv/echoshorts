#0Wat is EchoShortsPlayer
  • ✦ Realtime vertaling tijdens het kijken van online videos, plus batchvertaling voor offline videos.
  • ✦ Ondersteunt 10.000+ websites met downloaden of opnemen met een klik via de browserextensie.
  • ✦ Legt geen gebruikersgegevens vast en verzamelt ze niet, voor betere privacy.
  • ✦ Ondersteunt 99+ talen en meerdere grote modellen.

#1 Features

🎤

Speech Recognition

Powered by OpenAI Whisper. Supports 99 languages with automatic language detection. Multiple model sizes from tiny (fast) to large-v3 (highest accuracy).

🌐

AI Translation

Multiple translation engines:

  • Opus-MT — fast, 9 languages
  • Qwen — best quality, CJK-optimized
📶

Media Detection

Supports 10,000+ websites and automatically detects m3u8/HLS streams and MP4 video links. Download or translate with one click via browser extension.

⚡

Real-time Subtitles

Stream translation mode: subtitles appear in real-time as you watch. No need to wait for the full video to download first. SRT subtitle files are saved locally for future use.

🔒

100% Offline & Private

All processing happens locally. No data is sent to external servers. No accounts, no tracking, no ads. Your content stays on your device.

💻

Hardware Requirements

NVIDIA GPU with 8 GB+ VRAM and CUDA drivers installed. Supports GPU-accelerated speech recognition and translation for optimal performance.

#2 How to Use

📥 Install EchoShortsPlayer Required

Desktop application — the core engine for all features

EchoShortsPlayer is the desktop application that runs the AI models locally. The browser extension and CLI depend on it. Install it first before using any of the methods below.

Downloaden uit de Windows Store

System requirements: Windows 10/11, NVIDIA GPU with 8 GB+ VRAM, CUDA drivers installed.

After installation, launch the application. It starts a local backend server at localhost:18632 that the extension and CLI communicate with.

🔌 Chrome Extension (Video Sniffing) Strongly recommended

Deep network-level media interception

The Chrome extension uses the webRequest API to intercept all network requests at the browser level, detecting m3u8/HLS streams, MP4 files, and other media formats. It also scans the page DOM for video elements and download links.

Download Extension (.zip)

Installatie (ontwikkelaarsmodus):

  1. Download de extensie-zip hierboven en pak deze uit naar een map.
  2. Open Chrome en ga naar chrome://extensions/.
  3. Schakel Ontwikkelaarsmodus in (schakelaar rechtsboven).
  4. Klik op Pakketloze extensie laden en selecteer de map echoshorts-extension.
  5. Het extensiepictogram verschijnt op de werkbalk met een badge met het aantal gedetecteerde media.

Gebruik:

  1. Ga naar een pagina met video-inhoud.
  2. Klik op het extensiepictogram om gedetecteerde m3u8/MP4-streams te zien.
  3. Klik op Downloaden om lokaal als MP4 op te slaan, of op Vertalen om ondertiteling te starten.
  4. Klik op Opnemen, speel de video in de browser af, klik daarna op Stoppen wanneer het afspelen klaar is — de extensie slaat automatisch de video's op die u in dit tabblad heeft bekeken.
  5. Beweeg de muis over items om het bijbehorende video-element op de pagina te markeren.

Is de extensie veilig?

  • Volledig open source — u kunt de code controleren. De communiceert alleen met de desktop-app op uw machine; wij ontvangen uw browsegeschiedenis niet.
  • De extensie en EchoShortsPlayer verzamelen geen persoonsgegevens en doen geen gedragsvolging of advertenties.
  • Afgezien van licentie-activering is typische netwerkactiviteit beperkt tot het ophalen van de videostreams die u kiest.
  • U kunt uitgaande verzoeken inspecteren om te bevestigen dat er geen onverwachte uploads zijn buiten activering en media-ophaal.

💻 Command-Line Interface Power Users

Automation, batch processing, and scripting

The CLI provides direct access to all download and translation features from the terminal. It's designed for power users who need to process multiple videos, automate workflows, or integrate with other tools.

Waarom de CLI gebruiken?

  • Batchverwerking: vertaal honderden video's met één commando
  • Scriptbaar: integratie in shell-scripts, cron-taken of CI/CD-pipelines
  • Volledige controle over modellen: kies Whisper-modelgrootte, vertaalengine, ruisonderdrukkingsmodus
  • Geen GUI-overhead: ideaal voor servers, headless machines of externe SSH-sessies
  • Ondersteunt zowel seriële (geheugenefficiënt) als parallelle (snel) verwerkingsmodus

Available commands:

# Translate a local video file to Chinese subtitles
resources\backend\backend.exe --cli translate video.mp4 --target zh

# Batch translate an entire folder
resources\backend\backend.exe --cli translate C:\Videos\

# Full options: source language, whisper model, translation engine, denoising, processing mode
resources\backend\backend.exe --cli translate video.mp4 --source auto --target ja --whisper distil-large-v3 --translation qwen3-8b --denoise vocal --mode parallel

# Download a remote m3u8 or MP4
resources\backend\backend.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# Download and translate in one step
resources\backend\backend.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# Translate an existing SRT file
resources\backend\backend.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

Parameterreferentie:

--source, -s      Source language or "auto" (default: auto)
--target, -t      Target language (default: zh)
--whisper, -w     tiny|base|small|medium|distil-large-v3|large-v3
--translation, -m opus-mt|nllb-distilled-600M|nllb-1.3B|nllb-3.3B|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal (default: off)
--mode            serial|parallel (default: serial)
--output, -o      Output file path
--url             Media URL (m3u8 / MP4)
--referer         Referer header

Bekijk de volledige lijst met ondersteunde taalcodes voor --source en --target: Taalcodereferentie

Voor technische ondersteuning kunt u contact opnemen met supports@echoshorts.win.

#3 Privacybeleid en disclaimer

Lokale gegevensverwerking

Alle kernfuncties van EchoShortsPlayer — waaronder spraakherkenning, vertaling en media-downloads — draaien volledig op uw lokale apparaat, aangedreven door een lokale backend-server (127.0.0.1:18632).

We verzamelen, bewaren, verzenden of analyseren geen gebruikersgegevens, waaronder maar niet beperkt tot: bekeken video-inhoud, herkende ondertiteltekst, vertaalresultaten, browsegeschiedenis of persoonlijke informatie.

Geen gegevensverzending via het netwerk

De applicatie verzendt tijdens normaal gebruik geen gebruikersgegevens naar externe servers. Alle audiobewerking en tekstvertaling vindt lokaal plaats. AI-modellen worden bij eerste gebruik gedownload van openbare bronnen (HuggingFace) en kunnen daarna volledig offline draaien.

De browserextensie communiceert alleen met de lokale backend op localhost:18632. Er worden geen gegevens verzonden naar externe servers van de ontwikkelaars.

Geen advertenties, tracking of aanbevelingen

Deze applicatie bevat geen advertenties, code voor gedragstracking, analytics of aanbevelingsmechanismen. We delen geen gebruikersgegevens met derden en maken geen profielen of pushen inhoud op basis van gedrag.

Safe harbor en verantwoordelijkheid van de gebruiker

EchoShortsPlayer is een algemeen technisch hulpmiddel uitsluitend bedoeld om video-inhoud te begrijpen. Onder het safe-harborbeginsel dragen ontwikkelaars en uitgevers geen juridische aansprakelijkheid voor inbreuk op auteursrechten of anderszins met betrekking tot inhoud waartoe de gebruiker toegang heeft, die hij vertaalt of verwerkt.

De gebruiker moet zorgen dat het gebruik voldoet aan lokale wetten en de servicevoorwaarden van platforms. Alle juridische aansprakelijkheid uit toegang tot auteursrechtelijk beschermde inhoud, overtreding van platformregels of illegale activiteiten rust uitsluitend bij de gebruiker.

De applicatie oordeelt niet over en garandeert niet de legaliteit van de benaderde inhoud en aanvaardt geen aansprakelijkheid voor directe of indirecte verliezen door gebruik.

Beoogd gebruik

De applicatie is ontworpen als hulpmiddel voor persoonlijk lokaal gebruik door slechthorenden, taalleerders of personen die video's in vreemde talen moeten begrijpen. Elk ander gebruik is volledig voor rekening van de gebruiker.

Technische beperkingen

De applicatie ondersteunt analyse van openbaar toegankelijke video zonder Digital Rights Management (DRM). Door beveiligingsprotocollen (zoals Widevine, PlayReady) zijn audiostreams van DRM-inhoud mogelijk niet te extraheren, waardoor geen ondertitels kunnen worden gegenereerd.

Voor MP4-bestanden zonder «fast-start»-codering (moov-atoom aan het einde van het bestand) is een volledige download vereist voordat vertaling start. Fast-start MP4 ondersteunt streamingvertaling tijdens downloaden.
