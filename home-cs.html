#1 Features

🎤

Speech Recognition

Powered by OpenAI Whisper. Supports 99 languages with automatic language detection. Multiple model sizes from tiny (fast) to large-v3 (highest accuracy).

🌐

AI Translation

Multiple translation engines:

  • Opus-MT — fast, 9 languages
  • Qwen — best quality, CJK-optimized
📶

Media Detection

Supports 10,000+ websites and automatically detects m3u8/HLS streams and MP4 video links. Download or translate with one click via browser extension.

⚡

Real-time Subtitles

Stream translation mode: subtitles appear in real-time as you watch. No need to wait for the full video to download first. SRT subtitle files are saved locally for future use.

🔒

100% Offline & Private

All processing happens locally. No data is sent to external servers. No accounts, no tracking, no ads. Your content stays on your device.

💻

Hardware Requirements

NVIDIA GPU with 8 GB+ VRAM and CUDA drivers installed. Supports GPU-accelerated speech recognition and translation for optimal performance.

#2 How to Use

📥 Install EchoShortsPlayer Required

Desktop application — the core engine for all features

EchoShortsPlayer is the desktop application that runs the AI models locally. The browser extension and CLI depend on it. Install it first before using any of the methods below.

Stáhnout z Windows Store

System requirements: Windows 10/11, NVIDIA GPU with 8 GB+ VRAM, CUDA drivers installed.

After installation, launch the application. It starts a local backend server at localhost:18632 that the extension and CLI communicate with.

🔌 Chrome Extension (Video Sniffing) Strongly recommended

Deep network-level media interception

The Chrome extension uses the webRequest API to intercept all network requests at the browser level, detecting m3u8/HLS streams, MP4 files, and other media formats. It also scans the page DOM for video elements and download links.

Download Extension (.zip)

Instalace (režim pro vývojáře):

  1. Stáhněte zip rozšíření výše a rozbalte jej do složky.
  2. Otevřete Chrome a přejděte na chrome://extensions/.
  3. Zapněte Režim pro vývojáře (přepínač vpravo nahoře).
  4. Klikněte na Načíst rozbalené a vyberte složku echoshorts-extension.
  5. Ikona rozšíření se zobrazí na panelu nástrojů s odznakem počtu zjištěných médií.

Použití:

  1. Otevřete libovolnou stránku s videem.
  2. Klikněte na ikonu rozšíření a zobrazíte zjištěné streamy m3u8/MP4.
  3. Klikněte na Stáhnout pro uložení jako místní MP4 nebo na Přeložit pro spuštění generování titulků.
  4. Klikněte na Nahrát, přehrajte video v prohlížeči, po skončení klikněte na Zastavit — rozšíření automaticky uloží videa zhlédnutá na této kartě.
  5. Najeďte myší na položky pro zvýraznění odpovídajícího prvku videa na stránce.

Je rozšíření bezpečné?

  • Je plně open source — kód si můžete kdykoli zkontrolovat. Komunikuje jen s desktopovou aplikací na vašem počítači; neobdržíme vaši historii prohlížeče.
  • Rozšíření ani EchoShortsPlayer nesbírají osobní údaje ani neprovádějí behaviorální sledování ani reklamy.
  • Kromě aktivace licence je typická síťová aktivita omezena na získání videostreamů, které si zvolíte.
  • Odchozí požadavky si můžete sami zkontrolovat a ověřit, že kromě aktivace a stažení médií nic neočekávaného neodchází.

💻 Command-Line Interface Power Users

Automation, batch processing, and scripting

The CLI provides direct access to all download and translation features from the terminal. It's designed for power users who need to process multiple videos, automate workflows, or integrate with other tools.

Proč používat CLI?

  • Dávkové zpracování: přeložte stovky videí jediným příkazem
  • Skriptovatelné: integrace do shell skriptů, cron úloh nebo CI/CD pipeline
  • Plná kontrola nad modely: zvolte velikost modelu Whisper, překladač, režim odšumění
  • Bez režie GUI: ideální pro servery, bezhlavé počítače nebo vzdálené SSH relace
  • Podporuje sériové (úsporné na paměť) i paralelní (rychlé) režimy zpracování

Available commands:

# Translate a local video file to Chinese subtitles
resources\backend\backend.exe --cli translate video.mp4 --target zh

# Batch translate an entire folder
resources\backend\backend.exe --cli translate C:\Videos\

# Full options: source language, whisper model, translation engine, denoising, processing mode
resources\backend\backend.exe --cli translate video.mp4 --source auto --target ja --whisper distil-large-v3 --translation qwen3-8b --denoise vocal --mode parallel

# Download a remote m3u8 or MP4
resources\backend\backend.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# Download and translate in one step
resources\backend\backend.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# Translate an existing SRT file
resources\backend\backend.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

Reference parametrů:

--source, -s      Source language or "auto" (default: auto)
--target, -t      Target language (default: zh)
--whisper, -w     tiny|base|small|medium|distil-large-v3|large-v3
--translation, -m opus-mt|nllb-distilled-600M|nllb-1.3B|nllb-3.3B|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal (default: off)
--mode            serial|parallel (default: serial)
--output, -o      Output file path
--url             Media URL (m3u8 / MP4)
--referer         Referer header

Úplný seznam podporovaných jazykových kódů pro --source a --target: Reference jazykových kódů

Technickou podporu získáte na supports@echoshorts.win.

#3 Zásady ochrany osobních údajů a vyloučení odpovědnosti

Místní zpracování dat

Všechny hlavní funkce EchoShortsPlayer — včetně rozpoznávání řeči, překladu a stahování médií — běží zcela na vašem místním zařízení prostřednictvím místního backendového serveru (127.0.0.1:18632).

Nesbíráme, neukládáme nepřenášíme ani neanalyzujeme žádná uživatelská data, včetně mimo jiného: sledovaného videoobsahu, rozpoznaného textu titulků, výsledků překladu, historie prohlížení ani žádných osobních údajů.

Žádný přenos dat po síti

Aplikace při běžném používání neodesílá uživatelská data na externí servery. Veškeré zpracování zvuku a překlad textu probíhá lokálně. Modely AI se při prvním použití stáhnou z veřejných zdrojů (HuggingFace) a poté mohou fungovat zcela offline.

Rozšíření prohlížeče komunikuje pouze s místním backendem na localhost:18632. Data se nepřenášejí na žádné vzdálené servery provozované vývojáři.

Žádné reklamy, sledování ani doporučení

Tato aplikace neobsahuje reklamní systémy, kód pro sledování chování uživatele, analytiku ani mechanismy doporučování dat. Nesdílíme uživatelská data s třetími stranami ani nevytváříme profily ani nezasíláme obsah na základě chování.

Bezpečný přístav a odpovědnost uživatele

EchoShortsPlayer je obecné technické nástroj určený výhradně k pochopení videoobsahu. Podle doktríny bezpečného přístavu vývojáři a vydavatelé nenesou právní odpovědnost za porušení autorských práv nebo jiné v souvislosti s obsahem, ke kterému uživatel přistupuje, který překládá nebo zpracovává.

Uživatel musí zajistit, aby používání bylo v souladu s místními zákony a podmínkami služeb platforem. Veškerá právní odpovědnost vyplývající z přístupu k obsahu chráněnému autorským právem, porušení pravidel platforem nebo nezákonné činnosti leží výhradně na uživateli.

Aplikace neposuzuje ani negarantuje zákonnost obsahu, ke kterému uživatel přistupuje, a nepřijímá odpovědnost za přímé nebo nepřímé ztráty vzniklé jejím používáním.

Zamýšlené použití

Aplikace je navržena jako pomůcka pro osobní místní použití osobami se sluchovým postižením, studenty jazyků nebo těmi, kteří potřebují rozumět cizojazyčným videím. Jakékoli jiné použití je výhradně odpovědností uživatele.

Technická omezení

Aplikace podporuje analýzu veřejně dostupného videoobsahu nechráněného správou digitálních práv (DRM). Kvůli ochranným protokolům (např. Widevine, PlayReady) nemusí být zvukové stopy z DRM obsahu extrahovatelné, což brání generování titulků.

U souborů MP4, které nejsou kódovány jako «fast-start» (atom moov na konci souboru), je před zahájením překladu vyžadováno úplné stažení. MP4 fast-start podporuje streamovaný překlad během stahování.

Vyloučení odpovědnosti

Aplikace je poskytována «tak, jak je» bez výslovných nebo předpokládaných záruk. Vývojář nezaručuje správné fungování ve všech prostředích ani nepřijímá odpovědnost za ztráty, ztrátu dat nebo problémy zařízení způsobené používáním. Použití znamená souhlas se všemi výše uvedenými podmínkami.

Titulky a překlady jsou generovány automaticky strojem a slouží pouze pro informaci. Nejsou poskytovány záruky ohledně přesnosti, úplnosti nebo vhodnosti strojově přeloženého obsahu ani odpovědnost za důsledky spoléhání na takové překlady.

Aktualizace zásad

Tyto zásady ochrany osobních údajů mohou být aktualizovány v nových verzích. Významné změny budou oznámeny prostřednictvím protokolu aktualizací aplikace. Pokračování v používání znamená souhlas s nejnovější verzí zásad ochrany osobních údajů.
