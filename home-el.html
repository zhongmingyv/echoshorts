#1 Features

🎤

Speech Recognition

Powered by OpenAI Whisper. Supports 99 languages with automatic language detection. Multiple model sizes from tiny (fast) to large-v3 (highest accuracy).

🌐

AI Translation

Multiple translation engines:

  • Opus-MT — fast, 9 languages
  • Qwen — best quality, CJK-optimized
📶

Media Detection

Supports 10,000+ websites and automatically detects m3u8/HLS streams and MP4 video links. Download or translate with one click via browser extension.

⚡

Real-time Subtitles

Stream translation mode: subtitles appear in real-time as you watch. No need to wait for the full video to download first. SRT subtitle files are saved locally for future use.

🔒

100% Offline & Private

All processing happens locally. No data is sent to external servers. No accounts, no tracking, no ads. Your content stays on your device.

💻

Hardware Requirements

NVIDIA GPU with 8 GB+ VRAM and CUDA drivers installed. Supports GPU-accelerated speech recognition and translation for optimal performance.

#2 How to Use

📥 Install EchoShortsPlayer Required

Desktop application — the core engine for all features

EchoShortsPlayer is the desktop application that runs the AI models locally. The browser extension and CLI depend on it. Install it first before using any of the methods below.

Λήψη από το Windows Store

System requirements: Windows 10/11, NVIDIA GPU with 8 GB+ VRAM, CUDA drivers installed.

After installation, launch the application. It starts a local backend server at localhost:18632 that the extension and CLI communicate with.

🔌 Chrome Extension (Video Sniffing) Strongly recommended

Deep network-level media interception

The Chrome extension uses the webRequest API to intercept all network requests at the browser level, detecting m3u8/HLS streams, MP4 files, and other media formats. It also scans the page DOM for video elements and download links.

Download Extension (.zip)

Εγκατάσταση (λειτουργία προγραμματιστή):

  1. Κάντε λήψη του zip της επέκτασης παραπάνω και αποσυμπιέστε το σε έναν φάκελο.
  2. Ανοίξτε το Chrome και μεταβείτε στο chrome://extensions/.
  3. Ενεργοποιήστε τη Λειτουργία προγραμματιστή (εναλλαγή πάνω δεξιά).
  4. Κάντε κλικ στο Φόρτωση επέκτασης χωρίς συσκευασία και επιλέξτε τον φάκελο echoshorts-extension.
  5. Το εικονίδιο της επέκτασης εμφανίζεται στη γραμμή εργαλείων με σήμα που δείχνει τον αριθμό των εντοπισμένων μέσων.

Χρήση:

  1. Περιηγηθείτε σε οποιαδήποτε σελίδα με περιεχόμενο βίντεο.
  2. Κάντε κλικ στο εικονίδιο της επέκτασης για να δείτε τις ροές m3u8/MP4 που εντοπίστηκαν.
  3. Κάντε κλικ στο Λήψη για αποθήκευση τοπικά ως MP4 ή στο Μετάφραση για έναρξη δημιουργίας υποτίτλων.
  4. Κάντε κλικ στο Εγγραφή, αναπαράγετε το βίντεο στο πρόγραμμα περιήγησης, μετά το τέλος κλικ στο Διακοπή — η επέκταση αποθηκεύει αυτόματα τα βίντεο που παρακολουθήσατε σε αυτήν την καρτέλα.
  5. Τοποθετήστε τον δείκτη πάνω από στοιχεία για να επισημάνετε το αντίστοιχο στοιχείο βίντεο στη σελίδα.

Είναι ασφαλής η επέκταση;

  • Είναι πλήρως ανοιχτού κώδικα — μπορείτε να ελέγξετε τον κώδικα. Επικοινωνεί μόνο με την εφαρμογή υπολογιστή στον υπολογιστή σας· δεν λαμβάνουμε το ιστορικό περιήγησής σας.
  • Η επέκταση και το EchoShortsPlayer δεν συλλέγουν προσωπικά δεδομένα ούτε εκτελούν παρακολούθηση συμπεριφοράς ή διαφημίσεις.
  • Πέρα από την ενεργοποίηση άδειας, η τυπική δραστηριότητα δικτύου περιορίζεται στην επίλυση και λήψη των ροών βίντεο που επιλέγετε.
  • Μπορείτε να ελέγξετε τις εξερχόμενες αιτήσεις για να επιβεβαιώσετε ότι δεν υπάρχουν απροσδόκητες μεταφορτώσεις πέρα από την ενεργοποίηση και τη λήψη μέσων.

💻 Command-Line Interface Power Users

Automation, batch processing, and scripting

The CLI provides direct access to all download and translation features from the terminal. It's designed for power users who need to process multiple videos, automate workflows, or integrate with other tools.

Γιατί να χρησιμοποιήσετε το CLI;

  • Επεξεργασία κατά παρτίδες: μεταφράστε εκατοντάδες βίντεο με μία εντολή
  • Με δυνατότητα δέσμης ενεργειών: ενσωμάτωση σε shell scripts, cron jobs ή CI/CD pipelines
  • Πλήρης έλεγχος μοντέλων: επιλέξτε μέγεθος μοντέλου Whisper, μηχανή μετάφρασης, λειτουργία αποθορυβοποίησης
  • Χωρίς επιβάρυνση GUI: ιδανικό για διακομιστές, μηχανήματα χωρίς κεφαλή ή απομακρυσμένες συνεδρίες SSH
  • Υποστηρίζει τόσο τη σειριακή (αποδοτική στη μνήμη) όσο και την παράλληλη (γρήγορη) λειτουργία επεξεργασίας

Available commands:

# Translate a local video file to Chinese subtitles
resources\backend\backend.exe --cli translate video.mp4 --target zh

# Batch translate an entire folder
resources\backend\backend.exe --cli translate C:\Videos\

# Full options: source language, whisper model, translation engine, denoising, processing mode
resources\backend\backend.exe --cli translate video.mp4 --source auto --target ja --whisper distil-large-v3 --translation qwen3-8b --denoise vocal --mode parallel

# Download a remote m3u8 or MP4
resources\backend\backend.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# Download and translate in one step
resources\backend\backend.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# Translate an existing SRT file
resources\backend\backend.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

Αναφορά παραμέτρων:

--source, -s      Source language or "auto" (default: auto)
--target, -t      Target language (default: zh)
--whisper, -w     tiny|base|small|medium|distil-large-v3|large-v3
--translation, -m opus-mt|nllb-distilled-600M|nllb-1.3B|nllb-3.3B|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal (default: off)
--mode            serial|parallel (default: serial)
--output, -o      Output file path
--url             Media URL (m3u8 / MP4)
--referer         Referer header

Δείτε την πλήρη λίστα υποστηριζόμενων κωδικών γλώσσας για --source και --target: Αναφορά κωδικών γλώσσας

Για τεχνική υποστήριξη, επικοινωνήστε με supports@echoshorts.win.

#3 Πολιτική απορρήτου και αποποίηση ευθύνης

Τοπική επεξεργασία δεδομένων

Όλες οι βασικές λειτουργίες του EchoShortsPlayer — συμπεριλαμβανομένης της αναγνώρισης ομιλίας, μετάφρασης και λήψης πολυμέσων — εκτελούνται πλήρως στη συσκευή σας μέσω τοπικού διακομιστή backend (127.0.0.1:18632).

Δεν συλλέγουμε, αποθηκεύουμε, μεταδίδουμε ή αναλύουμε δεδομένα χρήστη, συμπεριλαμβανομένων ενδεικτικά: περιεχομένου βίντεο που παρακολουθείτε, αναγνωρισμένου κειμένου υποτίτλων, αποτελεσμάτων μετάφρασης, ιστορικού περιήγησης ή προσωπικών πληροφοριών.

Χωρίς μετάδοση δεδομένων στο δίκτυο

Η εφαρμογή δεν αποστέλλει δεδομένα χρήστη σε εξωτερικούς διακομιστές κατά την κανονική χρήση. Όλη η επεξεργασία ήχου και η μετάφραση κειμένου ολοκληρώνονται τοπικά. Τα μοντέλα AI λαμβάνονται από δημόσιες πηγές (HuggingFace) στην πρώτη χρήση και μπορούν στη συνέχεια να λειτουργούν πλήρως εκτός σύνδεσης.

Η επέκταση περιηγητή επικοινωνεί μόνο με το τοπικό backend στο localhost:18632. Δεν μεταδίδονται δεδομένα σε απομακρυσμένους διακομιστές που λειτουργούν οι προγραμματιστές.

Χωρίς διαφημίσεις, παρακολούθηση ή συστάσεις

Αυτή η εφαρμογή δεν περιέχει συστήματα διαφήμισης, κώδικα παρακολούθησης συμπεριφοράς χρήστη, αναλυτικά στοιχεία ή μηχανισμούς σύστασης δεδομένων. Δεν μοιραζόμαστε δεδομένα χρήστη με τρίτους ούτε δημιουργούμε προφίλ ούτε στέλνουμε περιεχόμενο βάσει συμπεριφοράς.

Ασφαλές λιμάνι και ευθύνη χρήστη

Το EchoShortsPlayer είναι γενικό τεχνικό εργαλείο σχεδιασμένο αποκλειστικά για βοήθεια στην κατανόηση περιεχομένου βίντεο. Σύμφωνα με τη δοκτρίνα ασφαλούς λιμανιού, οι προγραμματιστές και οι εκδότες δεν φέρουν νομική ευθύνη για παραβίαση πνευματικών δικαιωμάτων ή άλλα σχετικά με περιεχόμενο στο οποίο ο χρήστης έχει πρόσβαση, μεταφράζει ή επεξεργάζεται.

Ο χρήστης πρέπει να διασφαλίζει ότι η χρήση συμμορφώνεται με τους τοπικούς νόμους και τους όρους υπηρεσίας των πλατφορμών. Όλη η νομική ευθύνη από πρόσβαση σε περιεχόμενο προστατευμένο από πνευματικά δικαιώματα, παράβαση κανόνων πλατφόρμας ή παράνομη δραστηριότητα βαρύνει αποκλειστικά τον χρήστη.

Η εφαρμογή δεν κρίνει ούτε εγγυάται τη νομιμότητα του περιεχομένου στο οποίο έχει πρόσβαση ο χρήστης και δεν αποδέχεται ευθύνη για άμεσες ή έμμεσες απώλειες από τη χρήση της.

Προβλεπόμενη χρήση

Η εφαρμογή σχεδιάστηκε ως βοηθητικό εργαλείο για προσωπική τοπική χρήση από άτομα με προβλήματα ακοής, εκμαθητές γλωσσών ή όσους χρειάζονται να κατανοήσουν βίντεο σε ξένες γλώσσες. Οποιαδήποτε άλλη χρήση είναι αποκλειστική ευθύνη του χρήστη.

Τεχνικοί περιορισμοί

Η εφαρμογή υποστηρίζει ανάλυση δημόσια προσβάσιμου περιεχομένου βίντεο που δεν προστατεύεται από DRM. Λόγω πρωτοκόλλων προστασίας (π.χ. Widevine, PlayReady), οι ροές ήχου περιεχομένου DRM ενδέχεται να μην είναι εξαγώγιμες, εμποδίζοντας τη δημιουργία υποτίτλων.

Για αρχεία MP4 που δεν είναι κωδικοποιημένα «fast-start» (άτομο moov στο τέλος του αρχείου), απαιτείται πλήρης λήψη πριν ξεκινήσει η μετάφραση. Τα MP4 fast-start υποστηρίζουν ροή μετάφρασης κατά τη λήψη.

Αποποίηση ευθύνης

Η εφαρμογή παρέχεται «ως έχει» χωρίς ρητές ή σιωπηρές εγγυήσεις. Ο προγραμματιστής δεν εγγυάται σωστή λειτουργία σε όλα τα περιβάλλοντα και δεν αποδέχεται ευθύνη για απώλειες, απώλεια δεδομένων ή προβλήματα συσκευής που προκαλούνται από τη χρήση. Η χρήση συνιστά αποδοχή όλων των παραπάνω όρων.

Οι υπότιτλοι και οι μεταφράσεις δημιουργούνται αυτόματα από μηχανή και είναι μόνο για αναφορά. Δεν παρέχονται εγγυήσεις για την ακρίβεια, πληρότητα ή καταλληλότητα αυτόματα μεταφρασμένου περιεχομένου και δεν αποδέχεται ευθύνη για συνέπειες εξάρτησης από τέτοιες μεταφράσεις.

Ενημερώσεις πολιτικής

Αυτή η πολιτική απορρήτου ενδέχεται να ενημερώνεται σε νέες εκδόσεις. Σημαντικές αλλαγές θα κοινοποιούνται μέσω του αρχείου καταγραφής ενημερώσεων της εφαρμογής. Η συνεχής χρήση συνιστά αποδοχή της πιο πρόσφατης έκδοσης της πολιτικής απορρήτου.
