#0EchoShortsPlayerとは
  • ✦ オンライン動画を視聴しながらリアルタイム翻訳。オフライン動画の一括翻訳にも対応。
  • ✦ 10,000以上のサイトに対応し、ブラウザ拡張機能からワンクリックでダウンロードまたは録画できます。
  • ✦ ユーザーデータを記録・収集せず、プライバシーを保護します。
  • ✦ 99以上の言語と複数の大規模モデルに対応。

#1 機能

🎤

音声認識

OpenAI Whisperを搭載。99言語に対応し、自動言語検出機能付き。tiny（高速）からlarge-v3（最高精度）まで複数のモデルサイズを選択可能。

🌐

AI翻訳

複数の翻訳エンジン：

  • Opus-MT — 高速、9言語対応
  • Qwen — 最高品質、CJK最適化
📶

メディア検出

10,000+サイトをサポートし、あらゆるWebページ上のm3u8/HLSストリームおよびMP4動画リンクを自動検出。ブラウザ拡張機能でワンクリックダウンロードまたは翻訳。

⚡

リアルタイム字幕

ストリーム翻訳モード：視聴中にリアルタイムで字幕が表示されます。動画全体のダウンロードを待つ必要はありません。SRT字幕ファイルはローカルに保存され、今後の使用に備えます。

🔒

100%オフライン＆プライベート

すべての処理はローカルで実行されます。外部サーバーにデータは送信されません。アカウント不要、トラッキングなし、広告なし。コンテンツはデバイス上に保持されます。

💻

ハードウェア要件

8 GB以上のVRAMを搭載したNVIDIA GPUとCUDAドライバーのインストールが必要です。GPU高速化による音声認識と翻訳をサポートし、最適なパフォーマンスを実現します。

#2 使い方

📥 EchoShortsPlayerのインストール 必須

デスクトップアプリケーション — すべての機能の中核エンジン

EchoShortsPlayerは、AIモデルをローカルで実行するデスクトップアプリケーションです。ブラウザ拡張機能とCLIはこれに依存しています。以下の方法を使用する前に、まずインストールしてください。

Windows Store からダウンロード

システム要件： Windows 10/11、8 GB以上のVRAMを搭載したNVIDIA GPU、CUDAドライバーのインストール。

インストール後、アプリケーションを起動してください。拡張機能とCLIが通信するlocalhost:18632のローカルバックエンドサーバーが起動します。

🔌 Chrome拡張機能（動画検知） 強く推奨

ネットワークレベルの高度なメディア傍受

Chrome拡張機能はwebRequest APIを使用してブラウザレベルですべてのネットワークリクエストを傍受し、m3u8/HLSストリーム、MP4ファイル、その他のメディア形式を検出します。また、ページDOMをスキャンしてビデオ要素やダウンロードリンクを検出します。

拡張機能をダウンロード（.zip）

インストール（開発者モード）：

  1. 上記の拡張機能zipをダウンロードし、フォルダに解凍します。
  2. Chromeを開き、chrome://extensions/に移動します。
  3. デベロッパーモード（右上のトグル）を有効にします。
  4. パッケージ化されていない拡張機能を読み込むをクリックし、echoshorts-extensionフォルダを選択します。
  5. ツールバーに拡張機能アイコンが表示され、検出されたメディア数がバッジで表示されます。

使い方：

  1. 動画コンテンツのあるページを閲覧します。
  2. 拡張機能アイコンをクリックして、検出されたm3u8/MP4ストリームを確認します。
  3. ダウンロードをクリックしてローカルMP4に保存、または翻訳をクリックして字幕生成を開始します。
  4. 録画をクリックし、ブラウザで動画を再生します。再生が終わったら停止をクリックすると、このタブで視聴した動画が自動的に保存されます。
  5. アイテムにカーソルを合わせると、ページ上の対応するビデオ要素がハイライトされます。

拡張機能は安全ですか？

  • ソースコードは完全に公開されており、いつでも検証できます。通信はお使いのマシン上のデスクトップアプリに限定され、閲覧内容が開発者のサーバーに送信されることはありません。
  • 拡張機能とEchoShortsPlayerは個人情報を収集せず、行動追跡や広告も行いません。
  • ソフトウェアのライセンス認証を除き、一般的な通信はお客様がアクセスする動画ストリームの解決と取得に限られます。
  • ネットワークリクエストを自分で確認し、認証とメディア取得以外の予期しないアップロードがないことを確かめられます。

💻 コマンドラインインターフェース 上級ユーザー向け

自動化、バッチ処理、スクリプティング

CLIはターミナルからすべてのダウンロードおよび翻訳機能に直接アクセスできます。複数の動画を処理したり、ワークフローを自動化したり、他のツールと統合する必要があるパワーユーザー向けに設計されています。

CLIを使う理由

  • バッチ処理：1つのコマンドで数百の動画を翻訳
  • スクリプト化可能：シェルスクリプト、cronジョブ、CI/CDパイプラインに統合
  • モデルの完全制御：Whisperモデルサイズ、翻訳エンジン、ノイズ除去モードを選択
  • GUIオーバーヘッドなし：サーバー、ヘッドレスマシン、リモートSSHセッションに最適
  • シリアル（メモリ効率）とパラレル（高速）の両方の処理モードに対応

利用可能なコマンド：

# ローカル動画ファイルを中国語字幕に翻訳する
resources\backend\backend.exe --cli translate video.mp4 --target zh

# フォルダ全体を一括翻訳する
resources\backend\backend.exe --cli translate C:\Videos\

# 全オプション：ソース言語、Whisperモデル、翻訳エンジン、ノイズ除去、処理モード
resources\backend\backend.exe --cli translate video.mp4 --source auto --target ja --whisper distil-large-v3 --translation qwen3-8b --denoise vocal --mode parallel

# リモートのm3u8またはMP4をダウンロードする
resources\backend\backend.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# ダウンロードと翻訳を一度に実行する
resources\backend\backend.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# 既存のSRTファイルを翻訳する
resources\backend\backend.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

パラメータリファレンス：

--source, -s      ソース言語または "auto"（デフォルト: auto）
--target, -t      ターゲット言語（デフォルト: zh）
--whisper, -w     tiny|base|small|medium|distil-large-v3|large-v3
--translation, -m opus-mt|nllb-distilled-600M|nllb-1.3B|nllb-3.3B|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal（デフォルト: off）
--mode            serial|parallel（デフォルト: serial）
--output, -o      出力ファイルパス
--url             メディアURL（m3u8 / MP4）
--referer         Refererヘッダー

      
--source と --target でサポートされる言語コードの完全なリスト: 言語コード一覧

テクニカルサポートが必要な場合は、supports@echoshorts.win までご連絡ください。

#3 プライバシーポリシーと免責事項

ローカルでのデータ処理

EchoShortsPlayer の主要機能（音声認識、翻訳、メディアのダウンロードを含む）はすべて、ローカルバックエンド（127.0.0.1:18632）によって、お使いのデバイス上だけで動作します。

視聴した動画、認識された字幕、翻訳結果、閲覧履歴、個人情報など、ユーザーデータを収集・保存・送信・分析することはありません。

ネットワークへのデータ送信なし

通常利用時、ユーザーデータを外部サーバーに送信することはありません。音声処理とテキスト翻訳はすべてローカルで完了します。AI モデルは初回利用時に公開ソース（HuggingFace）からダウンロードされ、その後は完全オフラインで利用できます。

ブラウザ拡張機能は localhost:18632 のローカルバックエンドとのみ通信します。開発者が運用するリモートサーバーにはデータを送信しません。

広告・トラッキング・レコメンドなし

本アプリに広告、行動トラッキング、アナリティクス、推薦アルゴリズムは含まれません。第三者とユーザーデータを共有せず、行動プロファイルの作成やそれに基づくコンテンツの配信も行いません。

セーフハーバーとユーザーの責任

EchoShortsPlayer は動画内容の理解を支援する汎用技術ツールです。セーフハーバーに基づき、ユーザーがアクセス・翻訳・処理したコンテンツについて、開発者および配布者は著作権侵害その他の法的責任を負いません。

利用は各国の法令および利用するプラットフォームの利用規約に適合させる必要があります。著作権で保護されたコンテンツへのアクセス、規約違反、違法行為に起因する法的責任はすべてユーザーに帰属します。

本アプリはユーザーがアクセスするコンテンツの合法性を判断・保証せず、その利用に起因する直接的・間接的損害について責任を負いません。

想定される利用

本アプリは、聴覚に障害のある方、語学学習者、外国語の動画を理解する必要がある個人の、個人的かつローカルな利用を目的とした補助ツールとして設計されています。それ以外の利用については、すべてユーザーの責任となります。

技術的制限

デジタル著作権管理（DRM）で保護されていない、公開的にアクセス可能な動画の分析をサポートします。Widevine や PlayReady などの保護により、DRM 付きコンテンツの音声ストリームは取得できず、字幕生成ができない場合があります。

「fast-start」でない MP4（moov がファイル末尾にある場合）は、翻訳開始前にファイル全体のダウンロードが必要です。fast-start の MP4 はダウンロードしながらストリーミング翻訳できます。

免責事項

本アプリは現状有姿で提供され、明示黙示を問わずいかなる保証もありません。すべての環境で正常に動作することを保証せず、利用に起因する損失、データ消失、端末の不具合について責任を負いません。利用により上記すべてに同意したものとみなされます。
