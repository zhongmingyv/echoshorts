#2 วิธีใช้งาน

📥 Install EchoShortsPlayer Required

Desktop application — the core engine for all features

EchoShortsPlayer is the desktop application that runs the AI models locally. The browser extension and CLI depend on it. Install it first before using any of the methods below.

Download EchoShortsPlayer

System requirements: Windows 10/11, NVIDIA GPU with 8 GB+ VRAM, CUDA drivers installed.

After installation, launch the application. It starts a local backend server at localhost:18632 that the extension and CLI communicate with.

🔌 ส่วนขยาย Chrome แนะนำ

การดักจับสื่อระดับลึกในระดับเครือข่าย

ส่วนขยาย Chrome ใช้ API webRequest เพื่อดักจับคำขอเครือข่ายทั้งหมดในระดับเบราว์เซอร์ ตรวจจับสตรีม m3u8/HLS, ไฟล์ MP4 และรูปแบบสื่ออื่นๆ นอกจากนี้ยังสแกน DOM ของหน้าเพื่อหาองค์ประกอบวิดีโอและลิงก์ดาวน์โหลด

ดาวน์โหลดส่วนขยาย (.zip)

การติดตั้ง (โหมดนักพัฒนา):

  1. ดาวน์โหลดไฟล์ zip ส่วนขยายด้านบนและแตกไฟล์ไปยังโฟลเดอร์
  2. เปิด Chrome และไปที่ chrome://extensions/
  3. เปิดใช้งาน โหมดนักพัฒนา (สวิตช์มุมบนขวา)
  4. คลิก โหลดที่แกะแพ็กแล้ว และเลือกโฟลเดอร์ m3u8-extension
  5. ไอคอนส่วนขยายปรากฏบนแถบเครื่องมือพร้อมตราแสดงจำนวนสื่อที่ตรวจพบ

การใช้งาน:

  1. เข้าชมหน้าเว็บใดก็ได้ที่มีเนื้อหาวิดีโอ
  2. คลิกไอคอนส่วนขยายเพื่อดูสตรีม m3u8/MP4 ที่ตรวจพบ
  3. คลิก ดาวน์โหลด เพื่อบันทึกเป็น MP4 ในเครื่อง หรือ แปล เพื่อเริ่มสร้างคำบรรยาย
  4. เลื่อนเมาส์ไปเหนือรายการเพื่อไฮไลต์องค์ประกอบวิดีโอที่เกี่ยวข้องบนหน้า

ทำไมควรใช้ส่วนขยาย?

  • ดักจับคำขอเครือข่ายในระดับเบราว์เซอร์ — จับสตรีมที่การสแกน DOM พลาดไป
  • เลือกคุณภาพอัตโนมัติ: จัดกลุ่มตัวแปรตาม ID วิดีโอและเลือกคุณภาพดีที่สุด
  • แทรกเฮดเดอร์ Referer สำหรับเล่นสตรีมที่ต้องการการยืนยันตัวตน
  • ตัวนับตราแสดงจำนวนสื่อที่ตรวจพบต่อแท็บอย่างรวดเร็ว

💻 อินเทอร์เฟซบรรทัดคำสั่ง ผู้ใช้ขั้นสูง

ระบบอัตโนมัติ, การประมวลผลแบบแบตช์ และการเขียนสคริปต์

CLI ให้การเข้าถึงโดยตรงไปยังฟีเจอร์ดาวน์โหลดและแปลทั้งหมดจากเทอร์มินัล ออกแบบมาสำหรับผู้ใช้ขั้นสูงที่ต้องการประมวลผลวิดีโอหลายรายการ ทำให้เวิร์กโฟลว์เป็นอัตโนมัติ หรือรวมเข้ากับเครื่องมืออื่น

ทำไมควรใช้ CLI?

  • การประมวลผลแบบแบตช์: แปลวิดีโอหลายร้อยรายการด้วยคำสั่งเดียว
  • เขียนสคริปต์ได้: รวมเข้ากับ shell scripts, cron jobs หรือ CI/CD pipelines
  • ควบคุมโมเดลได้เต็มที่: เลือกขนาดโมเดล Whisper, เอนจินแปล, โหมดลดเสียงรบกวน
  • ไม่มี GUI โอเวอร์เฮด: เหมาะสำหรับเซิร์ฟเวอร์ เครื่องไม่มีหน้าจอ หรือเซสชัน SSH ระยะไกล
  • รองรับทั้งโหมดประมวลผลแบบอนุกรม (ประหยัดหน่วยความจำ) และแบบขนาน (เร็ว)

คำสั่งที่ใช้ได้:

# แปลไฟล์วิดีโอในเครื่องเป็นคำบรรยายภาษาจีน
EchoShortsPlayer.exe --cli translate video.mp4 --target zh

# แปลทั้งโฟลเดอร์แบบแบตช์
EchoShortsPlayer.exe --cli translate C:\Videos\

# ตัวเลือกทั้งหมด: ภาษาต้นทาง, โมเดล Whisper, เอนจินแปล, ลดเสียงรบกวน, โหมดประมวลผล
EchoShortsPlayer.exe --cli translate video.mp4 --source auto --target ja --whisper distil-large-v3 --translation qwen3-8b --denoise vocal --mode parallel

# ดาวน์โหลด m3u8 หรือ MP4 จากระยะไกล
EchoShortsPlayer.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# ดาวน์โหลดและแปลในขั้นตอนเดียว
EchoShortsPlayer.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# แปลไฟล์ SRT ที่มีอยู่
EchoShortsPlayer.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

อ้างอิงพารามิเตอร์:

--source, -s      ภาษาต้นทางหรือ "auto" (ค่าเริ่มต้น: auto)
--target, -t      ภาษาปลายทาง (ค่าเริ่มต้น: zh)
--whisper, -w     tiny|base|small|medium|distil-large-v3|large-v3
--translation, -m opus-mt|nllb-distilled-600M|nllb-1.3B|nllb-3.3B|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal (ค่าเริ่มต้น: off)
--mode            serial|parallel (ค่าเริ่มต้น: serial)
--output, -o      เส้นทางไฟล์เอาต์พุต
--url             URL สื่อ (m3u8 / MP4)
--referer         ส่วนหัว Referer

      
ดูรายการรหัสภาษาที่รองรับทั้งหมดสำหรับ --source และ --target: อ้างอิงรหัสภาษา

#3 นโยบายความเป็นส่วนตัวและข้อจำกัดความรับผิดชอบ

การประมวลผลข้อมูลในเครื่อง

ฟีเจอร์หลักทั้งหมดของ EchoShortsPlayer — รวมถึงการรู้จำเสียง การแปล และการดาวน์โหลดสื่อ — ทำงานบนอุปกรณ์ของคุณทั้งหมด ขับเคลื่อนโดยเซิร์ฟเวอร์แบ็คเอนด์ในเครื่อง (127.0.0.1:18632)

เราไม่เก็บรวบรวม จัดเก็บ ส่ง หรือวิเคราะห์ข้อมูลผู้ใช้ใด ๆ

ไม่มีการส่งข้อมูลผ่านเครือข่าย

แอปพลิเคชันนี้ไม่ส่งข้อมูลผู้ใช้ไปยังเซิร์ฟเวอร์ภายนอกระหว่างการใช้งานปกติ

ส่วนขยายเบราว์เซอร์สื่อสารกับแบ็คเอนด์ในเครื่องที่ localhost:18632 เท่านั้น

ไม่มีโฆษณา ไม่มีการติดตาม ไม่มีคำแนะนำ

แอปพลิเคชันนี้ไม่มีระบบโฆษณา โค้ดติดตามพฤติกรรมผู้ใช้ เครื่องมือวิเคราะห์ หรือกลไกแนะนำข้อมูล

Safe Harbor และความรับผิดชอบของผู้ใช้

EchoShortsPlayer เป็นเครื่องมือเทคนิคทั่วไปที่ออกแบบมาเพื่อช่วยผู้ใช้ทำความเข้าใจเนื้อหาวิดีโอเท่านั้น นักพัฒนาไม่รับผิดชอบทางกฎหมายสำหรับเนื้อหาใด ๆ ที่ผู้ใช้เข้าถึง แปล หรือประมวลผล

ผู้ใช้ต้องมั่นใจว่าการใช้งานของตนเป็นไปตามกฎหมายและข้อบังคับท้องถิ่น ความรับผิดทางกฎหมายทั้งหมดตกอยู่ที่ผู้ใช้เท่านั้น

การใช้งานที่ตั้งใจ

แอปพลิเคชันนี้ออกแบบเป็นเครื่องมือช่วยเหลือสำหรับการใช้งานส่วนตัวในเครื่องโดยผู้พิการทางการได้ยิน ผู้เรียนภาษา หรือผู้ที่ต้องการทำความเข้าใจเนื้อหาวิดีโอในภาษาต่างประเทศ

ข้อจำกัดทางเทคนิค

แอปพลิเคชันนี้รองรับการวิเคราะห์เนื้อหาวิดีโอที่เข้าถึงได้สาธารณะซึ่งไม่ได้รับการป้องกันโดย DRM

สำหรับไฟล์ MP4 ที่ไม่ได้เข้ารหัสแบบ fast-start จำเป็นต้องดาวน์โหลดทั้งหมดก่อนเริ่มการแปล

ข้อจำกัดความรับผิดชอบ

แอปพลิเคชันนี้ให้บริการ "ตามสภาพ" โดยไม่มีการรับประกันใด ๆ ทั้งโดยชัดแจ้งหรือโดยนัย

คำบรรยายและการแปลถูกสร้างขึ้นโดยอัตโนมัติโดยเครื่องจักรและมีไว้เพื่ออ้างอิงเท่านั้น

การอัปเดตนโยบาย

นโยบายความเป็นส่วนตัวนี้อาจได้รับการอัปเดตพร้อมกับเวอร์ชันใหม่ การใช้แอปพลิเคชันนี้ต่อไปถือเป็นการยอมรับนโยบายความเป็นส่วนตัวเวอร์ชันล่าสุด
