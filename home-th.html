#2 วิธีใช้งาน

📥 ติดตั้ง EchoShortsPlayer จำเป็น

แอปพลิเคชันเดสก์ท็อป — เอนจินหลักสำหรับทุกฟีเจอร์

EchoShortsPlayer คือแอปพลิเคชันเดสก์ท็อปที่รันโมเดล AI ในเครื่อง ส่วนขยายเบราว์เซอร์และ CLI ขึ้นอยู่กับมัน ติดตั้งก่อนเป็นอันดับแรกก่อนใช้วิธีใดๆ ด้านล่าง

ดาวน์โหลดจาก Windows Store

ข้อกำหนดระบบ: Windows 10/11, GPU NVIDIA ที่มี VRAM 8 GB ขึ้นไป, ติดตั้งไดรเวอร์ CUDA

หลังจากติดตั้งแล้ว เปิดแอปพลิเคชัน มันจะเริ่มเซิร์ฟเวอร์แบ็กเอนด์ในเครื่องที่ localhost:18632 ซึ่งส่วนขยายและ CLI ใช้สื่อสาร

🔌 ส่วนขยาย Chrome (ดักจับวิดีโอ) แนะนำอย่างยิ่ง

การดักจับสื่อระดับลึกในระดับเครือข่าย

ส่วนขยาย Chrome ใช้ API webRequest เพื่อดักจับคำขอเครือข่ายทั้งหมดในระดับเบราว์เซอร์ ตรวจจับสตรีม m3u8/HLS, ไฟล์ MP4 และรูปแบบสื่ออื่นๆ นอกจากนี้ยังสแกน DOM ของหน้าเพื่อหาองค์ประกอบวิดีโอและลิงก์ดาวน์โหลด

ดาวน์โหลดส่วนขยาย (.zip)

การติดตั้ง (โหมดนักพัฒนา):

  1. ดาวน์โหลดไฟล์ zip ส่วนขยายด้านบนและแตกไฟล์ไปยังโฟลเดอร์
  2. เปิด Chrome และไปที่ chrome://extensions/
  3. เปิดใช้งาน โหมดนักพัฒนา (สวิตช์มุมบนขวา)
  4. คลิก โหลดที่แกะแพ็กแล้ว และเลือกโฟลเดอร์ echoshorts-extension
  5. ไอคอนส่วนขยายปรากฏบนแถบเครื่องมือพร้อมตราแสดงจำนวนสื่อที่ตรวจพบ

การใช้งาน:

  1. เข้าชมหน้าเว็บใดก็ได้ที่มีเนื้อหาวิดีโอ
  2. คลิกไอคอนส่วนขยายเพื่อดูสตรีม m3u8/MP4 ที่ตรวจพบ
  3. คลิก ดาวน์โหลด เพื่อบันทึกเป็น MP4 ในเครื่อง หรือ แปล เพื่อเริ่มสร้างคำบรรยาย
  4. คลิก บันทึก เล่นวิดีโอในเบราว์เซอร์ เมื่อเล่นจบแล้วคลิก หยุด — ส่วนขยายจะบันทึกวิดีโอที่ดูในแท็บนี้โดยอัตโนมัติ
  5. เลื่อนเมาส์ไปเหนือรายการเพื่อไฮไลต์องค์ประกอบวิดีโอที่เกี่ยวข้องบนหน้า

ส่วนขยายปลอดภัยหรือไม่?

  • โค้ดเป็นโอเพนซอร์สทั้งหมด — ตรวจสอบได้เอง สื่อสารเฉพาะกับแอปเดสก์ท็อปบนเครื่องคุณ เราไม่ได้รับประวัติการเข้าชม
  • ส่วนขยายและ EchoShortsPlayer ไม่เก็บข้อมูลส่วนบุคคล ไม่มีการติดตามพฤติกรรมหรือโฆษณา
  • นอกจากการเปิดใช้งานใบอนุญาตแล้ว กิจกรรมเครือข่ายทั่วไปจำกัดอยู่ที่การแก้และดึงสตรีมวิดีโอที่คุณเลือก
  • คุณตรวจสอบคำขอขาออกได้เองเพื่อยืนยันว่าไม่มีการอัปโหลดที่ไม่คาดคิดนอกจากการเปิดใช้งานและการดึงสื่อ

💻 อินเทอร์เฟซบรรทัดคำสั่ง ผู้ใช้ขั้นสูง

ระบบอัตโนมัติ, การประมวลผลแบบแบตช์ และการเขียนสคริปต์

CLI ให้การเข้าถึงโดยตรงไปยังฟีเจอร์ดาวน์โหลดและแปลทั้งหมดจากเทอร์มินัล ออกแบบมาสำหรับผู้ใช้ขั้นสูงที่ต้องการประมวลผลวิดีโอหลายรายการ ทำให้เวิร์กโฟลว์เป็นอัตโนมัติ หรือรวมเข้ากับเครื่องมืออื่น

ทำไมควรใช้ CLI?

  • การประมวลผลแบบแบตช์: แปลวิดีโอหลายร้อยรายการด้วยคำสั่งเดียว
  • เขียนสคริปต์ได้: รวมเข้ากับ shell scripts, cron jobs หรือ CI/CD pipelines
  • ควบคุมโมเดลได้เต็มที่: เลือกขนาดโมเดล Whisper, เอนจินแปล, โหมดลดเสียงรบกวน
  • ไม่มี GUI โอเวอร์เฮด: เหมาะสำหรับเซิร์ฟเวอร์ เครื่องไม่มีหน้าจอ หรือเซสชัน SSH ระยะไกล
  • รองรับทั้งโหมดประมวลผลแบบอนุกรม (ประหยัดหน่วยความจำ) และแบบขนาน (เร็ว)

คำสั่งที่ใช้ได้:

# แปลไฟล์วิดีโอในเครื่องเป็นคำบรรยายภาษาจีน
resources\backend\backend.exe --cli translate video.mp4 --target zh

# แปลทั้งโฟลเดอร์แบบแบตช์
resources\backend\backend.exe --cli translate C:\Videos\

# ตัวเลือกทั้งหมด: ภาษาต้นทาง, โมเดล Whisper, เอนจินแปล, ลดเสียงรบกวน, โหมดประมวลผล
resources\backend\backend.exe --cli translate video.mp4 --source auto --target ja --whisper distil-large-v3 --translation qwen3-8b --denoise vocal --mode parallel

# ดาวน์โหลด m3u8 หรือ MP4 จากระยะไกล
resources\backend\backend.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# ดาวน์โหลดและแปลในขั้นตอนเดียว
resources\backend\backend.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# แปลไฟล์ SRT ที่มีอยู่
resources\backend\backend.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

อ้างอิงพารามิเตอร์:

--source, -s      ภาษาต้นทางหรือ "auto" (ค่าเริ่มต้น: auto)
--target, -t      ภาษาปลายทาง (ค่าเริ่มต้น: zh)
--whisper, -w     tiny|base|small|medium|distil-large-v3|large-v3
--translation, -m opus-mt|nllb-distilled-600M|nllb-1.3B|nllb-3.3B|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal (ค่าเริ่มต้น: off)
--mode            serial|parallel (ค่าเริ่มต้น: serial)
--output, -o      เส้นทางไฟล์เอาต์พุต
--url             URL สื่อ (m3u8 / MP4)
--referer         ส่วนหัว Referer

      
ดูรายการรหัสภาษาที่รองรับทั้งหมดสำหรับ --source และ --target: อ้างอิงรหัสภาษา

หากต้องการความช่วยเหลือทางเทคนิค กรุณาติดต่อ supports@echoshorts.win

#3 นโยบายความเป็นส่วนตัวและข้อจำกัดความรับผิดชอบ

การประมวลผลข้อมูลในเครื่อง

ฟีเจอร์หลักทั้งหมดของ EchoShortsPlayer — รวมถึงการรู้จำเสียงพูด การแปล และการดาวน์โหลดสื่อ — ทำงานบนอุปกรณ์ของคุณทั้งหมด ผ่านเซิร์ฟเวอร์ภายในเครื่อง (127.0.0.1:18632)

เราไม่เก็บรวบรวม จัดเก็บ ส่ง หรือวิเคราะห์ข้อมูลผู้ใช้ รวมถึงแต่ไม่จำกัดเพียง: เนื้อหาวิดีโอที่คุณดู ข้อความคำบรรยายที่รู้จำ ผลการแปล ประวัติการเรียกดู หรือข้อมูลส่วนบุคคลใดๆ

ไม่มีการส่งข้อมูลผ่านเครือข่าย

ระหว่างการใช้งานปกติ แอปไม่ส่งข้อมูลผู้ใช้ไปยังเซิร์ฟเวอร์ภายนอก การประมวลผลเสียงและการแปลข้อความทำบนเครื่องทั้งหมด โมเดล AI ดาวน์โหลดจากแหล่งสาธารณะ (HuggingFace) ในครั้งแรกและสามารถใช้งานออฟไลน์ได้หลังจากนั้น

ส่วนขยายเบราว์เซอร์สื่อสารกับแบ็กเอนด์ภายในเครื่องที่ localhost:18632 เท่านั้น ไม่มีการส่งข้อมูลไปยังเซิร์ฟเวอร์ระยะไกลที่ผู้พัฒนาดำเนินการ

ไม่มีโฆษณา การติดตาม หรือการแนะนำ

แอปนี้ไม่มีระบบโฆษณา โค้ดติดตามพฤติกรรม การวิเคราะห์ หรือกลไกการแนะนำข้อมูล เราไม่แชร์ข้อมูลผู้ใช้กับบุคคลที่สาม ไม่สร้างโปรไฟล์ และไม่ส่งเนื้อหาตามพฤติกรรม

หลักนิรภัยและความรับผิดชอบของผู้ใช้

EchoShortsPlayer เป็นเครื่องมือทางเทคนิคทั่วไปที่ออกแบบมาเพื่อช่วยให้เข้าใจเนื้อหาวิดีโอเท่านั้น ภายใต้หลัก safe harbor ผู้พัฒนาและผู้เผยแพร่ไม่รับผิดชอบทางกฎหมายเรื่องละเมิดลิขสิทธิ์หรืออื่นๆ สำหรับเนื้อหาที่ผู้ใช้เข้าถึง แปล หรือประมวลผล

ผู้ใช้ต้องให้แน่ใจว่าการใช้งานเป็นไปตามกฎหมายท้องถิ่นและข้อกำหนดการให้บริการของแพลตฟอร์ม ความรับผิดทางกฎหมายจากการเข้าถึงเนื้อหาที่มีลิขสิทธิ์ การละเมิดกฎ หรือกิจกรรมผิดกฎหมายเป็นของผู้ใช้แต่เพียงผู้เดียว

แอปไม่ตัดสินหรือรับประกันความถูกต้องตามกฎหมายของเนื้อหาที่เข้าถึง และไม่รับผิดชอบต่อความสูญเสียโดยตรงหรือโดยอ้อมจากการใช้งาน

การใช้งานที่ตั้งใจไว้

แอปออกแบบเป็นเครื่องมือช่วยสำหรับการใช้งานส่วนตัวบนเครื่องโดยผู้มีความบกพร่องทางการได้ยิน ผู้เรียนภาษา หรือผู้ที่ต้องการเข้าใจวิดีโอภาษาต่างประเทศ การใช้งานอื่นเป็นความรับผิดชอบของผู้ใช้แต่เพียงผู้เดียว

ข้อจำกัดทางเทคนิค

แอปรองรับการวิเคราะห์วิดีโอที่เข้าถึงได้สาธารณะและไม่มี DRM เนื่องจากโปรโตคอลป้องกันลิขสิทธิ์ (เช่น Widevine, PlayReady) สตรีมเสียงของเนื้อหาที่มี DRM อาจดึงไม่ได้ จึงไม่สามารถสร้างคำบรรยายได้

สำหรับไฟล์ MP4 ที่ไม่ได้เข้ารหัสแบบ fast-start (อะตอม moov อยู่ท้ายไฟล์) ต้องดาวน์โหลดให้ครบก่อนเริ่มแปล ไฟล์ MP4 แบบ fast-start รองรับการแปลแบบสตรีมขณะดาวน์โหลด

ข้อจำกัดความรับผิดชอบ

แอปจัดให้ตามสภาพโดยไม่มีการรับประกันโดยชัดแจ้งหรือโดยนัย ผู้พัฒนาไม่รับประกันการทำงานที่ถูกต้องในทุกสภาพแวดล้อม และไม่รับผิดชอบต่อความสูญเสีย การสูญหายของข้อมูล หรือปัญหาอุปกรณ์จากการใช้งาน การใช้งานถือเป็นการยอมรับข้อกำหนดทั้งหมดข้างต้น

คำบรรยายและการแปลสร้างโดยเครื่องอัตโนมัติเพื่ออ้างอิงเท่านั้น ไม่มีการรับประกันความถูกต้อง ความสมบูรณ์ หรือความเหมาะสม และไม่รับผิดชอบต่อผลที่ตามมาจากการพึ่งพาการแปลดังกล่าว

การอัปเดตนโยบาย

นโยบายความเป็นส่วนตัวนี้อาจได้รับการอัปเดตในเวอร์ชันใหม่ การเปลี่ยนแปลงที่สำคัญจะแจ้งผ่านบันทึกการอัปเดตของแอป การใช้งานต่อเนื่องถือเป็นการยอมรับนโยบายความเป็นส่วนตัวฉบับล่าสุด

#4 โปรแกรมพันธมิตร

🌟 แอมบาสเดอร์โปรโมชัน

เหมาะกับ: ครีเอเตอร์วิดีโอ สื่อ และผู้ดูแลชุมชน คุณโฟกัสคอนเทนต์ เราจัดการขายและจัดส่ง

ขั้นตอน:

  1. สมัคร: ติดต่อ supports@echoshorts.win เพื่อรับรหัสส่วนลดและลิงก์ติดตาม
  2. สร้างคอนเทนต์: นำเสนอประสบการณ์ EchoShortsPlayer ในวิดีโอหรือบทความ
  3. ค่าคอมมิชชัน: ผู้ใช้สั่งซื้อด้วยรหัสของคุณ รับค่าคอมสูงแบบเรียลไทม์

จุดเด่น

  • ไม่ต้องลงทุนและรับความเสี่ยงสต็อก ไม่ต้องดูแลหลังการขาย เห็นรายได้ชัดเจน

💼 ตัวแทนจำหน่ายที่ได้รับอนุญาต

เหมาะกับ: ร้านค้า ไลฟ์ขาย หรือมีประสบการณ์จัดจำหน่ายซอฟต์แวร์

ขั้นตอน:

  1. ตรวจสอบช่องทาง: ส่ง URL แพลตฟอร์มขาย (ลิงก์ร้านหรือห้องไลฟ์)
  2. รับอนุญาต: ตกลงส่วนแบ่ง เราส่งชุดคีย์พร้อมตัวระบุช่องทาง
  3. ขายเอง: เก็บเงินและจัดส่งในช่องทางของคุณ
  4. ชำระรอบ: หลังรอบขาย ชำระยอดคงเหลือและเปิดรอบถัดไป

หมายเหตุ

  • คีย์จำหน่ายได้รับการปกป้องด้วยใบอนุญาตแบบไดนามิกบนคลาวด์
