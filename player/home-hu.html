#2 How to Use

📥 Install EchoShortsPlayer Required

Desktop application — the core engine for all features

EchoShortsPlayer is the desktop application that runs the AI models locally. The browser extension and CLI depend on it. Install it first before using any of the methods below.

Get EchoShortsPlayer

System requirements: Windows 10/11, NVIDIA GPU with 8 GB+ VRAM, CUDA drivers installed.

After installation, launch the application. It starts a local backend server at localhost:18632 that the extension and CLI communicate with.

🔌 Chrome Extension (Video Sniffing) Strongly recommended

Deep network-level media interception

The Chrome extension uses the webRequest API to intercept all network requests at the browser level, detecting m3u8/HLS streams, MP4 files, and other media formats. It also scans the page DOM for video elements and download links.

Get Extension Package (.zip)

Telepítés (fejlesztői mód):

  1. Get the extension package above and extract it to a folder.
  2. Nyissa meg a Chrome-ot, és lépjen a chrome://extensions/ oldalra.
  3. Kapcsolja be a Fejlesztői módot (jobb felső kapcsoló).
  4. Kattintson a Csomagolatlan bővítmény betöltése lehetőségre, és válassza a echoshorts-extension mappát.
  5. A bővítmény ikon megjelenik az eszköztáron; a jelvény a felismert média számát mutatja.

Használat:

  1. Nyisson meg bármely oldalt videótartalommal.
  2. Kattintson a bővítmény ikonra a felismert m3u8/MP4 streamek megtekintéséhez.
  3. Kattintson a Letöltés gombra helyi MP4 mentéséhez, vagy a Fordítás gombra a feliratgenerálás indításához.
  4. Kattintson a Felvétel gombra, játssza le a videót a böngészőben, lejátszás után a Leállítás gombra — a bővítmény automatikusan elmenti a lapon megtekintett videókat.
  5. Vigye az egeret az elemek fölé, hogy kiemelje a megfelelő videóelemet az oldalon.

Biztonságos a bővítmény?

  • Teljesen nyílt forráskódú — bármikor átnézheti a kódot. Csak az asztali alkalmazással kommunikál a gépen; nem kapjuk meg a böngészési előzményeit.
  • A bővítmény és az EchoShortsPlayer nem gyűjt személyes adatot, és nem végez viselkedéskövetést vagy hirdetést.
  • A licencaktiváláson kívül a jellemző hálózati tevékenység a választott videostream lekérésére korlátozódik.
  • Ellenőrizheti a kimenő kéréseket, hogy nincs-e váratlan feltöltés az aktiváláson és a média lekérésén kívül.

💻 Command-Line Interface Power Users

Automation, batch processing, and scripting

The CLI provides direct access to all download and translation features from the terminal. It's designed for power users who need to process multiple videos, automate workflows, or integrate with other tools.

Miért érdemes a CLI-t használni?

  • Kötegelt feldolgozás: fordíts le több száz videót egyetlen paranccsal
  • Szkriptelhető: integrálható shell-szkriptekbe, cron-feladatokba vagy CI/CD-pipeline-okba
  • Teljes irányítás a modellek felett: válassz Whisper-modellméretet, fordítómotort, zajcsökkentési módot
  • Nincs GUI-túlterhelés: ideális szerverekhez, fej nélküli gépekhez vagy távoli SSH-munkamenetekhez
  • Támogatja a soros (memória-hatékony) és a párhuzamos (gyors) feldolgozási módot is

Available commands:

# Translate a local video file to Chinese subtitles
resources\backend\backend.exe --cli translate video.mp4 --target zh

# Batch translate an entire folder
resources\backend\backend.exe --cli translate C:\Videos\

# Full options: source language, whisper model, translation engine, denoising, processing mode
resources\backend\backend.exe --cli translate video.mp4 --source auto --target ja --whisper distil-large-v3 --translation qwen3-8b --denoise vocal --mode parallel

# Fetch a remote m3u8 or MP4
resources\backend\backend.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# Fetch and translate in one step
resources\backend\backend.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# Translate an existing SRT file
resources\backend\backend.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

Hang- és szinkronparancsok:

# Feliratfájlból beszélt párbeszédsávot készít (beszédszintézis)
resources\backend\backend.exe --cli speak-srt video.zh.srt --model kokoro-multi-lang-v1.1 --gender female

# Néma másolatot készít a videóról (hang eltávolítva, a videosáv változatlanul másolva)
resources\backend\backend.exe --cli strip-audio video.mp4

# Csak a háttérzenét tartja meg, az eredeti párbeszédet eltávolítja
resources\backend\backend.exe --cli extract-bgm video.mp4

# Több sávot kever össze, mindegyiket saját hangerőszorzóval
resources\backend\backend.exe --cli mix-audio --input video.zh.m4a 1.75 --input video.bgm.m4a 0.4 --output video.dubbed.m4a --duration first

Paraméter-hivatkozás:

--source, -s      Source language or "auto" (default: auto)
--target, -t      Target language (default: zh)
--whisper, -w     tiny|base|small|medium|distil-large-v3|large-v3
--translation, -m opus-mt|nllb-distilled-600M|nllb-1.3B|nllb-3.3B|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal (default: off)
--mode            serial|parallel (default: serial)
--output, -o      Output file path
--url             Media source (m3u8 / MP4)
--referer         Referer header

Hangparaméterek referenciája:

speak-srt
  --lang, -l      Language to speak (default: read from the filename)
  --model, -m     TTS model key (default: fastest model for the language)
  --voice, -v     Voice id within the model (overrides --gender)
  --gender, -g    male|female
  --ref-audio     Voice sample to clone (voice-cloning models only)
  --ref-text      Verbatim transcript of --ref-audio
  --duration      Pin the track to this many seconds

strip-audio / extract-bgm
  --bitrate       AAC bitrate (default: 192k)
  --output, -o    Output path

mix-audio
  --input, -i     FILE GAIN - repeat once per track (1.0 = unchanged)
  --duration      longest|first|shortest (default: longest)
  --sample-rate   Output sample rate (default: 44100)

A --source és --target támogatott nyelvkódjainak teljes listája: Nyelvkód-hivatkozás

#3 Adatvédelmi irányelvek és felelősségkizárás

Helyi adatfeldolgozás

Az EchoShortsPlayer összes alapvető funkciója — beleértve a beszédfelismerést, a fordítást és a médialetöltést — teljes egészében a helyi eszközén fut, egy helyi háttérszerver (127.0.0.1:18632) segítségével.

Nem gyűjtünk, tárolunk, továbbítunk vagy elemezünk felhasználói adatot, ideértve többek között: a megtekintett videótartalmat, a felismert feliratszöveget, a fordítási eredményeket, a böngészési előzményeket vagy bármilyen személyes információt.

Nincs adattovábbítás a hálózaton

Az alkalmazás normál használat során nem küld felhasználói adatot külső szerverekre. Minden hangfeldolgozás és szövegfordítás helyben történik. Az AI-modellek első használatkor nyilvános forrásokból (HuggingFace) töltődnek le, majd teljesen offline is futhatnak.

A böngészőbővítmény csak a helyi háttérrendszerrel kommunikál a localhost:18632 címen. Nem kerül adat a fejlesztők által üzemeltetett távoli szerverekre.

Nincs hirdetés, követés vagy ajánlás

Ez az alkalmazás nem tartalmaz hirdetési rendszereket, felhasználói viselkedés követő kódot, elemzéseket vagy adat-ajánlási mechanizmusokat. Nem osztunk meg felhasználói adatot harmadik felekkel, és nem hozunk létre profilokat vagy nem tolunk tartalmat viselkedés alapján.
