#2 How to Use

📥 Install EchoShortsPlayer Required

Desktop application — the core engine for all features

EchoShortsPlayer is the desktop application that runs the AI models locally. The browser extension and CLI depend on it. Install it first before using any of the methods below.

Завантажити з Windows Store

System requirements: Windows 10/11, NVIDIA GPU with 8 GB+ VRAM, CUDA drivers installed.

After installation, launch the application. It starts a local backend server at localhost:18632 that the extension and CLI communicate with.

🔌 Chrome Extension (Video Sniffing) Strongly recommended

Deep network-level media interception

The Chrome extension uses the webRequest API to intercept all network requests at the browser level, detecting m3u8/HLS streams, MP4 files, and other media formats. It also scans the page DOM for video elements and download links.

Download Extension (.zip)

Встановлення (режим розробника):

  1. Завантажте zip-архів розширення вище та розпакуйте його в теку.
  2. Відкрийте Chrome і перейдіть на chrome://extensions/.
  3. Увімкніть Режим розробника (перемикач угорі праворуч).
  4. Натисніть Завантажити розпаковане розширення і виберіть теку echoshorts-extension.
  5. Піктограма розширення з’явиться на панелі інструментів; на значку показано кількість виявлених медіа.

Використання:

  1. Відкрийте сторінку з відео.
  2. Натисніть піктограму розширення, щоб переглянути виявлені потоки m3u8/MP4.
  3. Натисніть Завантажити, щоб зберегти локально як MP4, або Перекласти, щоб почати створення субтитрів.
  4. Натисніть Запис, відтворіть відео в браузері, після закінчення натисніть Стоп — розширення автоматично збереже переглянуті на цій вкладці відео.
  5. Наведіть курсор на елемент, щоб підсвітити відповідне відео на сторінці.

Чи безпечне розширення?

  • Повністю з відкритим кодом — ви можете перевірити код. Воно спілкується лише з настільним застосунком на вашому ПК; ми не отримуємо історію перегляду.
  • Розширення та EchoShortsPlayer не збирають персональні дані й не ведуть поведінкове відстеження чи рекламу.
  • Окрім активації ліцензії типова мережева активність обмежується отриманням обраних вами відеопотоків.
  • Ви можете самостійно перевірити вихідні запити, щоб переконатися, що немає несподіваних передач поза активацією та отриманням медіа.

💻 Command-Line Interface Power Users

Automation, batch processing, and scripting

The CLI provides direct access to all download and translation features from the terminal. It's designed for power users who need to process multiple videos, automate workflows, or integrate with other tools.

Навіщо використовувати CLI?

  • Пакетна обробка: переклад сотень відео однією командою
  • Підтримує скрипти: інтеграція в shell-скрипти, cron-завдання або CI/CD-пайплайни
  • Повний контроль над моделями: вибір розміру моделі Whisper, рушія перекладу, режиму шумозаглушення
  • Без накладних витрат GUI: ідеально для серверів, безголових машин або віддалених SSH-сесій
  • Підтримує як послідовний (економний за пам'яттю), так і паралельний (швидкий) режими обробки

Available commands:

# Translate a local video file to Chinese subtitles
resources\backend\backend.exe --cli translate video.mp4 --target zh

# Batch translate an entire folder
resources\backend\backend.exe --cli translate C:\Videos\

# Full options: source language, whisper model, translation engine, denoising, processing mode
resources\backend\backend.exe --cli translate video.mp4 --source auto --target ja --whisper distil-large-v3 --translation qwen3-8b --denoise vocal --mode parallel

# Download a remote m3u8 or MP4
resources\backend\backend.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# Download and translate in one step
resources\backend\backend.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# Translate an existing SRT file
resources\backend\backend.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

Довідка параметрів:

--source, -s      Source language or "auto" (default: auto)
--target, -t      Target language (default: zh)
--whisper, -w     tiny|base|small|medium|distil-large-v3|large-v3
--translation, -m opus-mt|nllb-distilled-600M|nllb-1.3B|nllb-3.3B|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal (default: off)
--mode            serial|parallel (default: serial)
--output, -o      Output file path
--url             Media URL (m3u8 / MP4)
--referer         Referer header

Повний список підтримуваних кодів мов для --source та --target: Довідник кодів мов

#3 Політика конфіденційності та відмова від відповідальності

Локальна обробка даних

Усі основні функції EchoShortsPlayer — зокрема розпізнавання мовлення, переклад і завантаження медіа — повністю виконуються на вашому локальному пристрої через локальний сервер бекенду (127.0.0.1:18632).

Ми не збираємо, не зберігаємо, не передаємо й не аналізуємо дані користувача, зокрема: переглянутий відеоконтент, розпізнаний текст субтитрів, результати перекладу, історію перегляду або будь-яку особисту інформацію.

Без передачі даних мережею

Під час звичайного використання застосунок не надсилає дані користувача на зовнішні сервери. Уся обробка аудіо та переклад тексту виконується локально. Моделі ШІ завантажуються з відкритих джерел (HuggingFace) під час першого використання й далі можуть працювати повністю офлайн.

Розширення браузера спілкується лише з локальним бекендом на localhost:18632. Дані не передаються на віддалені сервери, якими керують розробники.

Без реклами, стеження чи рекомендацій

Цей застосунок не містить рекламних систем, коду стеження за поведінкою користувача, аналітики чи механізмів рекомендацій даних. Ми не передаємо дані користувача третім сторонам і не створюємо профілі чи не надсилаємо контент на основі поведінки.

Безпечна гавань і відповідальність користувача

EchoShortsPlayer — загальнотехнічний інструмент, призначений лише для допомоги в розумінні відеоконтенту. Згідно з принципом безпечної гавані розробники та видавці не несуть юридичної відповідальності за порушення авторських прав або інше щодо контенту, до якого користувач отримує доступ, який перекладає або обробляє.

Користувач повинен забезпечити відповідність використання місцевим законам і умовам надання послуг платформ. Уся юридична відповідальність за доступ до контенту, захищеного авторським правом, порушення правил платформ або незаконну діяльність лежить виключно на користувачі.

Застосунок не оцінює й не гарантує законність контенту, до якого звертається користувач, і не приймає відповідальності за прямі чи непрямі збитки від його використання.

Призначене використання

Застосунок розроблено як допоміжний інструмент для особистого локального використання людьми з порушеннями слуху, тими, хто вивчає мови, або тими, кому потрібно розуміти відео іноземними мовами. Будь-яке інше використання — виключна відповідальність користувача.

Технічні обмеження

Застосунок підтримує аналіз публічно доступного відеоконтенту без захисту DRM. Через протоколи захисту (наприклад Widevine, PlayReady) аудіопотоки DRM-контенту можуть бути недоступні для витягування, що унеможливлює створення субтитрів.

Для файлів MP4 без кодування «fast-start» (атом moov у кінці файлу) потрібне повне завантаження перед початком перекладу. Fast-start MP4 підтримують потоковий переклад під час завантаження.

Відмова від відповідальності

Застосунок надається «як є» без будь-яких явних чи припущених гарантій. Розробник не гарантує коректну роботу в усіх середовищах і не несе відповідальності за збитки, втрату даних або проблеми пристрою, спричинені використанням. Використання означає прийняття всіх наведених умов.

Субтитри та переклади генеруються автоматично машиною лише для довідки. Немає гарантій щодо точності, повноти чи придатності машинного перекладу та не приймається відповідальність за наслідки покладення на такі переклади.

Оновлення політики

Цю політику конфіденційності може бути оновлено в нових версіях. Про суттєві зміни повідомлятиметься через журнал оновлень застосунку. Продовження використання означає прийняття найновішої версії політики конфіденційності.
