AI Translation

Multiple translation engines:

  • Opus-MT — fast, 9 languages
  • Qwen — best quality, CJK-optimized
📶

Media Detection

Supports 10,000+ websites and automatically detects m3u8/HLS streams and MP4 video links. Download or translate with one click via browser extension.

NVIDIA GPU with 8 GB+ VRAM and CUDA drivers installed. Supports GPU-accelerated speech recognition and translation for optimal performance.

#2 How to Use

📥 Install EchoShortsPlayer Required

Desktop application — the core engine for all features

EchoShortsPlayer is the desktop application that runs the AI models locally. The browser extension and CLI depend on it. Install it first before using any of the methods below.

Get EchoShortsPlayer

System requirements: Windows 10/11, NVIDIA GPU with 8 GB+ VRAM, CUDA drivers installed.

After installation, launch the application. It starts a local backend server at localhost:18632 that the extension and CLI communicate with.

🔌 Chrome Extension (Video Sniffing) Strongly recommended

Deep network-level media interception

The Chrome extension uses the webRequest API to intercept all network requests at the browser level, detecting m3u8/HLS streams, MP4 files, and other media formats. It also scans the page DOM for video elements and download links.

Get Extension Package (.zip)

Kurulum (geliştirici modu):

  1. Get the extension package above and extract it to a folder.
  2. Chrome’u açın ve chrome://extensions/ adresine gidin.
  3. Sağ üstteki anahtarla Geliştirici modunu etkinleştirin.
  4. Paketlenmemiş öğe yükleye tıklayın ve echoshorts-extension klasörünü seçin.
  5. Uzantı simgesi araç çubuğunda görünür; rozet algılanan medya sayısını gösterir.

Kullanım:

  1. Video içeren herhangi bir sayfaya gidin.
  2. Algılanan m3u8/MP4 akışlarını görmek için uzantı simgesine tıklayın.
  3. Yerel MP4 olarak kaydetmek için İndir veya altyazı oluşturmaya başlamak için Çevirye tıklayın.
  4. Kayıt'a tıklayın, videoyu tarayıcıda oynatın, bitince Durdur'a tıklayın — uzantı bu sekmede izlenen videoları otomatik kaydeder.
  5. Sayfadaki ilgili video öğesini vurgulamak için öğelerin üzerine gelin.

Uzantı güvenli mi?

  • Tamamen açık kaynak — kodu inceleyebilirsiniz. Yalnızca makinenizdeki masaüstü uygulamasıyla iletişim kurar; tarama geçmişinizi almayız.
  • Uzantı ve EchoShortsPlayer kişisel veri toplamaz; davranış izleme veya reklam yoktur.
  • Lisans etkinleştirmesi dışında tipik ağ etkinliği seçtiğiniz video akışlarını almakla sınırlıdır.
  • Etkinleştirme ve medya alımı dışında beklenmeyen yüklemeler olmadığını doğrulamak için giden istekleri kendiniz inceleyebilirsiniz.

💻 Command-Line Interface Power Users

Automation, batch processing, and scripting

The CLI provides direct access to all download and translation features from the terminal. It's designed for power users who need to process multiple videos, automate workflows, or integrate with other tools.

CLI neden kullanılmalı?

  • Toplu işleme: tek bir komutla yüzlerce videoyu çevirin
  • Komut dosyası yazılabilir: shell betiklerine, cron işlerine veya CI/CD süreçlerine entegre edilebilir
  • Modeller üzerinde tam kontrol: Whisper model boyutu, çeviri motoru, gürültü azaltma modu seçimi
  • GUI ek yükü yok: sunucular, başsız makineler veya uzak SSH oturumları için ideal
  • Hem seri (bellek verimli) hem de paralel (hızlı) işleme modlarını destekler

Available commands:

# Translate a local video file to Chinese subtitles
resources\backend\backend.exe --cli translate video.mp4 --target zh

# Batch translate an entire folder
resources\backend\backend.exe --cli translate C:\Videos\

# Full options: source language, whisper model, translation engine, denoising, processing mode
resources\backend\backend.exe --cli translate video.mp4 --source auto --target ja --whisper distil-large-v3 --translation qwen3-8b --denoise vocal --mode parallel

# Fetch a remote m3u8 or MP4
resources\backend\backend.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# Fetch and translate in one step
resources\backend\backend.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# Translate an existing SRT file
resources\backend\backend.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

Ses ve dublaj komutları:

# Bir altyazı dosyasını seslendirilmiş diyalog parçasına dönüştürür (konuşma sentezi)
resources\backend\backend.exe --cli speak-srt video.zh.srt --model kokoro-multi-lang-v1.1 --gender female

# Videonun sessiz bir kopyasını oluşturur (ses kaldırılır, video akışı olduğu gibi kopyalanır)
resources\backend\backend.exe --cli strip-audio video.mp4

# Yalnızca fon müziğini korur, orijinal diyaloğu kaldırır
resources\backend\backend.exe --cli extract-bgm video.mp4

# Birden fazla parçayı harmanlar, her biri kendi ses çarpanıyla
resources\backend\backend.exe --cli mix-audio --input video.zh.m4a 1.75 --input video.bgm.m4a 0.4 --output video.dubbed.m4a --duration first

Parametre referansı:

--source, -s      Source language or "auto" (default: auto)
--target, -t      Target language (default: zh)
--whisper, -w     tiny|base|small|medium|distil-large-v3|large-v3
--translation, -m opus-mt|nllb-distilled-600M|nllb-1.3B|nllb-3.3B|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal (default: off)
--mode            serial|parallel (default: serial)
--output, -o      Output file path
--url             Media source (m3u8 / MP4)
--referer         Referer header

Ses parametre referansı:

speak-srt
  --lang, -l      Language to speak (default: read from the filename)
  --model, -m     TTS model key (default: fastest model for the language)
  --voice, -v     Voice id within the model (overrides --gender)
  --gender, -g    male|female
  --ref-audio     Voice sample to clone (voice-cloning models only)
  --ref-text      Verbatim transcript of --ref-audio
  --duration      Pin the track to this many seconds

strip-audio / extract-bgm
  --bitrate       AAC bitrate (default: 192k)
  --output, -o    Output path

mix-audio
  --input, -i     FILE GAIN - repeat once per track (1.0 = unchanged)
  --duration      longest|first|shortest (default: longest)
  --sample-rate   Output sample rate (default: 44100)

--source ve --target için desteklenen dil kodlarının tam listesine bakın: Dil kodu referansı

Teknik destek için lütfen supports@echoshorts.win adresine yazın.

#3 Gizlilik politikası ve sorumluluk reddi

Yerel veri işleme

EchoShortsPlayer'ın tüm temel özellikleri — konuşma tanıma, çeviri ve medya indirme dahil — tamamen yerel cihazınızda, yerel bir arka uç sunucusu (127.0.0.1:18632) tarafından çalıştırılır.

İzlediğiniz video içeriği, tanınan altyazı metni, çeviri sonuçları, tarama geçmişi veya herhangi bir kişisel bilgi dahil ancak bunlarla sınırlı olmamak üzere kullanıcı verisi toplamaz, saklamaz, iletmez veya analiz etmeyiz.

Ağ üzerinden veri iletimi yok

Uygulama normal kullanımda kullanıcı verilerini harici sunuculara göndermez. Tüm ses işleme ve metin çevirisi yerel olarak tamamlanır. Yapay zekâ modelleri ilk kullanımda herkese açık kaynaklardan (HuggingFace) indirilir ve sonrasında tamamen çevrimdışı çalışabilir.

Tarayıcı uzantısı yalnızca localhost:18632 adresindeki yerel arka uçla iletişim kurar. Geliştiricilerin işlettiği uzak sunuculara veri iletilmez.

Reklam, izleme veya öneri yok

Bu uygulama reklam sistemleri, kullanıcı davranışı izleme kodu, analitik veya veri öneri mekanizmaları içermez. Kullanıcı verilerini üçüncü taraflarla paylaşmayız ve davranışa dayalı profil oluşturmayız veya içerik sunmayız.

Güvenli liman ve kullanıcı sorumluluğu

EchoShortsPlayer yalnızca video içeriğini anlamaya yardımcı olmak için tasarlanmış genel amaçlı bir teknik araçtır. Güvenli liman ilkesi uyarınca, geliştiriciler ve yayıncılar kullanıcının eriştiği, çevirdiği veya işlediği içerik için telif hakkı ihlali veya diğer yasal sorumluluk üstlenmez.

Kullanıcı, kullanımının yerel yasalara ve erişilen platformların hizmet şartlarına uygun olmasını sağlamalıdır. Telif hakkıyla korunan içeriğe erişim, platform kurallarının ihlali veya yasadışı faaliyetlerden doğan tüm yasal sorumluluk yalnızca kullanıcıya aittir.

Uygulama, kullanıcının eriştiği içeriğin yasallığına ilişkin yargıda bulunmaz veya garanti vermez ve kullanımdan kaynaklanan doğrudan veya dolaylı kayıplardan sorumluluk kabul etmez.

Amaçlanan kullanım

Uygulama, işitme engelli bireyler, dil öğrenenler veya yabancı dildeki videoları anlaması gereken kişilerin kişisel yerel kullanımı için yardımcı bir araç olarak tasarlanmıştır. Diğer tüm kullanımlar yalnızca kullanıcının sorumluluğundadır.

Teknik sınırlamalar

Uygulama, Dijital Haklar Yönetimi (DRM) ile korunmayan herkese açık video içeriğinin analizini destekler. Telif koruma protokolleri (ör. Widevine, PlayReady) nedeniyle DRM içeriğinin ses akışları çıkarılamayabilir ve altyazı oluşturulamaz.

«Fast-start» kodlanmamış MP4 dosyaları için (moov atomu dosya sonunda) çeviri başlamadan önce tam indirme gerekir. Fast-start MP4, indirme sırasında akış çevirisini destekler.

Sorumluluk reddi

Uygulama açık veya zımni hiçbir garanti olmaksızın «olduğu gibi» sunulur. Geliştirici, uygulamanın tüm ortamlarda doğru çalışacağını garanti etmez ve kullanımdan kaynaklanan kayıplar, veri kaybı veya cihaz sorunlarından sorumluluk kabul etmez. Kullanım, yukarıdaki tüm şartların kabulü anlamına gelir.

Altyazılar ve çeviriler makineyle otomatik oluşturulur ve yalnızca referans içindir. Makine çevirisinin doğruluğu, tamlığı veya uygunluğu için garanti verilmez ve bu çevirilere güvenmenin sonuçlarından sorumluluk kabul edilmez.

Politika güncellemeleri

Bu gizlilik politikası yeni sürümlerde güncellenebilir. Önemli değişiklikler uygulama güncelleme günlüğü aracılığıyla bildirilir. Kullanımın sürdürülmesi, gizlilik politikasının en son sürümünün kabulü anlamına gelir.
