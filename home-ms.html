EchoShortsPlayer

Terjemahan Video & Sari Kata AI
Strim, Terjemah, Muat Turun — Semuanya Luar Talian

EchoShortsPlayer menterjemah video dalam talian secara masa nyata semasa anda menonton — sari kata muncul semasa video dimainkan, tanpa menunggu. Muat turun video yang boleh diakses secara umum untuk tontonan luar talian. Semua pengecaman pertuturan dan terjemahan berjalan 100% secara tempatan pada peranti anda: tiada internet diperlukan, tiada akaun, tiada data keluar dari komputer anda. Menyokong 99+ bahasa, strim m3u8 dan fail MP4.

#1 Ciri-ciri

🎤

Pengecaman Pertuturan

Dikuasakan oleh OpenAI Whisper. Menyokong 99 bahasa dengan pengesanan bahasa automatik. Pelbagai saiz model dari tiny (pantas) hingga large-v3 (ketepatan tertinggi).

🌐

Terjemahan AI

Pelbagai enjin terjemahan:

  • Opus-MT — pantas, 9 bahasa
  • NLLB — 32+ bahasa, mana-mana ke mana-mana
  • Qwen — kualiti terbaik, dioptimumkan untuk CJK
📶

Pengesanan Media

Mengesan strim m3u8/HLS dan pautan video MP4 secara automatik pada mana-mana laman web. Muat turun atau terjemah dengan satu klik melalui sambungan pelayar.

⚡

Sari Kata Masa Nyata

Mod terjemahan strim: sari kata muncul secara masa nyata semasa anda menonton. Tidak perlu menunggu muat turun penuh video terlebih dahulu. Fail sari kata SRT disimpan secara tempatan untuk kegunaan masa hadapan.

🔒

100% Luar Talian & Peribadi

Semua pemprosesan berlaku secara tempatan. Tiada data dihantar ke pelayan luaran. Tiada akaun, tiada penjejakan, tiada iklan. Kandungan anda kekal pada peranti anda.

💻

Keperluan Perkakasan

GPU NVIDIA dengan VRAM 8 GB atau lebih dan pemacu CUDA dipasang. Menyokong pengecaman pertuturan dan terjemahan dipercepat GPU untuk prestasi optimum.

#2 Cara Penggunaan

📥 Install EchoShortsPlayer Required

Desktop application — the core engine for all features

EchoShortsPlayer is the desktop application that runs the AI models locally. The browser extension and CLI depend on it. Install it first before using any of the methods below.

Download EchoShortsPlayer

System requirements: Windows 10/11, NVIDIA GPU with 8 GB+ VRAM, CUDA drivers installed.

After installation, launch the application. It starts a local backend server at localhost:18632 that the extension and CLI communicate with.

🔌 Sambungan Chrome Disyorkan

Pintasan media mendalam peringkat rangkaian

Sambungan Chrome menggunakan API webRequest untuk memintas semua permintaan rangkaian di peringkat pelayar, mengesan strim m3u8/HLS, fail MP4 dan format media lain. Ia juga mengimbas DOM halaman untuk elemen video dan pautan muat turun.

Muat Turun Sambungan (.zip)

Pemasangan (mod pembangun):

  1. Muat turun zip sambungan di atas dan ekstrak ke folder.
  2. Buka Chrome dan navigasi ke chrome://extensions/.
  3. Dayakan Mod pembangun (togol kanan atas).
  4. Klik Muat yang tidak dibungkus dan pilih folder m3u8-extension.
  5. Ikon sambungan muncul di bar alat dengan lencana menunjukkan bilangan media yang dikesan.

Penggunaan:

  1. Layari mana-mana halaman dengan kandungan video.
  2. Klik ikon sambungan untuk melihat strim m3u8/MP4 yang dikesan.
  3. Klik Muat Turun untuk simpan sebagai MP4 tempatan, atau Terjemah untuk mula menjana sari kata.
  4. Tuding pada item untuk menyerlahkan elemen video yang berkaitan pada halaman.

Mengapa guna sambungan?

  • Memintas permintaan rangkaian di peringkat pelayar — menangkap strim yang terlepas dari imbasan DOM
  • Pemilihan kualiti automatik: mengumpulkan varian mengikut ID video dan memilih kualiti terbaik
  • Suntikan pengepala Referer untuk memainkan strim yang memerlukan pengesahan
  • Kaunter lencana menunjukkan bilangan media yang dikesan bagi setiap tab sepintas lalu

💻 Antara Muka Baris Perintah Pengguna Kuasa

Automasi, pemprosesan kelompok dan skrip

CLI menyediakan akses terus ke semua ciri muat turun dan terjemahan dari terminal. Direka untuk pengguna kuasa yang perlu memproses berbilang video, mengautomasi aliran kerja atau mengintegrasikan dengan alat lain.

Mengapa guna CLI?

  • Pemprosesan kelompok: terjemah ratusan video dengan satu perintah
  • Boleh diskrip: integrasikan ke dalam skrip shell, tugas cron atau saluran paip CI/CD
  • Kawalan penuh ke atas model: pilih saiz model Whisper, enjin terjemahan, mod penyahbisingan
  • Tiada beban GUI: sesuai untuk pelayan, mesin tanpa paparan atau sesi SSH jauh
  • Menyokong mod pemprosesan bersiri (jimat memori) dan selari (pantas)

Perintah yang tersedia:

# Terjemah fail video tempatan ke sari kata Cina
EchoShortsPlayer.exe --cli translate video.mp4 --target zh

# Terjemah keseluruhan folder secara kelompok
EchoShortsPlayer.exe --cli translate C:\Videos\

# Semua pilihan: bahasa sumber, model Whisper, enjin terjemahan, pengurangan hingar, mod pemprosesan
EchoShortsPlayer.exe --cli translate video.mp4 --source auto --target ja --whisper distil-large-v3 --translation qwen3-8b --denoise vocal --mode parallel

# Muat turun m3u8 atau MP4 jauh
EchoShortsPlayer.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# Muat turun dan terjemah dalam satu langkah
EchoShortsPlayer.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# Terjemah fail SRT sedia ada
EchoShortsPlayer.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

Rujukan parameter:

--source, -s      Bahasa sumber atau "auto" (lalai: auto)
--target, -t      Bahasa sasaran (lalai: zh)
--whisper, -w     tiny|base|small|medium|distil-large-v3|large-v3
--translation, -m opus-mt|nllb-distilled-600M|nllb-1.3B|nllb-3.3B|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal (lalai: off)
--mode            serial|parallel (lalai: serial)
--output, -o      Laluan fail output
--url             URL media (m3u8 / MP4)
--referer         Pengepala Referer

      
Lihat senarai penuh kod bahasa yang disokong untuk --source dan --target: Rujukan kod bahasa

#3 Dasar Privasi dan Penafian

Pemprosesan Data Tempatan

Semua ciri teras EchoShortsPlayer — termasuk pengecaman suara, penterjemahan dan muat turun media — berjalan sepenuhnya pada peranti tempatan anda, dikuasakan oleh pelayan backend tempatan (127.0.0.1:18632).

Kami tidak mengumpul, menyimpan, menghantar atau menganalisis sebarang data pengguna.

Tiada Penghantaran Data Rangkaian

Aplikasi ini tidak menghantar sebarang data pengguna ke pelayan luaran semasa penggunaan biasa.

Sambungan pelayar hanya berkomunikasi dengan backend tempatan di localhost:18632.

Tiada Iklan, Tiada Penjejakan, Tiada Cadangan

Aplikasi ini tidak mengandungi sistem pengiklanan, kod penjejakan tingkah laku pengguna, alat analitik atau mekanisme cadangan data.

Pelabuhan Selamat dan Tanggungjawab Pengguna

EchoShortsPlayer ialah alat teknikal kegunaan umum yang direka semata-mata untuk membantu pengguna memahami kandungan video. Pembangun tidak menanggung liabiliti undang-undang untuk sebarang kandungan yang diakses, diterjemah atau diproses oleh pengguna.

Pengguna mesti memastikan penggunaan mereka mematuhi undang-undang dan peraturan tempatan. Semua liabiliti undang-undang terletak pada pengguna semata-mata.

Kegunaan Yang Dimaksudkan

Aplikasi ini direka sebagai alat bantuan untuk kegunaan peribadi tempatan oleh individu kurang pendengaran, pelajar bahasa atau mereka yang perlu memahami kandungan video dalam bahasa asing.

Had Teknikal

Aplikasi ini menyokong analisis kandungan video yang boleh diakses secara awam yang tidak dilindungi oleh DRM.

Untuk fail MP4 yang tidak dikodkan fast-start, aplikasi memerlukan muat turun penuh sebelum penterjemahan boleh dimulakan.

Penafian

Aplikasi ini disediakan "seadanya" tanpa sebarang jaminan nyata atau tersirat.

Sari kata dan terjemahan dijana secara automatik oleh mesin dan hanya untuk rujukan.

Kemas Kini Dasar

Dasar privasi ini mungkin dikemas kini dengan versi baharu. Penggunaan berterusan aplikasi ini merupakan penerimaan versi terkini dasar privasi.
