#1 Features

🎤

Speech Recognition

Powered by OpenAI Whisper. Supports 99 languages with automatic language detection. Multiple model sizes from tiny (fast) to large-v3 (highest accuracy).

🌐

AI Translation

Multiple translation engines:

  • Opus-MT — fast, 9 languages
  • Qwen — best quality, CJK-optimized
📶

Media Detection

Supports 10,000+ websites and automatically detects m3u8/HLS streams and MP4 video links. Download or translate with one click via browser extension.

⚡

Real-time Subtitles

Stream translation mode: subtitles appear in real-time as you watch. No need to wait for the full video to download first. SRT subtitle files are saved locally for future use.

🔒

100% Offline & Private

All processing happens locally. No data is sent to external servers. No accounts, no tracking, no ads. Your content stays on your device.

💻

Hardware Requirements

NVIDIA GPU with 8 GB+ VRAM and CUDA drivers installed. Supports GPU-accelerated speech recognition and translation for optimal performance.

#2 How to Use

📥 Install EchoShortsPlayer Required

Desktop application — the core engine for all features

EchoShortsPlayer is the desktop application that runs the AI models locally. The browser extension and CLI depend on it. Install it first before using any of the methods below.

הורדה מ-Windows Store

System requirements: Windows 10/11, NVIDIA GPU with 8 GB+ VRAM, CUDA drivers installed.

After installation, launch the application. It starts a local backend server at localhost:18632 that the extension and CLI communicate with.

🔌 Chrome Extension (Video Sniffing) Strongly recommended

Deep network-level media interception

The Chrome extension uses the webRequest API to intercept all network requests at the browser level, detecting m3u8/HLS streams, MP4 files, and other media formats. It also scans the page DOM for video elements and download links.

Download Extension (.zip)

התקנה (מצב מפתחים):

  1. הורידו את קובץ ה-zip של התוסף למעלה וחלצו אותו לתיקייה.
  2. פתחו את Chrome ועברו ל-chrome://extensions/.
  3. הפעילו מצב מפתחים (מתג בפינה הימנית העליונה).
  4. לחצו על טעינת תוספת לא ארוזה ובחרו בתיקייה echoshorts-extension.
  5. סמל התוסף מופיע בסרגל הכלים עם תג המציג את מספר המדיה שזוהתה.

שימוש:

  1. גלשו לכל דף עם תוכן וידאו.
  2. לחצו על סמל התוסף כדי לראות זרמי m3u8/MP4 שזוהו.
  3. לחצו על הורדה לשמירה כקובץ MP4 מקומי, או על תרגום להתחלת יצירת כתוביות.
  4. לחצו על הקלטה, נגנו את הווידאו בדפדפן, בסיום לחצו על עצירה — התוספת שומרת אוטומטית את סרטוני הווידאו שצפיתם בלשונית זו.
  5. רחפו מעל פריטים כדי להדגיש את רכיב הווידאו המתאים בדף.

האם התוספת בטוחה?

  • קוד פתוח לחלוטין — ניתן לבדוק אותו. היא מתקשרת רק עם אפליקציית השולחן שלך; איננו מקבלים את היסטוריית הגלישה.
  • התוספת ו-EchoShortsPlayer אינן אוספות מידע אישי ואינן מבצעות מעקב התנהגותי או פרסומות.
  • מלבד הפעלת רישיון, פעילות הרשת המאפיינית מוגבלת לקבלת זרמי הווידאו שבחרתם.
  • ניתן לבדוק בקשות יוצאות כדי לוודא שאין העלאות בלתי צפויות מעבר להפעלה ולקבלת מדיה.

💻 Command-Line Interface Power Users

Automation, batch processing, and scripting

The CLI provides direct access to all download and translation features from the terminal. It's designed for power users who need to process multiple videos, automate workflows, or integrate with other tools.

למה להשתמש ב-CLI?

  • עיבוד אצווה: תרגום מאות סרטוני וידאו בפקודה אחת
  • בר-סקריפט: שילוב בסקריפטי shell, משימות cron או צינורות CI/CD
  • שליטה מלאה במודלים: בחירת גודל מודל Whisper, מנוע תרגום, מצב הפחתת רעש
  • ללא תקורת GUI: אידיאלי לשרתים, מכונות ללא תצוגה או חיבורי SSH מרוחקים
  • תומך גם במצב טורי (חסכוני בזיכרון) וגם במצב מקבילי (מהיר)

Available commands:

# Translate a local video file to Chinese subtitles
resources\backend\backend.exe --cli translate video.mp4 --target zh

# Batch translate an entire folder
resources\backend\backend.exe --cli translate C:\Videos\

# Full options: source language, whisper model, translation engine, denoising, processing mode
resources\backend\backend.exe --cli translate video.mp4 --source auto --target ja --whisper distil-large-v3 --translation qwen3-8b --denoise vocal --mode parallel

# Download a remote m3u8 or MP4
resources\backend\backend.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# Download and translate in one step
resources\backend\backend.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# Translate an existing SRT file
resources\backend\backend.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

הפניית פרמטרים:

--source, -s      Source language or "auto" (default: auto)
--target, -t      Target language (default: zh)
--whisper, -w     tiny|base|small|medium|distil-large-v3|large-v3
--translation, -m opus-mt|nllb-distilled-600M|nllb-1.3B|nllb-3.3B|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal (default: off)
--mode            serial|parallel (default: serial)
--output, -o      Output file path
--url             Media URL (m3u8 / MP4)
--referer         Referer header

ראו את הרשימה המלאה של קודי שפה נתמכים עבור --source ו---target: מדריך קודי שפה

לתמיכה טכנית נא לפנות ל-supports@echoshorts.win.

#3 מדיניות פרטיות וכתב ויתור

עיבוד נתונים מקומי

כל התכונות המרכזיות של EchoShortsPlayer — כולל זיהוי דיבור, תרגום והורדת מדיה — פועלות במלואן במכשיר המקומי שלך באמצעות שרת backend מקומי (127.0.0.1:18632).

איננו אוספים, שומרים, מעבירים או מנתחים נתוני משתמש, לרבות אך לא רק: תוכן וידאו שצפית בו, טקסט כתוביות מזוהה, תוצאות תרגום, היסטוריית גלישה או מידע אישי כלשהו.

ללא העברת נתונים ברשת

היישום אינו שולח נתוני משתמש לשרתים חיצוניים בשימוש רגיל. כל עיבוד השמע ותרגום הטקסט מתבצעים במקומי. מודלי AI מורדים ממקורות ציבוריים (HuggingFace) בשימוש הראשון ולאחר מכן יכולים לפעול במלואם לא מקוון.

ההרחבה לדפדפן מתקשרת רק עם ה-backend המקומי ב-localhost:18632. לא מועברים נתונים לשרתים מרוחקים המופעלים על ידי המפתחים.

ללא פרסומות, מעקב או המלצות

יישום זה אינו מכיל מערכות פרסום, קוד מעקב אחר התנהגות משתמש, אנליטיקה או מנגנוני המלצת נתונים. איננו משתפים נתוני משתמש עם צדדים שלישיים ואיננו יוצרים פרופילים או דוחפים תוכן על בסיס התנהגות.

נמל בטוח ואחריות המשתמש

EchoShortsPlayer הוא כלי טכני כללי שנועד אך ורק לסייע בהבנת תוכן וידאו. לפי עקרון הנמל הבטוח, המפתחים והמפרסמים אינם נושאים באחריות משפטית להפרת זכויות יוצרים או אחרת בנוגע לתוכן שאליו המשתמש ניגש, מתרגם או מעבד.

על המשתמש להבטיח שהשימוש עומד בחוקים המקומיים ובתנאי השירות של הפלטפורמות. כל האחריות המשפטית הנובעת מגישה לתוכן מוגן בזכויות יוצרים, הפרת כללי פלטפורמה או פעילות בלתי חוקית מוטלת על המשתמש בלבד.

היישום אינו שופט או מבטיח את חוקיות התוכן שאליו ניגש המשתמש ואינו מקבל אחריות לכל הפסד ישיר או עקיף הנובע משימושו.

שימוש מיועד

היישום תוכנן ככלי עזר לשימוש אישי מקומי על ידי אנשים עם לקות שמיעה, לומדי שפות או מי שצריך להבין סרטונים בשפות זרות. כל שימוש אחר הוא באחריות המשתמש בלבד.

מגבלות טכניות

היישום תומך בניתוח תוכן וידאו נגיש לציבור שאינו מוגן בניהול זכויות דיגיטלי (DRM). בגלל פרוטוקולי הגנה (כגון Widevine, PlayReady), ייתכן שלא ניתן לחלץ זרמי אודיו מתוכן עם DRM, מה שמונע יצירת כתוביות.

עבור קבצי MP4 שאינם מקודדים «fast-start» (אטום moov בסוף הקובץ), נדרשת הורדה מלאה לפני תחילת התרגום. MP4 fast-start תומכים בתרגום זרם במהלך ההורדה.

כתב ויתור

היישום מסופק «כפי שהוא» ללא כל אחריות מפורשת או משתמעת. המפתח אינו מבטיח פעולה נכונה בכל הסביבות ואינו מקבל אחריות לכל הפסד, אובדן נתונים או בעיות במכשיר שנגרמו מהשימוש. השימוש מהווה הסכמה לכל התנאים לעיל.

כתוביות ותרגומים נוצרים אוטומטית על ידי מכונה ומהווים התייחסות בלבד. אין אחריות לדיוק, שלמות או התאמה של תוכן מתורגם אוטומטית ואין קבלת אחריות לכל השלכות של הסתמכות על תרגומים אלה.

עדכוני מדיניות

מדיניות פרטיות זו עשויה להתעדכן בגרסאות חדשות. שינויים מהותיים יועברו דרך יומן העדכונים של היישום. המשך שימוש מהווה הסכמה לגרסה העדכנית ביותר של מדיניות הפרטיות.
