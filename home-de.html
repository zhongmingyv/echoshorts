EchoShorts

Video-Untertitel, sofortige Übersetzung
Vollständig offline, Datenschutz zuerst

EchoShorts führt alle Spracherkennung und Übersetzung lokal auf Ihrem Gerät durch — kein Internet, kein Konto, Ihre Daten verlassen niemals Ihren Computer. Geben Sie eine URL in die Adressleiste ein, um zu beginnen.

🎙️

Whisper Spracherkennung

Basierend auf OpenAI Whisper, unterstützt Transkription in 99 Sprachen, läuft lokal, keine API erforderlich.

🔍

OCR Untertitelerkennung

Verwendet PaddleOCR zur Erkennung eingebetteter Untertitel in Videoframes, unterstützt Chinesisch, Englisch, Japanisch, Koreanisch und mehr.

🌐

Offline-Übersetzungsmotor

Basierend auf Helsinki-NLP OPUS-MT, unterstützt mehrsprachige Übersetzung, vollständig offline, keine Daten hochgeladen.

Alt + S

Drücken Sie die Tastenkombination auf einer beliebigen Videoseite, um das Untertitelpanel ein- oder auszublenden. Sie können auch auf die Schaltfläche Sub in der Symbolleiste klicken.

Datenschutzrichtlinie & Haftungsausschluss

Lokale Datenverarbeitung

Alle Kernfunktionen von EchoShorts — einschließlich Spracherkennung, OCR und Übersetzung — laufen auf Ihrem lokalen Gerät, unterstützt durch einen lokalen Server (127.0.0.1:8765).

Wir sammeln, speichern, übertragen oder analysieren keine Benutzerdaten, einschließlich: Videoinhalte, Untertiteltexte, Übersetzungsergebnisse, Browserverlauf oder persönliche Informationen.

Keine Netzwerkdatenübertragung

Diese Anwendung sendet bei normaler Nutzung keine Daten an externe Server. Die gesamte Audioverarbeitung, Bilderkennung und Textübersetzung erfolgt lokal. KI-Modelle werden beim ersten Gebrauch aus öffentlichen Quellen heruntergeladen und können danach offline ausgeführt werden.

Keine Werbung, kein Tracking, keine Empfehlungen

Diese Anwendung enthält keine Werbsysteme, Benutzerverhaltensverfolgungscode oder Datenempfehlungsmechanismen. Wir teilen keine Benutzerdaten mit Dritten.

Technische Einschränkungen

Diese Anwendung verwendet Echtzeit-Audiostream-Erkennungstechnologie und unterstützt nur die Analyse öffentlich zugänglicher Videoinhalte, die nicht durch Digital Rights Management (DRM) geschützt sind. Aufgrund der Einschränkungen durch Urheberrechtsschutzprotokolle (wie Widevine, PlayReady usw.) können Audiostreams von DRM-geschützten HD-Inhalten oder eingeschränkten Plattformvideos möglicherweise nicht extrahiert werden, was die Echtzeit-Untertitelgenerierung verhindert. Wenn Sie bei der Wiedergabe von Videos im Standardformat auf Probleme bei der Untertitelgenerierung stoßen, senden Sie uns bitte die Video-URL per E-Mail und wir werden die Kompatibilität unserer Erkennungs-Engine kontinuierlich verbessern.
