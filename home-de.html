EchoShortsPlayer

KI-Videoübersetzung & Untertitel
Streamen, Übersetzen, Herunterladen — Alles Offline

EchoShortsPlayer übersetzt Online-Videos in Echtzeit während Sie schauen — Untertitel erscheinen während der Wiedergabe, ohne Wartezeit. Laden Sie öffentlich zugängliche Videos für die Offline-Wiedergabe herunter. Die gesamte Spracherkennung und Übersetzung läuft zu 100% lokal auf Ihrem Gerät: kein Internet nötig, keine Konten, keine Daten verlassen Ihren Computer. Unterstützt über 99 Sprachen, m3u8-Streams und MP4-Dateien.

#1 Funktionen

🎤

Spracherkennung

Basierend auf OpenAI Whisper. Unterstützt 99 Sprachen mit automatischer Spracherkennung. Mehrere Modellgrößen von tiny (schnell) bis large-v3 (höchste Genauigkeit).

🌐

KI-Übersetzung

Mehrere Übersetzungsmotoren:

  • Opus-MT — schnell, 9 Sprachen
  • NLLB — 32+ Sprachen, beliebige Kombinationen
  • Qwen — beste Qualität, CJK-optimiert
📶

Medienerkennung

Erkennt automatisch m3u8/HLS-Streams und MP4-Videolinks auf jeder Webseite. Mit einem Klick herunterladen oder übersetzen über die Browser-Erweiterung.

⚡

Echtzeit-Untertitel

Stream-Übersetzungsmodus: Untertitel erscheinen in Echtzeit während Sie schauen. Kein Warten auf den vollständigen Video-Download nötig. SRT-Untertiteldateien werden lokal für die zukünftige Verwendung gespeichert.

🔒

100% Offline & Privat

Die gesamte Verarbeitung erfolgt lokal. Keine Daten werden an externe Server gesendet. Keine Konten, kein Tracking, keine Werbung. Ihre Inhalte bleiben auf Ihrem Gerät.

💻

Hardwareanforderungen

NVIDIA GPU mit 8 GB oder mehr VRAM und installierte CUDA-Treiber. Unterstützt GPU-beschleunigte Spracherkennung und Übersetzung für optimale Leistung.

#2 Anleitung

📥 Install EchoShortsPlayer Required

Desktop application — the core engine for all features

EchoShortsPlayer is the desktop application that runs the AI models locally. The browser extension and CLI depend on it. Install it first before using any of the methods below.

Download EchoShortsPlayer

System requirements: Windows 10/11, NVIDIA GPU with 8 GB+ VRAM, CUDA drivers installed.

After installation, launch the application. It starts a local backend server at localhost:18632 that the extension and CLI communicate with.

🔌 Chrome-Erweiterung Empfohlen

Tiefgreifende Medienabfangung auf Netzwerkebene

Die Chrome-Erweiterung verwendet die webRequest-API, um alle Netzwerkanfragen auf Browserebene abzufangen und m3u8/HLS-Streams, MP4-Dateien und andere Medienformate zu erkennen. Sie scannt auch das Seiten-DOM nach Videoelementen und Download-Links.

Erweiterung Herunterladen (.zip)

Installation (Entwicklermodus):

  1. Laden Sie die Erweiterungs-ZIP oben herunter und entpacken Sie sie in einen Ordner.
  2. Öffnen Sie Chrome und navigieren Sie zu chrome://extensions/.
  3. Aktivieren Sie den Entwicklermodus (Schalter oben rechts).
  4. Klicken Sie auf Entpackte Erweiterung laden und wählen Sie den Ordner m3u8-extension.
  5. Das Erweiterungssymbol erscheint in der Symbolleiste mit einem Badge, das die Anzahl erkannter Medien anzeigt.

Verwendung:

  1. Navigieren Sie zu einer Seite mit Videoinhalten.
  2. Klicken Sie auf das Erweiterungssymbol, um erkannte m3u8/MP4-Streams anzuzeigen.
  3. Klicken Sie auf Herunterladen, um als lokale MP4 zu speichern, oder Übersetzen, um die Untertitelgenerierung zu starten.
  4. Fahren Sie mit der Maus über Einträge, um das entsprechende Videoelement auf der Seite hervorzuheben.

Warum die Erweiterung verwenden?

  • Fängt Netzwerkanfragen auf Browserebene ab — erfasst Streams, die DOM-Scanning übersieht
  • Automatische Qualitätsauswahl: gruppiert Varianten nach Video-ID und wählt die beste Qualität
  • Referer-Header-Injektion für Streams, die Authentifizierung erfordern
  • Badge-Zähler zeigt die Anzahl erkannter Medien pro Tab auf einen Blick

💻 Kommandozeile Fortgeschrittene

Automatisierung, Stapelverarbeitung und Skripting

Die CLI bietet direkten Zugriff auf alle Download- und Übersetzungsfunktionen vom Terminal aus. Sie ist für fortgeschrittene Benutzer konzipiert, die mehrere Videos verarbeiten, Arbeitsabläufe automatisieren oder mit anderen Tools integrieren müssen.

Warum die CLI verwenden?

  • Stapelverarbeitung: Hunderte von Videos mit einem einzigen Befehl übersetzen
  • Skriptfähig: Integration in Shell-Skripte, Cron-Jobs oder CI/CD-Pipelines
  • Volle Kontrolle über Modelle: Whisper-Modellgröße, Übersetzungsmotor, Rauschunterdrückungsmodus wählen
  • Kein GUI-Overhead: ideal für Server, Headless-Maschinen oder Remote-SSH-Sitzungen
  • Unterstützt sowohl seriellen (speichereffizient) als auch parallelen (schnell) Verarbeitungsmodus

Verfügbare Befehle:

# Eine lokale Videodatei in chinesische Untertitel übersetzen
resources\backend\backend.exe --cli translate video.mp4 --target zh

# Einen ganzen Ordner stapelweise übersetzen
resources\backend\backend.exe --cli translate C:\Videos\

# Alle Optionen: Quellsprache, Whisper-Modell, Übersetzungsengine, Rauschunterdrückung, Verarbeitungsmodus
resources\backend\backend.exe --cli translate video.mp4 --source auto --target ja --whisper distil-large-v3 --translation qwen3-8b --denoise vocal --mode parallel

# Eine entfernte m3u8- oder MP4-Datei herunterladen
resources\backend\backend.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# In einem Schritt herunterladen und übersetzen
resources\backend\backend.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# Eine vorhandene SRT-Datei übersetzen
resources\backend\backend.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

Parameterreferenz:

--source, -s      Quellsprache oder "auto" (Standard: auto)
--target, -t      Zielsprache (Standard: zh)
--whisper, -w     tiny|base|small|medium|distil-large-v3|large-v3
--translation, -m opus-mt|nllb-distilled-600M|nllb-1.3B|nllb-3.3B|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal (Standard: off)
--mode            serial|parallel (Standard: serial)
--output, -o      Ausgabedateipfad
--url             Medien-URL (m3u8 / MP4)
--referer         Referer-Header

      
Vollständige Liste der unterstützten Sprachcodes für --source und --target: Sprachcode-Referenz
