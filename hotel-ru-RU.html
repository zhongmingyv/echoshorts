Стандартные Аккаунты и Права Доступа

admin (123456)

Главный администратор. Высшие права доступа (меню, отделы, права).

boss (123456)

Владелец отеля. Все права, кроме добавления системных меню.

manager (123456)

Менеджер отеля. Все деловые права. Может добавлять пользователей только в свой отдел.

receptionist (123456)

Стойка регистрации. Только права на регистрацию и бронирование.

⚠️ Важное уведомление при первом входе

После первого входа admin немедленно измените пароли для всех стандартных аккаунтов и надежно запомните пароль admin!

  • Регулярное Копирование: Часто заходите на страницу "Резервное копирование и импорт" для создания резервных копий.
