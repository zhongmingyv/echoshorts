Transmita, Traduza, Baixe — Tudo Offline

O EchoShortsPlayer traduz vídeos online em tempo real enquanto você assiste — as legendas aparecem conforme o vídeo é reproduzido, sem espera. Baixe vídeos publicamente acessíveis para visualização offline. Todo o reconhecimento de fala e tradução funciona 100% localmente no seu dispositivo: sem necessidade de internet, sem contas, nenhum dado sai do seu computador. #2 Como Usar

📥 Instalar EchoShortsPlayer Obrigatório

Aplicativo de desktop — o motor central de todos os recursos

O EchoShortsPlayer é o aplicativo de desktop que executa os modelos de IA localmente. A extensão do navegador e o CLI dependem dele. Instale-o primeiro antes de usar qualquer um dos métodos abaixo.

Baixar EchoShortsPlayer

Requisitos do sistema: Windows 10/11, GPU NVIDIA com 8 GB ou mais de VRAM, drivers CUDA instalados.

Após a instalação, inicie o aplicativo. Ele inicia um servidor backend local em localhost:18632 com o qual a extensão e o CLI se comunicam.

🔌 Extensão para Chrome Recomendado

Interceptação profunda de mídia a nível de rede

A extensão do Chrome usa a API webRequest para interceptar todas as requisições de rede no nível do navegador, detectando streams m3u8/HLS, arquivos MP4 e outros formatos de mídia. Também escaneia o DOM da página em busca de elementos de vídeo e links de download.

Baixar Extensão (.zip)

Instalação (modo desenvolvedor):

  1. Baixe o zip da extensão acima e extraia em uma pasta.
  2. Abra o Chrome e navegue até chrome://extensions/.
  3. Ative o Modo desenvolvedor (botão no canto superior direito).
  4. Clique em Carregar sem compactação e selecione a pasta m3u8-extension.
  5. O ícone da extensão aparece na barra de ferramentas com um badge mostrando a quantidade de mídia detectada.

Como usar:

  1. Navegue até qualquer página com conteúdo de vídeo.
  2. Clique no ícone da extensão para ver os streams m3u8/MP4 detectados.
  3. Clique em Baixar para salvar como MP4 local, ou Traduzir para iniciar a geração de legendas.
  4. Passe o mouse sobre os itens para destacar o elemento de vídeo correspondente na página.

Por que usar a extensão?

  • Intercepts network requests at the browser level — catches streams that DOM scanning misses
  • Automatic quality selection: groups variants by video ID and picks the best quality
  • Referer header injection for playing streams that require authentication
  • Badge counter shows detected media count per tab at a glance

💻 Interface de Linha de Comando Usuários Avançados

Automação, processamento em lote e scripts

O CLI oferece acesso direto a todos os recursos de download e tradução pelo terminal. Projetado para usuários avançados que precisam processar múltiplos vídeos, automatizar fluxos de trabalho ou integrar com outras ferramentas.

Por que usar o CLI?

  • Batch processing: translate hundreds of videos with a single command
  • Scriptable: integrate into shell scripts, cron jobs, or CI/CD pipelines
  • Full control over models: choose Whisper model size, translation engine, denoising mode
  • No GUI overhead: ideal for servers, headless machines, or remote SSH sessions
  • Supports both serial (memory-efficient) and parallel (fast) processing modes

Comandos disponíveis:

# Traduzir um arquivo de vídeo local para legendas em chinês
resources\backend\backend.exe --cli translate video.mp4 --target zh

# Traduzir uma pasta inteira em lote
resources\backend\backend.exe --cli translate C:\Videos\

# Todas as opções: idioma de origem, modelo Whisper, motor de tradução, redução de ruído, modo de processamento
resources\backend\backend.exe --cli translate video.mp4 --source auto --target ja --whisper distil-large-v3 --translation qwen3-8b --denoise vocal --mode parallel

# Baixar um m3u8 ou MP4 remoto
resources\backend\backend.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# Baixar e traduzir em uma única etapa
resources\backend\backend.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# Traduzir um arquivo SRT existente
resources\backend\backend.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

Parameter reference:

--source, -s      Idioma de origem ou "auto" (padrão: auto)
--target, -t      Idioma de destino (padrão: zh)
--whisper, -w     tiny|base|small|medium|distil-large-v3|large-v3
--translation, -m opus-mt|nllb-distilled-600M|nllb-1.3B|nllb-3.3B|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal (padrão: off)
--mode            serial|parallel (padrão: serial)
--output, -o      Caminho do arquivo de saída
--url             URL de mídia (m3u8 / MP4)
--referer         Cabeçalho Referer
