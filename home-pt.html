EchoShortsPlayer

Tradução de Vídeo & Legendas com IA
Transmita, Traduza, Baixe — Tudo Offline

O EchoShortsPlayer traduz vídeos online em tempo real enquanto você assiste — as legendas aparecem conforme o vídeo é reproduzido, sem espera. Baixe vídeos publicamente acessíveis para visualização offline. Todo o reconhecimento de fala e tradução funciona 100% localmente no seu dispositivo: sem necessidade de internet, sem contas, nenhum dado sai do seu computador. Suporta mais de 99 idiomas, streams m3u8 e arquivos MP4.

#1 Recursos

🎤

Reconhecimento de Fala

Desenvolvido com OpenAI Whisper. Suporta 99 idiomas com detecção automática de idioma. Vários tamanhos de modelo, de tiny (rápido) a large-v3 (maior precisão).

🌐

Tradução com IA

Múltiplos mecanismos de tradução:

  • Opus-MT — rápido, 9 idiomas
  • NLLB — 32+ idiomas, qualquer para qualquer
  • Qwen — melhor qualidade, otimizado para CJK
📶

Detecção de Mídia

Detecta automaticamente streams m3u8/HLS e links de vídeo MP4 em qualquer página web. Baixe ou traduza com um clique via extensão do navegador.

⚡

Legendas em Tempo Real

Modo de tradução em streaming: as legendas aparecem em tempo real enquanto você assiste. Não é necessário esperar o download completo do vídeo. Os arquivos de legenda SRT são salvos localmente para uso futuro.

🔒

100% Offline & Privado

Todo o processamento acontece localmente. Nenhum dado é enviado a servidores externos. Sem contas, sem rastreamento, sem anúncios. Seu conteúdo permanece no seu dispositivo.

💻

Requisitos de Hardware

GPU NVIDIA com 8 GB ou mais de VRAM e drivers CUDA instalados. Suporta reconhecimento de fala e tradução acelerados por GPU para desempenho ideal.

#2 Como Usar

📥 Install EchoShortsPlayer Required

Desktop application — the core engine for all features

EchoShortsPlayer is the desktop application that runs the AI models locally. The browser extension and CLI depend on it. Install it first before using any of the methods below.

Download EchoShortsPlayer

System requirements: Windows 10/11, NVIDIA GPU with 8 GB+ VRAM, CUDA drivers installed.

After installation, launch the application. It starts a local backend server at localhost:18632 that the extension and CLI communicate with.

🔌 Extensão para Chrome Recomendado

Interceptação profunda de mídia a nível de rede

A extensão do Chrome usa a API webRequest para interceptar todas as requisições de rede no nível do navegador, detectando streams m3u8/HLS, arquivos MP4 e outros formatos de mídia. Também escaneia o DOM da página em busca de elementos de vídeo e links de download.

Baixar Extensão (.zip)

Instalação (modo desenvolvedor):

  1. Baixe o zip da extensão acima e extraia em uma pasta.
  2. Abra o Chrome e navegue até chrome://extensions/.
  3. Ative o Modo desenvolvedor (botão no canto superior direito).
  4. Clique em Carregar sem compactação e selecione a pasta m3u8-extension.
  5. O ícone da extensão aparece na barra de ferramentas com um badge mostrando a quantidade de mídia detectada.

Como usar:

  1. Navegue até qualquer página com conteúdo de vídeo.
  2. Clique no ícone da extensão para ver os streams m3u8/MP4 detectados.
  3. Clique em Baixar para salvar como MP4 local, ou Traduzir para iniciar a geração de legendas.
  4. Passe o mouse sobre os itens para destacar o elemento de vídeo correspondente na página.

Por que usar a extensão?

  • Intercepta requisições de rede no nível do navegador — captura streams que a varredura do DOM não detecta
  • Seleção automática de qualidade: agrupa variantes por ID de vídeo e escolhe a melhor qualidade
  • Injeção de cabeçalho Referer para reproduzir streams que exigem autenticação
  • Contador no badge mostra a quantidade de mídia detectada por aba de forma rápida

💻 Interface de Linha de Comando Usuários Avançados

Automação, processamento em lote e scripts

O CLI oferece acesso direto a todos os recursos de download e tradução pelo terminal. Projetado para usuários avançados que precisam processar múltiplos vídeos, automatizar fluxos de trabalho ou integrar com outras ferramentas.

Por que usar o CLI?

  • Processamento em lote: traduza centenas de vídeos com um único comando
  • Scriptável: integre em scripts shell, cron jobs ou pipelines CI/CD
  • Controle total sobre modelos: escolha o tamanho do modelo Whisper, mecanismo de tradução e modo de redução de ruído
  • Sem sobrecarga de interface gráfica: ideal para servidores, máquinas headless ou sessões SSH remotas
  • Suporta modos de processamento serial (econômico em memória) e paralelo (rápido)

Comandos disponíveis:

# Traduzir um arquivo de vídeo local para legendas em chinês
EchoShortsPlayer.exe --cli translate video.mp4 --target zh

# Traduzir uma pasta inteira em lote
EchoShortsPlayer.exe --cli translate C:\Videos\

# Todas as opções: idioma de origem, modelo Whisper, motor de tradução, redução de ruído, modo de processamento
EchoShortsPlayer.exe --cli translate video.mp4 --source auto --target ja --whisper distil-large-v3 --translation qwen3-8b --denoise vocal --mode parallel

# Baixar um m3u8 ou MP4 remoto
EchoShortsPlayer.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# Baixar e traduzir em uma única etapa
EchoShortsPlayer.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# Traduzir um arquivo SRT existente
EchoShortsPlayer.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

Referência de parâmetros:

--source, -s      Idioma de origem ou "auto" (padrão: auto)
--target, -t      Idioma de destino (padrão: zh)
--whisper, -w     tiny|base|small|medium|distil-large-v3|large-v3
--translation, -m opus-mt|nllb-distilled-600M|nllb-1.3B|nllb-3.3B|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal (padrão: off)
--mode            serial|parallel (padrão: serial)
--output, -o      Caminho do arquivo de saída
--url             URL de mídia (m3u8 / MP4)
--referer         Cabeçalho Referer

      
Veja a lista completa de códigos de idioma suportados para --source e --target: Referência de códigos de idioma

Todos os recursos principais do EchoShortsPlayer — incluindo reconhecimento de fala, tradução e download de mídia — são executados inteiramente no seu dispositivo local, alimentados por um servidor backend local (127.0.0.1:18632).
