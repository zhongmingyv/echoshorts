EchoShortsPlayer

AI Video Translation & Subtitles
Stream, Translate, Download — All Offline

EchoShortsPlayer translates online videos in real-time while you watch — subtitles appear as the video plays, no waiting. Download publicly accessible videos for offline viewing. All speech recognition and translation run 100% locally on your device: no internet needed, no accounts, no data leaves your computer. Supports 99+ languages, m3u8 streams and MP4 files.

#2 How to Use

📥 Install EchoShortsPlayer Required

Desktop application — the core engine for all features

EchoShortsPlayer is the desktop application that runs the AI models locally. The browser extension and CLI depend on it. Install it first before using any of the methods below.

Download EchoShortsPlayer

System requirements: Windows 10/11, NVIDIA GPU with 8 GB+ VRAM, CUDA drivers installed.

After installation, launch the application. It starts a local backend server at localhost:18632 that the extension and CLI communicate with.

🔌 Chrome Extension Recommended

Deep network-level media interception

The Chrome extension uses the webRequest API to intercept all network requests at the browser level, detecting m3u8/HLS streams, MP4 files, and other media formats. It also scans the page DOM for video elements and download links.

Download Extension (.zip)

Instalasi (mode pengembang):

  1. Unduh zip ekstensi di atas dan ekstrak ke sebuah folder.
  2. Buka Chrome dan buka chrome://extensions/.
  3. Aktifkan Mode pengembang (tombol di kanan atas).
  4. Klik Muat yang tidak dibungkus dan pilih folder m3u8-extension.
  5. Ikon ekstensi muncul di bilah alat dengan lencana yang menampilkan jumlah media terdeteksi.

Cara penggunaan:

  1. Buka halaman apa pun yang berisi video.
  2. Klik ikon ekstensi untuk melihat aliran m3u8/MP4 yang terdeteksi.
  3. Klik Unduh untuk menyimpan sebagai MP4 lokal, atau Terjemahkan untuk memulai pembuatan subtitle.
  4. Arahkan kursor ke item untuk menyoroti elemen video yang sesuai di halaman.

Mengapa menggunakan ekstensi?

  • Mencegat permintaan jaringan di tingkat peramban — menangkap aliran yang terlewat oleh pemindaian DOM
  • Pemilihan kualitas otomatis: mengelompokkan varian berdasarkan ID video dan memilih kualitas terbaik
  • Penyisipan header Referer untuk memutar aliran yang memerlukan autentikasi
  • Penghitung lencana menampilkan jumlah media terdeteksi per tab sekilas

💻 Command-Line Interface Power Users

Automation, batch processing, and scripting

The CLI provides direct access to all download and translation features from the terminal. It's designed for power users who need to process multiple videos, automate workflows, or integrate with other tools.

Mengapa menggunakan CLI?

  • Pemrosesan batch: terjemahkan ratusan video dengan satu perintah
  • Dapat di-skrip: integrasikan ke skrip shell, tugas cron, atau pipeline CI/CD
  • Kontrol penuh atas model: pilih ukuran model Whisper, mesin terjemahan, mode reduksi derau
  • Tanpa overhead GUI: ideal untuk server, mesin headless, atau sesi SSH jarak jauh
  • Mendukung mode pemrosesan serial (hemat memori) dan paralel (cepat)

Available commands:

# Translate a local video file to Chinese subtitles
resources\backend\backend.exe --cli translate video.mp4 --target zh

# Batch translate an entire folder
resources\backend\backend.exe --cli translate C:\Videos\

# Full options: source language, whisper model, translation engine, denoising, processing mode
resources\backend\backend.exe --cli translate video.mp4 --source auto --target ja --whisper distil-large-v3 --translation qwen3-8b --denoise vocal --mode parallel

# Download a remote m3u8 or MP4
resources\backend\backend.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# Download and translate in one step
resources\backend\backend.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# Translate an existing SRT file
resources\backend\backend.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

Referensi parameter:

--source, -s      Source language or "auto" (default: auto)
--target, -t      Target language (default: zh)
--whisper, -w     tiny|base|small|medium|distil-large-v3|large-v3
--translation, -m opus-mt|nllb-distilled-600M|nllb-1.3B|nllb-3.3B|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal (default: off)
--mode            serial|parallel (default: serial)
--output, -o      Output file path
--url             Media URL (m3u8 / MP4)
--referer         Referer header

Lihat daftar lengkap kode bahasa yang didukung untuk --source dan --target: Referensi kode bahasa

Untuk dukungan teknis, hubungi supports@echoshorts.win.

#3 Kebijakan privasi penyangkalan

Pemrosesan data lokal

Semua fitur inti EchoShortsPlayer — termasuk pengenalan ucapan, terjemahan, dan unduhan media — berjalan sepenuhnya di perangkat lokal Anda, didukung oleh server backend lokal (127.0.0.1:18632).

Kami tidak mengumpulkan, menyimpan, mengirim, atau menganalisis data pengguna apa pun, termasuk namun tidak terbatas pada: konten video yang Anda tonton, teks subtitle yang dikenali, hasil terjemahan, riwayat penjelajahan, atau informasi pribadi apa pun.

Tidak ada transmisi data jaringan

Aplikasi ini tidak mengirim data pengguna ke server eksternal selama penggunaan normal. Semua pemrosesan audio dan terjemahan teks diselesaikan secara lokal. Model AI diunduh dari sumber publik (HuggingFace) pada penggunaan pertama dan dapat berjalan sepenuhnya offline setelahnya.

Ekstensi browser hanya berkomunikasi dengan backend lokal di localhost:18632. Tidak ada data yang dikirim ke server jarak jauh yang dioperasikan oleh pengembang.

Tanpa iklan, pelacakan, atau rekomendasi

Aplikasi ini tidak berisi sistem iklan, kode pelacakan perilaku pengguna, analitik, atau mekanisme rekomendasi data. Kami tidak membagikan data pengguna kepada pihak ketiga dan tidak membuat profil atau mendorong konten berdasarkan perilaku pengguna.

Pelabuhan aman dan tanggung jawab pengguna

EchoShortsPlayer adalah alat teknis tujuan umum yang dirancang semata-mata untuk membantu memahami konten video. Berdasarkan doktrin pelabuhan aman, pengembang dan penerbit tidak memikul tanggung jawab hukum atas pelanggaran hak cipta atau lainnya terkait konten yang diakses, diterjemahkan, atau diproses oleh pengguna.

Pengguna harus memastikan penggunaan mematuhi hukum setempat dan ketentuan layanan platform yang diakses. Semua tanggung jawab hukum yang timbul dari mengakses konten berhak cipta, melanggar aturan platform, atau aktivitas ilegal sepenuhnya menjadi tanggung jawab pengguna.

Aplikasi ini tidak menilai atau menjamin legalitas konten yang diakses pengguna dan tidak bertanggung jawab atas kerugian langsung atau tidak langsung yang timbul dari penggunaannya.

Penggunaan yang dimaksudkan

Aplikasi ini dirancang sebagai alat bantu untuk penggunaan pribadi lokal oleh individu dengan gangguan pendengaran, pelajar bahasa, atau mereka yang perlu memahami video dalam bahasa asing. Penggunaan lain sepenuhnya menjadi tanggung jawab pengguna.

Keterbatasan teknis

Aplikasi ini mendukung analisis konten video yang dapat diakses publik dan tidak dilindungi oleh Manajemen Hak Digital (DRM). Karena protokol perlindungan (misalnya Widevine, PlayReady), aliran audio dari konten DRM mungkin tidak dapat diekstraksi, sehingga subtitle tidak dapat dibuat.

Untuk file MP4 yang tidak dikodekan «fast-start» (atom moov di akhir file), aplikasi memerlukan unduhan lengkap sebelum terjemahan dimulai. MP4 fast-start mendukung terjemahan streaming saat mengunduh.

Penyangkalan

Aplikasi ini disediakan «apa adanya» tanpa jaminan tersurat atau tersirat. Pengembang tidak menjamin aplikasi ini berfungsi dengan benar di semua lingkungan dan tidak bertanggung jawab atas kerugian, kehilangan data, atau masalah perangkat yang disebabkan oleh penggunaannya. Penggunaan berarti penerimaan semua ketentuan di atas.

Subtitle dan terjemahan dibuat secara otomatis oleh mesin dan hanya untuk referensi. Tidak ada jaminan mengenai keakuratan, kelengkapan, atau kesesuaian konten yang diterjemahkan mesin, dan tidak ada tanggung jawab atas konsekuensi mengandalkan terjemahan tersebut.

Pembaruan kebijakan

Kebijakan privasi ini dapat diperbarui dalam versi baru. Perubahan penting akan dikomunikasikan melalui log pembaruan aplikasi. Penggunaan berkelanjutan merupakan penerimaan versi terbaru kebijakan privasi.
