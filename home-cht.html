EchoShortsPlayer

AI 影片翻譯與字幕
邊播邊譯、下載、全程離線

EchoShortsPlayer 支援線上影片邊播放邊即時翻譯——字幕隨影片同步顯示，無需等待。可下載公開可存取的影片供離線觀看。所有語音辨識和翻譯 100% 在本機裝置執行：無需網路、無需帳號、資料絕不離開您的電腦。支援 99+ 種語言、m3u8 串流和 MP4 檔案。

#1 功能特性

🎤

語音辨識

基於 OpenAI Whisper。支援 99 種語言，自動語言偵測。多種模型大小可選，從 tiny（快速）到 large-v3（最高精度）。

🌐

AI 翻譯

多種翻譯引擎：

  • Opus-MT — 快速，9 種語言
  • NLLB — 32+ 種語言，任意互譯
  • Qwen — 最高品質，CJK 最佳化
📶

媒體偵測

自動偵測網頁上的 m3u8/HLS 串流和 MP4 影片連結。透過瀏覽器擴充功能一鍵下載或翻譯。

⚡

即時字幕

串流翻譯模式：字幕在觀看時即時顯示。無需等待整部影片下載完成。SRT 字幕檔案儲存在本機供後續使用。

🔒

100% 離線 & 隱私

所有處理都在本機完成。不向外部伺服器傳送任何資料。無需帳號、無追蹤、無廣告。您的內容留在您的裝置上。

💻

硬體需求

NVIDIA 顯示卡，8 GB+ 視訊記憶體，並安裝 CUDA 驅動程式。支援 GPU 加速的語音辨識和翻譯，獲得最佳效能。

#2 使用方式

📥 安裝 EchoShortsPlayer 必需

桌面應用——所有功能的核心引擎

EchoShortsPlayer 是在本機執行 AI 模型的桌面應用。瀏覽器擴充功能和 CLI 都依賴它。請先安裝後再使用下列任何方式。

下載 EchoShortsPlayer

系統需求：Windows 10/11，NVIDIA 顯示卡 8 GB+ 視訊記憶體，已安裝 CUDA 驅動程式。

安裝後啟動應用。它會在 localhost:18632 啟動本機後端伺服器，擴充功能和 CLI 都透過它通訊。

🔌 Chrome 擴充功能 推薦

深度網路級媒體攔截

Chrome 擴充功能使用 webRequest API 在瀏覽器層面攔截所有網路請求，偵測 m3u8/HLS 串流、MP4 檔案和其他媒體格式。還會掃描頁面 DOM 中的影片元素和下載連結。

下載擴充功能 (.zip)

安裝（開發者模式）：

  1. 下載上方的擴充功能 zip 檔案並解壓縮到一個資料夾中。
  2. 開啟 Chrome，導覽至 chrome://extensions/。
  3. 啟用 開發者模式（右上角切換）。
  4. 點擊 載入未封裝項目，選擇 m3u8-extension 資料夾。
  5. 擴充功能圖示出現在工具列中，徽章顯示偵測到的媒體數量。

使用方式：

  1. 瀏覽含有影片內容的頁面。
  2. 點擊擴充功能圖示查看偵測到的 m3u8/MP4 串流。
  3. 點擊 下載 儲存為本機 MP4，或點擊 翻譯 開始產生字幕。
  4. 懸停在項目上可高亮顯示頁面中對應的影片元素。

為什麼使用擴充功能？

  • 在瀏覽器層面攔截網路請求——捕獲 DOM 掃描遺漏的串流
  • 自動品質選擇：按影片 ID 分組並選擇最佳品質
  • Referer 標頭注入，播放需要驗證的串流
  • 徽章計數器一目了然顯示每個分頁偵測到的媒體數量

💻 命令列工具 進階使用者

自動化、批次處理和腳本整合

CLI 提供從終端直接存取所有下載和翻譯功能。專為需要批次處理影片、自動化工作流程或與其他工具整合的進階使用者設計。

為什麼使用 CLI？

  • 批次處理：一條命令翻譯數百部影片
  • 可腳本化：整合到 shell 腳本、排程工作或 CI/CD 管線
  • 完全控制模型：選擇 Whisper 模型大小、翻譯引擎、降噪模式
  • 無 GUI 開銷：適合伺服器、無頭裝置或遠端 SSH 工作階段
  • 支援序列（省記憶體）和平行（快速）處理模式

可用命令：

# 將本機影片翻譯為中文字幕
EchoShortsPlayer.exe --cli translate video.mp4 --target zh

# 批次翻譯整個資料夾
EchoShortsPlayer.exe --cli translate C:\Videos\

# 全部參數：來源語言、Whisper 模型、翻譯引擎、降噪、處理模式
EchoShortsPlayer.exe --cli translate video.mp4 --source auto --target ja --whisper large-v3-turbo --translation qwen3-8b --denoise vocal --mode parallel

# 下載遠端 m3u8 或 MP4
EchoShortsPlayer.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# 一步完成下載和翻譯
EchoShortsPlayer.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# 翻譯已有的 SRT 檔案
EchoShortsPlayer.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

參數參考：

--source, -s      來源語言或 "auto"（預設：auto）
--target, -t      目標語言（預設：zh）
--whisper, -w     tiny|base|small|medium|large-v3-turbo|large-v3
--translation, -m opus-mt|nllb-*|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal（預設：off）
--mode            serial|parallel（預設：serial）
--output, -o      輸出檔案路徑
--url             媒體 URL（m3u8 / MP4）
--referer         Referer 請求標頭

      
查看 --source 和 --target 支援的完整語言代碼列表：語言代碼參考

本機資料處理

EchoShortsPlayer 的所有核心功能——包括語音辨識、翻譯和媒體下載——完全在您的本機裝置上執行，由本機後端伺服器（127.0.0.1:18632）驅動。

我們不收集、儲存、傳輸或分析任何使用者資料，包括但不限於：您觀看的影片內容、辨識的字幕文字、翻譯結果、瀏覽記錄或任何個人資訊。

本應用在正常使用期間不會向外部伺服器傳送任何使用者資料。所有音訊處理和文字翻譯都在本機完成。AI 模型首次使用時從公開來源（HuggingFace）下載，此後可完全離線執行。

瀏覽器擴充功能僅與本機後端 localhost:18632 通訊。不向開發者營運的任何遠端伺服器傳輸資料。
