Traduction Vidéo & Sous-titres par IA
Streaming, Traduction, Téléchargement — Tout Hors Ligne

EchoShortsPlayer traduit les vidéos en ligne en temps réel pendant que vous les regardez — les sous-titres apparaissent pendant la lecture, sans attente. Téléchargez les vidéos accessibles publiquement pour les visionner hors ligne. Toute la reconnaissance vocale et la traduction s'exécutent à 100% localement sur votre appareil : pas d'internet, pas de compte, aucune donnée ne quitte votre ordinateur. Prend en charge plus de 99 langues, les flux m3u8 et les fichiers MP4.

#2 Comment Utiliser

📥 Installer EchoShortsPlayer Requis

Application de bureau — le moteur central de toutes les fonctionnalités

EchoShortsPlayer est l'application de bureau qui exécute les modèles d'IA localement. L'extension de navigateur et la CLI en dépendent. Installez-la en premier avant d'utiliser l'une des méthodes ci-dessous.

Télécharger EchoShortsPlayer

Configuration requise : Windows 10/11, GPU NVIDIA avec 8 Go ou plus de VRAM, pilotes CUDA installés.

Après l'installation, lancez l'application. Elle démarre un serveur backend local à localhost:18632 avec lequel l'extension et la CLI communiquent.

🔌 Extension Chrome Recommandé

Interception approfondie des médias au niveau réseau

L'extension Chrome utilise l'API webRequest pour intercepter toutes les requêtes réseau au niveau du navigateur, détectant les flux m3u8/HLS, les fichiers MP4 et autres formats multimédias. Elle scanne également le DOM de la page pour trouver les éléments vidéo et les liens de téléchargement.

Télécharger l'Extension (.zip)

Installation (mode développeur) :

  1. Téléchargez le zip de l'extension ci-dessus et extrayez-le dans un dossier.
  2. Ouvrez Chrome et accédez à chrome://extensions/.
  3. Activez le Mode développeur (interrupteur en haut à droite).
  4. Cliquez sur Charger l'extension non empaquetée et sélectionnez le dossier m3u8-extension.
  5. L'icône de l'extension apparaît dans la barre d'outils avec un badge indiquant le nombre de médias détectés.

Utilisation :

  1. Naviguez vers une page contenant du contenu vidéo.
  2. Cliquez sur l'icône de l'extension pour voir les flux m3u8/MP4 détectés.
  3. Cliquez sur Télécharger pour enregistrer en MP4 local, ou Traduire pour lancer la génération de sous-titres.
  4. Survolez les éléments pour mettre en surbrillance l'élément vidéo correspondant sur la page.

Pourquoi utiliser l'extension ?

  • Intercepts network requests at the browser level — catches streams that DOM scanning misses
  • Automatic quality selection: groups variants by video ID and picks the best quality
  • Referer header injection for playing streams that require authentication
  • Badge counter shows detected media count per tab at a glance

💻 Interface en Ligne de Commande Utilisateurs Avancés

Automatisation, traitement par lots et scripting

La CLI fournit un accès direct à toutes les fonctionnalités de téléchargement et de traduction depuis le terminal. Elle est conçue pour les utilisateurs avancés qui ont besoin de traiter plusieurs vidéos, d'automatiser des flux de travail ou de s'intégrer à d'autres outils.

Pourquoi utiliser la CLI ?

  • Batch processing: translate hundreds of videos with a single command
  • Scriptable: integrate into shell scripts, cron jobs, or CI/CD pipelines
  • Full control over models: choose Whisper model size, translation engine, denoising mode
  • No GUI overhead: ideal for servers, headless machines, or remote SSH sessions
  • Supports both serial (memory-efficient) and parallel (fast) processing modes

Commandes disponibles :

# Traduire un fichier vidéo local en sous-titres chinois
resources\backend\backend.exe --cli translate video.mp4 --target zh

# Traduire un dossier entier par lots
resources\backend\backend.exe --cli translate C:\Videos\

# Toutes les options : langue source, modèle Whisper, moteur de traduction, réduction du bruit, mode de traitement
resources\backend\backend.exe --cli translate video.mp4 --source auto --target ja --whisper distil-large-v3 --translation qwen3-8b --denoise vocal --mode parallel

# Télécharger un m3u8 ou MP4 distant
resources\backend\backend.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# Télécharger et traduire en une seule étape
resources\backend\backend.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# Traduire un fichier SRT existant
resources\backend\backend.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

Parameter reference:

--source, -s      Langue source ou "auto" (par défaut : auto)
--target, -t      Langue cible (par défaut : zh)
--whisper, -w     tiny|base|small|medium|distil-large-v3|large-v3
--translation, -m opus-mt|nllb-distilled-600M|nllb-1.3B|nllb-3.3B|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal (par défaut : off)
--mode            serial|parallel (par défaut : serial)
--output, -o      Chemin du fichier de sortie
--url             URL média (m3u8 / MP4)
--referer         En-tête Referer

      
See the full list of supported language codes for --source and --target: Language Code Reference
