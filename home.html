Privacy Policy & Disclaimer

Local Data Processing

All core features of EchoShorts — including speech recognition, OCR text recognition, and language translation — run on your local device, powered by a local server (127.0.0.1:8765).

We do not collect, store, transmit, or analyze any user data, including but not limited to: video content you watch, recognized subtitle text, translation results, browsing history, or any personal information.

No Network Data Transmission

This application does not send any data to external servers during normal use. All audio processing, image recognition, and text translation are completed locally. AI models are downloaded from public sources on first use and can run offline thereafter.
