EchoShortsPlayer

AI Video Translation & Subtitles
Stream, Translate, Download — All Offline

EchoShortsPlayer translates online videos in real-time while you watch — subtitles appear as the video plays, no waiting. Download publicly accessible videos for offline viewing. All speech recognition and translation run 100% locally on your device: no internet needed, no accounts, no data leaves your computer. Supports 99+ languages, m3u8 streams and MP4 files.

#2 How to Use

📥 Install EchoShortsPlayer Required

Desktop application — the core engine for all features

EchoShortsPlayer is the desktop application that runs the AI models locally. The browser extension and CLI depend on it. Install it first before using any of the methods below.

Download EchoShortsPlayer

System requirements: Windows 10/11, NVIDIA GPU with 8 GB+ VRAM, CUDA drivers installed.

After installation, launch the application. It starts a local backend server at localhost:18632 that the extension and CLI communicate with.

🔌 Chrome Extension Recommended

Deep network-level media interception

The Chrome extension uses the webRequest API to intercept all network requests at the browser level, detecting m3u8/HLS streams, MP4 files, and other media formats. It also scans the page DOM for video elements and download links.

Download Extension (.zip)

Installasjon (utviklermodus):

  1. Last ned zip-filen for utvidelsen over og pakk den ut til en mappe.
  2. Åpne Chrome og gå til chrome://extensions/.
  3. Slå på Utviklermodus (bryteren øverst til høyre).
  4. Klikk Last inn pakket ut og velg mappen m3u8-extension.
  5. Utvidelsesikonet vises på verktøylinjen med et merke som viser antall oppdagede medier.

Bruk:

  1. Gå til en side med videoinnhold.
  2. Klikk på utvidelsesikonet for å se oppdagede m3u8/MP4-strømmer.
  3. Klikk Last ned for å lagre som lokal MP4, eller Oversett for å starte undertekstgenerering.
  4. Hold pekeren over elementer for å utheve tilsvarende videoelement på siden.

Hvorfor bruke utvidelsen?

  • Fanger opp nettverksforespørsler på nettlesernivå — fanger strømmer DOM-skanning overser
  • Automatisk kvalitetsvalg: grupperer varianter etter video-ID og velger beste kvalitet
  • Injiserer Referer-header for å spille av strømmer som krever autentisering
  • Merketelleren viser antall oppdagede medier per fane med ett blikk

💻 Command-Line Interface Power Users

Automation, batch processing, and scripting

The CLI provides direct access to all download and translation features from the terminal. It's designed for power users who need to process multiple videos, automate workflows, or integrate with other tools.

Hvorfor bruke CLI?

  • Batchbehandling: oversett hundrevis av videoer med én kommando
  • Skriptbar: integrer i shell-skript, cron-jobber eller CI/CD-pipelines
  • Full kontroll over modeller: velg Whisper-modellstørrelse, oversettelsesmotor, støydempingsmodus
  • Ingen GUI-overhead: ideell for servere, hodeløse maskiner eller eksterne SSH-økter
  • Støtter både seriell (minneeffektiv) og parallell (rask) prosesseringsmodus

Available commands:

# Translate a local video file to Chinese subtitles
resources\backend\backend.exe --cli translate video.mp4 --target zh

# Batch translate an entire folder
resources\backend\backend.exe --cli translate C:\Videos\

# Full options: source language, whisper model, translation engine, denoising, processing mode
resources\backend\backend.exe --cli translate video.mp4 --source auto --target ja --whisper distil-large-v3 --translation qwen3-8b --denoise vocal --mode parallel

# Download a remote m3u8 or MP4
resources\backend\backend.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# Download and translate in one step
resources\backend\backend.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# Translate an existing SRT file
resources\backend\backend.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

Parameterreferanse:

--source, -s      Source language or "auto" (default: auto)
--target, -t      Target language (default: zh)
--whisper, -w     tiny|base|small|medium|distil-large-v3|large-v3
--translation, -m opus-mt|nllb-distilled-600M|nllb-1.3B|nllb-3.3B|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal (default: off)
--mode            serial|parallel (default: serial)
--output, -o      Output file path
--url             Media URL (m3u8 / MP4)
--referer         Referer header

Se den fullstendige listen over støttede språkkoder for --source og --target: Språkkodereferanse

For teknisk støtte, kontakt supports@echoshorts.win.

#3 Personvernregler og ansvarsfraskrivelse

Lokal databehandling

Alle kjernefunksjoner i EchoShortsPlayer — inkludert talegjenkjenning, oversettelse og nedlasting av media — kjører fullstendig på din lokale enhet via en lokal backend-server (127.0.0.1:18632).

Vi samler ikke inn, lagrer, sender eller analyserer brukerdata, inkludert men ikke begrenset til: videoinnhold du ser, gjenkjent undertekst, oversettelsesresultater, nettleserhistorikk eller personopplysninger.

Ingen nettverksdatatransmisjon

Applikasjonen sender ikke brukerdata til eksterne servere under normal bruk. All lydbehandling og tekstoversettelse fullføres lokalt. AI-modeller lastes ned fra offentlige kilder (HuggingFace) ved første bruk og kan deretter kjøre fullstendig frakoblet.

Nettleserutvidelsen kommuniserer kun med den lokale backenden på localhost:18632. Ingen data overføres til eksterne servere drevet av utviklerne.

Ingen annonser, sporing eller anbefalinger

Denne applikasjonen inneholder ikke annonsesystemer, sporingskode for brukeratferd, analyse eller datamekanismer for anbefalinger. Vi deler ikke brukerdata med tredjeparter og oppretter ikke profiler eller sender innhold basert på atferd.

Trygg havn og brukeransvar

EchoShortsPlayer er et generelt teknisk verktøy utelukkende designet for å hjelpe med å forstå videoinnhold. I henhold til trygg havn-doktrin påtar ikke utviklere og utgivere juridisk ansvar for brudd på opphavsrett eller annet angående innhold brukeren får tilgang til, oversetter eller behandler.

Brukeren må sikre at bruken overholder lokale lover og plattformenes tjenestevilkår. Alt juridisk ansvar ved tilgang til opphavsrettsbeskyttet innhold, brudd på plattformregler eller ulovlig aktivitet hviler utelukkende på brukeren.

Applikasjonen vurderer eller garanterer ikke lovligheten av innhold brukeren får tilgang til og påtar seg ikke ansvar for direkte eller indirekte tap fra bruken.

Tiltenkt bruk

Applikasjonen er designet som et hjelpeverktøy for personlig lokal bruk av personer med hørselstap, språklærere eller de som trenger å forstå videoer på fremmedspråk. Annen bruk er brukerens eget ansvar.

Tekniske begrensninger

Applikasjonen støtter analyse av offentlig tilgjengelig videoinnhold uten DRM. På grunn av beskyttelsesprotokoller (f.eks. Widevine, PlayReady) kan ikke lydstrømmer fra DRM-innhold trekkes ut, noe som hindrer undertekstgenerering.

For MP4-filer som ikke er «fast-start»-kodet (moov-atom på slutten av filen) kreves full nedlasting før oversettelse kan starte. Fast-start MP4 støtter strømmende oversettelse under nedlasting.

Ansvarsfraskrivelse

Applikasjonen leveres «som den er» uten uttrykkelige eller underforståtte garantier. Utvikleren garanterer ikke korrekt funksjon i alle miljøer og påtar seg ikke ansvar for tap, datatap eller enhetsproblemer forårsaket av bruk. Bruk innebærer aksept av alle ovennevnte vilkår.

Undertekster og oversettelser genereres automatisk av maskin og er kun til referanse. Ingen garantier for nøyaktighet, fullstendighet eller egnethet av maskinoversatt innhold og intet ansvar for følger av å stole på slike oversettelser.

Policyoppdateringer

Denne personvernregelen kan oppdateres i nye versjoner. Vesentlige endringer kommuniseres via applikasjonens oppdateringslogg. Fortsatt bruk innebærer aksept av den nyeste versjonen av personvernreglene.
