AI 동영상 번역 & 자막
스트리밍, 번역, 다운로드 — 모두 오프라인

EchoShortsPlayer는 시청 중인 온라인 동영상을 실시간으로 번역합니다. 동영상이 재생되는 동안 자막이 표시되며 기다릴 필요가 없습니다. 공개된 동영상을 다운로드하여 오프라인으로 시청할 수 있습니다. 모든 음성 인식과 번역은 기기에서 100% 로컬로 실행됩니다. 인터넷 불필요, 계정 불필요, 데이터가 컴퓨터 밖으로 나가지 않습니다. 99개 이상의 언어, m3u8 스트림 및 MP4 파일을 지원합니다.

#2 사용 방법

📥 EchoShortsPlayer 설치 필수

데스크톱 애플리케이션 — 모든 기능의 핵심 엔진

EchoShortsPlayer는 AI 모델을 로컬에서 실행하는 데스크톱 애플리케이션입니다. 브라우저 확장 프로그램과 CLI가 이에 의존합니다. 아래 방법을 사용하기 전에 먼저 설치하세요.

EchoShortsPlayer 다운로드

시스템 요구사항: Windows 10/11, 8 GB 이상 VRAM의 NVIDIA GPU, CUDA 드라이버 설치.

설치 후 애플리케이션을 실행하세요. 확장 프로그램과 CLI가 통신하는 localhost:18632의 로컬 백엔드 서버가 시작됩니다.

🔌 Chrome 확장 프로그램 추천

심층 네트워크 수준 미디어 인터셉트

Chrome 확장 프로그램은 webRequest API를 사용하여 브라우저 수준에서 모든 네트워크 요청을 인터셉트하여 m3u8/HLS 스트림, MP4 파일 및 기타 미디어 형식을 감지합니다. 또한 페이지 DOM을 스캔하여 비디오 요소와 다운로드 링크를 찾습니다.

확장 프로그램 다운로드 (.zip)

설치 (개발자 모드):

  1. 위의 확장 프로그램 zip을 다운로드하고 폴더에 압축을 해제합니다.
  2. Chrome을 열고 chrome://extensions/로 이동합니다.
  3. 개발자 모드(오른쪽 상단 토글)를 활성화합니다.
  4. 압축해제된 확장 프로그램을 로드합니다를 클릭하고 m3u8-extension 폴더를 선택합니다.
  5. 툴바에 확장 프로그램 아이콘이 나타나며 감지된 미디어 수가 배지로 표시됩니다.

사용법:

  1. 동영상 콘텐츠가 있는 페이지를 탐색합니다.
  2. 확장 프로그램 아이콘을 클릭하여 감지된 m3u8/MP4 스트림을 확인합니다.
  3. 다운로드를 클릭하여 로컬 MP4로 저장하거나 번역을 클릭하여 자막 생성을 시작합니다.
  4. 항목 위에 마우스를 올리면 페이지의 해당 비디오 요소가 강조 표시됩니다.

확장 프로그램을 사용하는 이유

  • Intercepts network requests at the browser level — catches streams that DOM scanning misses
  • Automatic quality selection: groups variants by video ID and picks the best quality
  • Referer header injection for playing streams that require authentication
  • Badge counter shows detected media count per tab at a glance

💻 명령줄 인터페이스 고급 사용자

자동화, 일괄 처리, 스크립팅

CLI는 터미널에서 모든 다운로드 및 번역 기능에 직접 접근할 수 있습니다. 여러 동영상을 처리하거나 워크플로를 자동화하거나 다른 도구와 통합해야 하는 고급 사용자를 위해 설계되었습니다.

CLI를 사용하는 이유

  • Batch processing: translate hundreds of videos with a single command
  • Scriptable: integrate into shell scripts, cron jobs, or CI/CD pipelines
  • Full control over models: choose Whisper model size, translation engine, denoising mode
  • No GUI overhead: ideal for servers, headless machines, or remote SSH sessions
  • Supports both serial (memory-efficient) and parallel (fast) processing modes

사용 가능한 명령:

# 로컬 동영상 파일을 중국어 자막으로 번역
resources\backend\backend.exe --cli translate video.mp4 --target zh

# 전체 폴더를 일괄 번역
resources\backend\backend.exe --cli translate C:\Videos\

# 전체 옵션: 소스 언어, Whisper 모델, 번역 엔진, 노이즈 제거, 처리 모드
resources\backend\backend.exe --cli translate video.mp4 --source auto --target ja --whisper distil-large-v3 --translation qwen3-8b --denoise vocal --mode parallel

# 원격 m3u8 또는 MP4 다운로드
resources\backend\backend.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# 다운로드와 번역을 한 번에 실행
resources\backend\backend.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# 기존 SRT 파일 번역
resources\backend\backend.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

Parameter reference:

--source, -s      소스 언어 또는 "auto" (기본값: auto)
--target, -t      대상 언어 (기본값: zh)
--whisper, -w     tiny|base|small|medium|distil-large-v3|large-v3
--translation, -m opus-mt|nllb-distilled-600M|nllb-1.3B|nllb-3.3B|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal (기본값: off)
--mode            serial|parallel (기본값: serial)
--output, -o      출력 파일 경로
--url             미디어 URL (m3u8 / MP4)
--referer         Referer 헤더
