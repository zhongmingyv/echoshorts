EchoShortsPlayer

AI 동영상 번역 & 자막
스트리밍, 번역, 다운로드 — 모두 오프라인

EchoShortsPlayer는 시청 중인 온라인 동영상을 실시간으로 번역합니다. 동영상이 재생되는 동안 자막이 표시되며 기다릴 필요가 없습니다. 공개된 동영상을 다운로드하여 오프라인으로 시청할 수 있습니다. 모든 음성 인식과 번역은 기기에서 100% 로컬로 실행됩니다. 인터넷 불필요, 계정 불필요, 데이터가 컴퓨터 밖으로 나가지 않습니다. 99개 이상의 언어, m3u8 스트림 및 MP4 파일을 지원합니다.

#1 기능

🎤

음성 인식

OpenAI Whisper 기반. 자동 언어 감지 기능으로 99개 언어를 지원합니다. tiny(빠름)부터 large-v3(최고 정확도)까지 다양한 모델 크기를 선택할 수 있습니다.

🌐

AI 번역

다양한 번역 엔진:

  • Opus-MT — 빠른 속도, 9개 언어
  • NLLB — 32개 이상 언어, 모든 언어 간 번역
  • Qwen — 최고 품질, CJK 최적화
📶

미디어 감지

모든 웹페이지에서 m3u8/HLS 스트림과 MP4 동영상 링크를 자동 감지합니다. 브라우저 확장 프로그램이나 유저스크립트로 원클릭 다운로드 또는 번역.

⚡

실시간 자막

스트림 번역 모드: 시청 중 실시간으로 자막이 표시됩니다. 전체 동영상 다운로드를 기다릴 필요가 없습니다. SRT 자막 파일은 향후 사용을 위해 로컬에 저장됩니다.

🔒

100% 오프라인 & 프라이버시

모든 처리가 로컬에서 이루어집니다. 외부 서버로 데이터가 전송되지 않습니다. 계정 불필요, 추적 없음, 광고 없음. 콘텐츠는 기기에 유지됩니다.

💻

하드웨어 요구사항

8 GB 이상의 VRAM을 탑재한 NVIDIA GPU와 CUDA 드라이버가 설치되어 있어야 합니다. 최적의 성능을 위해 GPU 가속 음성 인식 및 번역을 지원합니다.

#2 사용 방법

📥 Install EchoShortsPlayer Required

Desktop application — the core engine for all features

EchoShortsPlayer is the desktop application that runs the AI models locally. The browser extension, userscript, and CLI all depend on it. Install it first before using any of the methods below.

Download EchoShortsPlayer

System requirements: Windows 10/11, NVIDIA GPU with 8 GB+ VRAM, CUDA drivers installed.

After installation, launch the application. It starts a local backend server at localhost:18632 that the extension, userscript, and CLI communicate with.

🪄 Tampermonkey 유저스크립트 가장 쉬움

모든 브라우저에서 설치 없이 미디어 감지

Tampermonkey 유저스크립트는 모든 웹페이지에 플로팅 패널을 삽입하여 m3u8 스트림과 MP4 동영상 링크를 자동 감지합니다. 감지된 미디어는 다운로드와 번역 버튼이 있는 목록에 표시됩니다.

1단계: Tampermonkey 브라우저 확장 프로그램을 설치하세요:

Tampermonkey 공식 사이트 Chrome 웹 스토어

2단계: EchoShortsPlayer 유저스크립트를 설치하세요:

유저스크립트 설치

3단계: EchoShortsPlayer 데스크톱 앱이 실행 중인지 확인하세요 (유저스크립트는 감지된 URL을 localhost:18632의 로컬 백엔드로 전송합니다).

4단계: 아무 동영상 페이지를 방문하세요. 플로팅 패널(오른쪽 하단)이 미디어를 자동 감지합니다. 다운로드 또는 번역을 클릭하세요.

유저스크립트를 사용하는 이유

  • Tampermonkey를 지원하는 모든 브라우저에서 작동 (Chrome, Firefox, Edge, Safari, Opera)
  • Chrome 확장 프로그램 설치 불필요 — 확장 프로그램이 제한된 환경에 적합
  • 가볍고 단일 파일로 검사 및 수정이 용이
  • Tampermonkey 내장 업데이트 메커니즘으로 자동 업데이트
  • 페이지의 m3u8/HLS 스트림과 직접 MP4 링크를 모두 감지

🔌 Chrome 확장 프로그램 추천

심층 네트워크 수준 미디어 인터셉트

Chrome 확장 프로그램은 webRequest API를 사용하여 브라우저 수준에서 모든 네트워크 요청을 인터셉트하여 m3u8/HLS 스트림, MP4 파일 및 기타 미디어 형식을 감지합니다. 또한 페이지 DOM을 스캔하여 비디오 요소와 다운로드 링크를 찾습니다.

확장 프로그램 다운로드 (.zip)

설치 (개발자 모드):

  1. 위의 확장 프로그램 zip을 다운로드하고 폴더에 압축을 해제합니다.
  2. Chrome을 열고 chrome://extensions/로 이동합니다.
  3. 개발자 모드(오른쪽 상단 토글)를 활성화합니다.
  4. 압축해제된 확장 프로그램을 로드합니다를 클릭하고 m3u8-extension 폴더를 선택합니다.
  5. 툴바에 확장 프로그램 아이콘이 나타나며 감지된 미디어 수가 배지로 표시됩니다.

사용법:

  1. 동영상 콘텐츠가 있는 페이지를 탐색합니다.
  2. 확장 프로그램 아이콘을 클릭하여 감지된 m3u8/MP4 스트림을 확인합니다.
  3. 다운로드를 클릭하여 로컬 MP4로 저장하거나 번역을 클릭하여 자막 생성을 시작합니다.
  4. 항목 위에 마우스를 올리면 페이지의 해당 비디오 요소가 강조 표시됩니다.

확장 프로그램을 사용하는 이유

  • 브라우저 수준에서 네트워크 요청을 인터셉트 — DOM 스캔으로 놓치는 스트림도 포착
  • 자동 화질 선택: 동영상 ID별로 변형을 그룹화하고 최고 화질을 선택
  • 인증이 필요한 스트림 재생을 위한 Referer 헤더 삽입
  • 배지 카운터로 탭별 감지된 미디어 수를 한눈에 확인
  • 유저스크립트보다 심층적인 감지: fetch, XHR, MediaSource, 응답 본문 스캔에 연결

💻 명령줄 인터페이스 고급 사용자

자동화, 일괄 처리, 스크립팅

CLI는 터미널에서 모든 다운로드 및 번역 기능에 직접 접근할 수 있습니다. 여러 동영상을 처리하거나 워크플로를 자동화하거나 다른 도구와 통합해야 하는 고급 사용자를 위해 설계되었습니다.

CLI를 사용하는 이유

  • 일괄 처리: 단일 명령으로 수백 개의 동영상을 번역
  • 스크립트 가능: 셸 스크립트, cron 작업, CI/CD 파이프라인에 통합
  • 모델 완전 제어: Whisper 모델 크기, 번역 엔진, 노이즈 제거 모드 선택
  • GUI 오버헤드 없음: 서버, 헤드리스 머신, 원격 SSH 세션에 적합
  • 직렬(메모리 효율적) 및 병렬(고속) 처리 모드 모두 지원

사용 가능한 명령:

# 로컬 동영상 파일을 중국어 자막으로 번역
EchoShortsPlayer.exe --cli translate video.mp4 --target zh

# 전체 폴더를 일괄 번역
EchoShortsPlayer.exe --cli translate C:\Videos\

# 전체 옵션: 소스 언어, Whisper 모델, 번역 엔진, 노이즈 제거, 처리 모드
EchoShortsPlayer.exe --cli translate video.mp4 --source auto --target ja --whisper large-v3-turbo --translation qwen3-8b --denoise vocal --mode parallel

# 원격 m3u8 또는 MP4 다운로드
EchoShortsPlayer.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# 다운로드와 번역을 한 번에 실행
EchoShortsPlayer.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# 기존 SRT 파일 번역
EchoShortsPlayer.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

매개변수 참조:

--source, -s      소스 언어 또는 "auto" (기본값: auto)
--target, -t      대상 언어 (기본값: zh)
--whisper, -w     tiny|base|small|medium|large-v3-turbo|large-v3
--translation, -m opus-mt|nllb-*|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal (기본값: off)
--mode            serial|parallel (기본값: serial)
--output, -o      출력 파일 경로
--url             미디어 URL (m3u8 / MP4)
--referer         Referer 헤더

      
--source 및 --target에서 지원되는 언어 코드 전체 목록: 언어 코드 참조

#3 개인정보 보호정책 및 면책조항

로컬 데이터 처리

EchoShortsPlayer의 모든 핵심 기능—음성 인식, 번역, 미디어 다운로드 포함—은 로컬 백엔드 서버(127.0.0.1:18632)를 통해 사용자의 기기에서 완전히 실행됩니다.

당사는 사용자 데이터를 일체 수집, 저장, 전송 또는 분석하지 않습니다.

네트워크 데이터 전송 없음

이 애플리케이션은 정상 사용 중 사용자 데이터를 외부 서버로 전송하지 않습니다. 모든 오디오 처리와 텍스트 번역은 로컬에서 완료됩니다.

브라우저 확장 프로그램과 유저스크립트는 localhost:18632의 로컬 백엔드와만 통신합니다.

광고 없음, 추적 없음, 추천 없음

이 애플리케이션에는 광고 시스템, 사용자 행동 추적 코드, 분석 도구 또는 데이터 추천 메커니즘이 포함되어 있지 않습니다.

오픈 소스 및 투명성

애플리케이션의 소스 코드는 검토를 위해 완전히 공개되어 있습니다. 사용자는 이 정책에서 주장하는 개인정보 보호 및 보안 사항을 확인하기 위해 코드를 검토하는 것이 좋습니다.

세이프 하버 및 사용자 책임

EchoShortsPlayer는 사용자가 비디오 콘텐츠를 이해하는 것을 돕기 위해 설계된 범용 기술 도구입니다. 개발자는 사용자가 액세스, 번역 또는 처리하는 콘텐츠에 대해 법적 책임을 지지 않습니다.

사용자는 자신의 사용이 현지 법률 및 규정과 액세스하는 플랫폼의 서비스 약관을 준수하는지 확인해야 합니다. 모든 법적 책임은 사용자에게만 있습니다.

의도된 용도

이 애플리케이션은 청각 장애인, 언어 학습자 또는 외국어 비디오 콘텐츠를 이해해야 하는 개인의 개인 로컬 사용을 위한 보조 도구로 설계되었습니다.

기술적 제한

이 애플리케이션은 DRM으로 보호되지 않는 공개적으로 접근 가능한 비디오 콘텐츠의 분석을 지원합니다.

fast-start로 인코딩되지 않은 MP4 파일의 경우, 번역을 시작하기 전에 전체 다운로드가 필요합니다.

면책조항

이 애플리케이션은 명시적이든 묵시적이든 어떠한 보증 없이 "있는 그대로" 제공됩니다.

자막과 번역은 기계에 의해 자동으로 생성되며 참고용으로만 제공됩니다.

정책 업데이트

이 개인정보 보호정책은 새로운 버전과 함께 업데이트될 수 있습니다. 이 애플리케이션의 계속 사용은 최신 버전의 개인정보 보호정책에 대한 동의를 의미합니다.
