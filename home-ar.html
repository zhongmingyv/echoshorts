#2 كيفية الاستخدام

📥 Install EchoShortsPlayer Required

Desktop application — the core engine for all features

EchoShortsPlayer is the desktop application that runs the AI models locally. The browser extension and CLI depend on it. Install it first before using any of the methods below.

Download EchoShortsPlayer

System requirements: Windows 10/11, NVIDIA GPU with 8 GB+ VRAM, CUDA drivers installed.

After installation, launch the application. It starts a local backend server at localhost:18632 that the extension and CLI communicate with.

🔌 إضافة Chrome موصى به

اعتراض عميق للوسائط على مستوى الشبكة

تستخدم إضافة Chrome واجهة webRequest لاعتراض جميع طلبات الشبكة على مستوى المتصفح، وكشف بث m3u8/HLS وملفات MP4 وتنسيقات الوسائط الأخرى. كما تفحص DOM الصفحة بحثاً عن عناصر الفيديو وروابط التحميل.

تحميل الإضافة (.zip)

التثبيت (وضع المطور):

  1. حمّل ملف zip الإضافة أعلاه واستخرجه في مجلد.
  2. افتح Chrome وانتقل إلى chrome://extensions/.
  3. فعّل وضع المطور (زر التبديل أعلى اليمين).
  4. انقر تحميل غير مُحزّم واختر مجلد m3u8-extension.
  5. يظهر رمز الإضافة في شريط الأدوات مع شارة تعرض عدد الوسائط المكتشفة.

الاستخدام:

  1. تصفح أي صفحة تحتوي على محتوى فيديو.
  2. انقر على رمز الإضافة لعرض بث m3u8/MP4 المكتشف.
  3. انقر تحميل للحفظ كملف MP4 محلي، أو ترجمة لبدء إنشاء الترجمات.
  4. مرّر الماوس فوق العناصر لتمييز عنصر الفيديو المقابل في الصفحة.

لماذا تستخدم الإضافة؟

  • تعترض طلبات الشبكة على مستوى المتصفح — تلتقط البث الذي لا يكتشفه فحص DOM
  • اختيار تلقائي للجودة: تجمّع المتغيرات حسب معرّف الفيديو وتختار أفضل جودة
  • حقن رأس Referer لتشغيل البث الذي يتطلب مصادقة
  • عدّاد الشارة يعرض عدد الوسائط المكتشفة لكل علامة تبويب بنظرة سريعة

💻 واجهة سطر الأوامر المستخدمون المتقدمون

أتمتة ومعالجة دفعية وبرمجة نصية

يوفر سطر الأوامر وصولاً مباشراً لجميع ميزات التحميل والترجمة من الطرفية. مصمم للمستخدمين المتقدمين الذين يحتاجون لمعالجة مقاطع فيديو متعددة أو أتمتة سير العمل أو الدمج مع أدوات أخرى.

لماذا تستخدم سطر الأوامر؟

  • معالجة دفعية: ترجم مئات مقاطع الفيديو بأمر واحد
  • قابل للبرمجة: ادمج في سكربتات shell أو مهام cron أو خطوط أنابيب CI/CD
  • تحكم كامل في النماذج: اختر حجم نموذج Whisper ومحرك الترجمة ووضع إزالة الضوضاء
  • بدون عبء واجهة رسومية: مثالي للخوادم والأجهزة بدون شاشة وجلسات SSH عن بعد
  • يدعم أوضاع المعالجة التسلسلية (موفرة للذاكرة) والمتوازية (سريعة)

الأوامر المتاحة:

# ترجمة ملف فيديو محلي إلى ترجمات صينية
resourcesbackendbackend.exe --cli translate video.mp4 --target zh

# ترجمة مجلد كامل دفعة واحدة
resourcesbackendbackend.exe --cli translate C:\Videos\

# جميع الخيارات: لغة المصدر، نموذج Whisper، محرك الترجمة، إزالة الضوضاء، وضع المعالجة
resourcesbackendbackend.exe --cli translate video.mp4 --source auto --target ja --whisper distil-large-v3 --translation qwen3-8b --denoise vocal --mode parallel

# تحميل m3u8 أو MP4 عن بُعد
resourcesbackendbackend.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# التحميل والترجمة في خطوة واحدة
resourcesbackendbackend.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# ترجمة ملف SRT موجود
resourcesbackendbackend.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

مرجع المعلمات:

--source, -s      اللغة المصدر أو "auto" (افتراضي: auto)
--target, -t      اللغة الهدف (افتراضي: zh)
--whisper, -w     tiny|base|small|medium|distil-large-v3|large-v3
--translation, -m opus-mt|nllb-distilled-600M|nllb-1.3B|nllb-3.3B|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal (افتراضي: off)
--mode            serial|parallel (افتراضي: serial)
--output, -o      مسار ملف الإخراج
--url             رابط الوسائط (m3u8 / MP4)
--referer         ترويسة Referer

      
عرض القائمة الكاملة لرموز اللغات المدعومة لـ --source و --target: مرجع رموز اللغات

#3 سياسة الخصوصية وإخلاء المسؤولية

معالجة البيانات محلياً

جميع الميزات الأساسية لـ EchoShortsPlayer — بما في ذلك التعرف على الكلام والترجمة وتنزيل الوسائط — تعمل بالكامل على جهازك المحلي، مدعومة بخادم محلي (127.0.0.1:18632).

نحن لا نجمع أو نخزن أو ننقل أو نحلل أي بيانات مستخدم، بما في ذلك على سبيل المثال لا الحصر: محتوى الفيديو الذي تشاهده، نص الترجمة المعترف به، نتائج الترجمة، سجل التصفح، أو أي معلومات شخصية.

عدم نقل البيانات عبر الشبكة

لا يرسل هذا التطبيق أي بيانات مستخدم إلى خوادم خارجية أثناء الاستخدام العادي. تتم جميع عمليات معالجة الصوت وترجمة النص محلياً. يتم تنزيل نماذج الذكاء الاصطناعي من مصادر عامة (HuggingFace) عند الاستخدام الأول ويمكن أن تعمل بالكامل دون اتصال بعد ذلك.

يتواصل امتداد المتصفح فقط مع الخادم المحلي على localhost:18632. لا يتم نقل أي بيانات إلى أي خادم بعيد يديره المطورون.

بدون إعلانات، بدون تتبع، بدون توصيات

لا يحتوي هذا التطبيق على أنظمة إعلانية أو رموز تتبع سلوك المستخدم أو أدوات تحليل أو آليات توصية البيانات. نحن لا نشارك بيانات المستخدم مع أي أطراف ثالثة.

الملاذ الآمن ومسؤولية المستخدم

EchoShortsPlayer هو أداة تقنية للأغراض العامة مصممة فقط لمساعدة المستخدمين على فهم محتوى الفيديو. بموجب مبدأ الملاذ الآمن، لا يتحمل مطورو وناشرو هذا التطبيق أي مسؤولية قانونية عن أي محتوى يتم الوصول إليه أو ترجمته أو معالجته من قبل المستخدمين.

يجب على المستخدمين التأكد من أن استخدامهم يتوافق مع القوانين واللوائح المحلية وشروط خدمة المنصات التي يصلون إليها. تقع جميع المسؤولية القانونية على عاتق المستخدم وحده.

لا يصدر هذا التطبيق أي حكم أو ضمان بشأن قانونية المحتوى الذي يصل إليه المستخدمون.

الاستخدام المقصود

تم تصميم هذا التطبيق كأداة مساعدة مخصصة للاستخدام الشخصي المحلي من قبل الأشخاص ذوي الإعاقة السمعية أو متعلمي اللغات أو من يحتاجون لفهم محتوى الفيديو بلغات أجنبية.

القيود التقنية

يدعم هذا التطبيق تحليل محتوى الفيديو المتاح للعامة وغير المحمي بإدارة الحقوق الرقمية (DRM).

بالنسبة لملفات MP4 غير المشفرة بـ "fast-start"، يتطلب التطبيق تنزيلاً كاملاً قبل أن تبدأ الترجمة.

إخلاء المسؤولية

يتم تقديم هذا التطبيق "كما هو" دون أي ضمانات صريحة أو ضمنية. لا يضمن المطور أن هذا التطبيق سيعمل بشكل صحيح في جميع البيئات.

الترجمات والعناوين الفرعية المقدمة يتم إنشاؤها تلقائياً بواسطة الآلة وهي للإشارة فقط.

تحديثات السياسة

قد يتم تحديث سياسة الخصوصية هذه مع الإصدارات الجديدة. الاستمرار في استخدام هذا التطبيق يشكل قبولاً لأحدث إصدار من سياسة الخصوصية.
