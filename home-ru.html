Вся обработка происходит локально. Никакие данные не отправляются на внешние серверы. Без аккаунтов, без отслеживания, без рекламы. Ваш контент остаётся на вашем устройстве.

#2 Как использовать

📥 Установить EchoShortsPlayer Обязательно

Настольное приложение — основной движок для всех функций

EchoShortsPlayer — это настольное приложение, которое запускает модели ИИ локально. Расширение браузера и CLI зависят от него. Установите его первым, прежде чем использовать любой из способов ниже.

Скачать из Windows Store

Системные требования: Windows 10/11, GPU NVIDIA с 8 ГБ или более видеопамяти, установленные драйверы CUDA.

После установки запустите приложение. Оно запускает локальный сервер на localhost:18632, с которым взаимодействуют расширение и CLI.

🔌 Расширение Chrome (перехват видео) Настоятельно рекомендуется

Глубокий перехват медиа на сетевом уровне

Расширение Chrome использует API webRequest для перехвата всех сетевых запросов на уровне браузера, обнаруживая потоки m3u8/HLS, файлы MP4 и другие медиаформаты. Также сканирует DOM страницы для поиска видеоэлементов и ссылок для скачивания.

Скачать расширение (.zip)

Установка (режим разработчика):

  1. Скачайте zip-архив расширения выше и распакуйте его в папку.
  2. Откройте Chrome и перейдите на chrome://extensions/.
  3. Включите Режим разработчика (переключатель в правом верхнем углу).
  4. Нажмите Загрузить распакованное расширение и выберите папку echoshorts-extension.
  5. Значок расширения появится на панели инструментов с индикатором количества обнаруженных медиа.

Использование:

  1. Перейдите на любую страницу с видеоконтентом.
  2. Нажмите на значок расширения, чтобы увидеть обнаруженные потоки m3u8/MP4.
  3. Нажмите Скачать для сохранения в локальный MP4 или Перевести для запуска генерации субтитров.
  4. Нажмите Запись, воспроизведите видео в браузере, по окончании нажмите Стоп — расширение автоматически сохранит просмотренные на этой вкладке видео.
  5. Наведите курсор на элемент, чтобы подсветить соответствующий видеоэлемент на странице.

Безопасно ли расширение?

  • Код полностью открыт — вы можете его проверить. Оно общается только с локальным приложением на вашем ПК; мы не получаем историю просмотров.
  • Расширение и EchoShortsPlayer не собирают персональные данные и не ведут поведенческую аналитику и рекламу.
  • Помимо активации лицензии типичный сетевой трафик ограничен получением выбранных вами видеопотоков.
  • Вы можете самостоятельно проверить исходящие запросы и убедиться, что нет лишних передач, кроме активации и загрузки медиа.

💻 Командная строка Продвинутые пользователи

Автоматизация, пакетная обработка и скриптинг

CLI обеспечивает прямой доступ ко всем функциям скачивания и перевода из терминала. Предназначен для продвинутых пользователей, которым нужно обрабатывать множество видео, автоматизировать рабочие процессы или интегрироваться с другими инструментами.

Зачем использовать CLI?

  • Пакетная обработка: перевод сотен видео одной командой
  • Скриптуемость: интеграция в shell-скрипты, cron-задания или CI/CD-пайплайны
  • Полный контроль над моделями: выбор размера модели Whisper, движка перевода, режима шумоподавления
  • Без накладных расходов GUI: идеально для серверов, безголовых машин или удалённых SSH-сессий
  • Поддержка последовательного (экономия памяти) и параллельного (быстрый) режимов обработки

Доступные команды:

# Перевести локальный видеофайл в китайские субтитры
resources\backend\backend.exe --cli translate video.mp4 --target zh

# Пакетный перевод целой папки
resources\backend\backend.exe --cli translate C:\Videos\

# Все параметры: язык источника, модель Whisper, движок перевода, шумоподавление, режим обработки
resources\backend\backend.exe --cli translate video.mp4 --source auto --target ja --whisper distil-large-v3 --translation qwen3-8b --denoise vocal --mode parallel

# Скачать удалённый m3u8 или MP4
resources\backend\backend.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# Скачать и перевести за один шаг
resources\backend\backend.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# Перевести существующий SRT-файл
resources\backend\backend.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

Справочник параметров:

--source, -s      Исходный язык или "auto" (по умолчанию: auto)
--target, -t      Целевой язык (по умолчанию: zh)
--whisper, -w     tiny|base|small|medium|distil-large-v3|large-v3
--translation, -m opus-mt|nllb-distilled-600M|nllb-1.3B|nllb-3.3B|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal (по умолчанию: off)
--mode            serial|parallel (по умолчанию: serial)
--output, -o      Путь выходного файла
--url             URL медиа (m3u8 / MP4)
--referer         Заголовок Referer

      
Полный список поддерживаемых кодов языков для --source и --target: Справочник кодов языков

По вопросам технической поддержки пишите на supports@echoshorts.win.

#3 Политика конфиденциальности и отказ от ответственности

Локальная обработка данных

Все основные функции EchoShortsPlayer — включая распознавание речи, перевод и загрузку медиа — выполняются полностью на вашем локальном устройстве с помощью локального сервера (127.0.0.1:18632).

Мы не собираем, не храним, не передаём и не анализируем пользовательские данные, в том числе: просматриваемое видео, распознанные субтитры, результаты перевода, историю просмотров и любую личную информацию.

Без передачи данных в сеть

При обычном использовании приложение не отправляет пользовательские данные на внешние серверы. Вся обработка аудио и перевод текста выполняются локально. Модели ИИ при первом запуске загружаются из открытых источников (HuggingFace) и далее могут работать полностью офлайн.

Расширение браузера взаимодействует только с локальным бэкендом по адресу localhost:18632. Данные не передаются на удалённые серверы, управляемые разработчиками.

Без рекламы, отслеживания и рекомендаций

В приложении нет рекламных систем, кода отслеживания поведения, аналитики или механизмов рекомендаций. Мы не передаём данные пользователей третьим лицам и не создаём профили и не продвигаем контент на основе поведения.

EchoShortsPlayer — универсальный технический инструмент, предназначенный исключительно для понимания видеоконтента.
