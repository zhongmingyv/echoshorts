#2 How to Use

📥 Install EchoShortsPlayer Required

Desktop application — the core engine for all features

EchoShortsPlayer is the desktop application that runs the AI models locally. The browser extension and CLI depend on it. Install it first before using any of the methods below.

Ladda ner från Windows Store

System requirements: Windows 10/11, NVIDIA GPU with 8 GB+ VRAM, CUDA drivers installed.

After installation, launch the application. It starts a local backend server at localhost:18632 that the extension and CLI communicate with.

🔌 Chrome Extension (Video Sniffing) Strongly recommended

Deep network-level media interception

The Chrome extension uses the webRequest API to intercept all network requests at the browser level, detecting m3u8/HLS streams, MP4 files, and other media formats. It also scans the page DOM for video elements and download links.

Download Extension (.zip)

Installation (utvecklarläge):

  1. Ladda ner zip-arkivet för tillägget ovan och packa upp det till en mapp.
  2. Öppna Chrome och gå till chrome://extensions/.
  3. Aktivera Utvecklarläge (reglaget uppe till höger).
  4. Klicka på Ladda uppackad och välj mappen echoshorts-extension.
  5. Tilläggsikonen visas i verktygsfältet med en bricka som visar antal upptäckta media.

Användning:

  1. Öppna en sida med videoinnehåll.
  2. Klicka på tilläggsikonen för att se upptäckta m3u8/MP4-strömmar.
  3. Klicka på Ladda ner för att spara som lokal MP4, eller Översätt för att starta undertextgenerering.
  4. Klicka på Spela in, spela upp videon i webbläsaren, klicka sedan på Stopp när uppspelningen är klar — tillägget sparar automatiskt videor du tittat på i den här fliken.
  5. Håll muspekaren över objekt för att markera motsvarande videoelement på sidan.

Är tillägget säkert?

  • Helt öppen källkod — du kan granska koden. Den kommunicerar bara med skrivbordsappen på din dator; vi får inte din webbhistorik.
  • Tillägget och EchoShortsPlayer samlar inte in personuppgifter och driver inte beteendespårning eller annonser.
  • Förutom licensaktivering är typisk nätverksaktivitet begränsad till att hämta de videoströmmar du väljer.
  • Du kan inspektera utgående begäranden för att bekräfta att det inte finns oväntade uppladdningar förutom aktivering och mediahämtning.

💻 Command-Line Interface Power Users

Automation, batch processing, and scripting

The CLI provides direct access to all download and translation features from the terminal. It's designed for power users who need to process multiple videos, automate workflows, or integrate with other tools.

Varför använda CLI?

  • Batchbearbetning: översätt hundratals videor med ett enda kommando
  • Skriptbar: integrera i shell-skript, cron-jobb eller CI/CD-pipelines
  • Full kontroll över modeller: välj Whisper-modellstorlek, översättningsmotor, brusreduceringsläge
  • Ingen GUI-overhead: idealisk för servrar, headless-maskiner eller fjärr-SSH-sessioner
  • Stöder både seriell (minneseffektiv) och parallell (snabb) bearbetningsläge

Available commands:

# Translate a local video file to Chinese subtitles
resources\backend\backend.exe --cli translate video.mp4 --target zh

# Batch translate an entire folder
resources\backend\backend.exe --cli translate C:\Videos\

# Full options: source language, whisper model, translation engine, denoising, processing mode
resources\backend\backend.exe --cli translate video.mp4 --source auto --target ja --whisper distil-large-v3 --translation qwen3-8b --denoise vocal --mode parallel

# Download a remote m3u8 or MP4
resources\backend\backend.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# Download and translate in one step
resources\backend\backend.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# Translate an existing SRT file
resources\backend\backend.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

Parameterreferens:

--source, -s      Source language or "auto" (default: auto)
--target, -t      Target language (default: zh)
--whisper, -w     tiny|base|small|medium|distil-large-v3|large-v3
--translation, -m opus-mt|nllb-distilled-600M|nllb-1.3B|nllb-3.3B|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal (default: off)
--mode            serial|parallel (default: serial)
--output, -o      Output file path
--url             Media URL (m3u8 / MP4)
--referer         Referer header

Se den fullständiga listan över språkkoder som stöds för --source och --target: Språkkodsreferens

#3 Integritetspolicy och ansvarsfriskrivning

Lokal databehandling

Alla kärnfunktioner i EchoShortsPlayer — inklusive taligenkänning, översättning och nedladdning av media — körs helt på din lokala enhet via en lokal backend-server (127.0.0.1:18632).

Vi samlar inte in, lagrar, överför eller analyserar någon användardata, inklusive men inte begränsat till: videoinnehåll du tittar på, igenkänd undertext, översättningsresultat, webbhistorik eller personuppgifter.

Ingen dataöverföring över nätverket

Applikationen skickar ingen användardata till externa servrar vid normal användning. All ljudbehandling och textöversättning slutförs lokalt. AI-modeller laddas ner från offentliga källor (HuggingFace) vid första användning och kan därefter köras helt offline.

Webbläsartillägget kommunicerar endast med den lokala backenden på localhost:18632. Ingen data överförs till fjärrservrar som drivs av utvecklarna.

Inga annonser, spårning eller rekommendationer

Denna applikation innehåller inga annonssystem, spårningskod för användarbeteende, analyser eller datarekommendationsmekanismer. Vi delar inte användardata med tredje part och skapar inte profiler eller skickar innehåll baserat på beteende.

Safe harbor och användaransvar

EchoShortsPlayer är ett allmänt tekniskt verktyg som endast är avsett att hjälpa till att förstå videoinnehåll. Enligt safe harbor-principen ansvarar utvecklare och utgivare inte juridiskt för upphovsrättsintrång eller annat avseende innehåll som användaren öppnar, översätter eller bearbetar.

Användaren måste säkerställa att användningen följer lokala lagar och plattformarnas användarvillkor. Allt juridiskt ansvar för åtkomst till upphovsrättsskyddat innehåll, brott mot plattformsregler eller olaglig verksamhet vilar enbart på användaren.

Applikationen bedömer eller garanterar inte lagligheten av innehåll som användaren öppnar och tar inte ansvar för direkta eller indirekta förluster från användningen.

Avsett användning

Applikationen är utformad som ett hjälpmedel för personlig lokal användning av personer med nedsatt hörsel, språkinlärare eller de som behöver förstå videor på främmande språk. All annan användning är användarens eget ansvar.

Tekniska begränsningar

Applikationen stöder analys av offentligt tillgängligt videoinnehåll som inte skyddas av DRM. På grund av skyddsprotokoll (t.ex. Widevine, PlayReady) kanske ljudströmmar från DRM-skyddat innehåll inte kan extraheras, vilket hindrar undertextgenerering.

För MP4-filer som inte är «fast-start»-kodade (moov-atom i slutet av filen) krävs full nedladdning innan översättning kan börja. Fast-start MP4 stöder strömmande översättning under nedladdning.

Ansvarsfriskrivning

Applikationen tillhandahålls «som den är» utan uttryckliga eller underförstådda garantier. Utvecklaren garanterar inte korrekt funktion i alla miljöer och tar inte ansvar för förluster, dataförlust eller enhetsproblem orsakade av användning. Användning innebär godkännande av alla ovanstående villkor.

Undertexter och översättningar genereras automatiskt av maskin och är endast för referens. Inga garantier för riktighet, fullständighet eller lämplighet för maskinöversatt innehåll och inget ansvar för följder av att förlita sig på sådana översättningar.

Policyuppdateringar

Denna integritetspolicy kan uppdateras i nya versioner. Viktiga ändringar meddelas via applikationens uppdateringslogg. Fortsatt användning innebär godkännande av den senaste versionen av integritetspolicyn.
