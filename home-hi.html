#2 कैसे उपयोग करें

📥 EchoShortsPlayer इंस्टॉल करें आवश्यक

डेस्कटॉप एप्लिकेशन — सभी सुविधाओं का मुख्य इंजन

EchoShortsPlayer वह डेस्कटॉप एप्लिकेशन है जो AI मॉडल को स्थानीय रूप से चलाता है। ब्राउज़र एक्सटेंशन और CLI इस पर निर्भर हैं। नीचे दी गई किसी भी विधि का उपयोग करने से पहले इसे पहले इंस्टॉल करें।

EchoShortsPlayer डाउनलोड करें

सिस्टम आवश्यकताएँ: Windows 10/11, 8 GB या अधिक VRAM वाला NVIDIA GPU, CUDA ड्राइवर इंस्टॉल।

इंस्टॉलेशन के बाद, एप्लिकेशन लॉन्च करें। यह localhost:18632 पर एक लोकल बैकएंड सर्वर शुरू करता है जिसके साथ एक्सटेंशन और CLI संवाद करते हैं।

🔌 Chrome एक्सटेंशन अनुशंसित

नेटवर्क-स्तरीय गहन मीडिया इंटरसेप्शन

Chrome एक्सटेंशन webRequest API का उपयोग करके ब्राउज़र स्तर पर सभी नेटवर्क अनुरोधों को इंटरसेप्ट करता है, m3u8/HLS स्ट्रीम, MP4 फ़ाइलें और अन्य मीडिया फ़ॉर्मेट का पता लगाता है। यह वीडियो एलिमेंट और डाउनलोड लिंक के लिए पेज DOM को भी स्कैन करता है।

एक्सटेंशन डाउनलोड करें (.zip)

इंस्टॉलेशन (डेवलपर मोड):

  1. ऊपर दी गई एक्सटेंशन zip डाउनलोड करें और एक फ़ोल्डर में एक्सट्रैक्ट करें।
  2. Chrome खोलें और chrome://extensions/ पर जाएँ।
  3. डेवलपर मोड सक्षम करें (ऊपर-दाएँ टॉगल)।
  4. Load unpacked पर क्लिक करें और m3u8-extension फ़ोल्डर चुनें।
  5. एक्सटेंशन आइकन टूलबार में पहचानी गई मीडिया की संख्या दिखाने वाले बैज के साथ दिखाई देता है।

उपयोग:

  1. वीडियो कंटेंट वाले किसी भी पेज पर जाएँ।
  2. पहचाने गए m3u8/MP4 स्ट्रीम देखने के लिए एक्सटेंशन आइकन पर क्लिक करें।
  3. लोकल MP4 में सेव करने के लिए डाउनलोड पर क्लिक करें, या सबटाइटल जनरेशन शुरू करने के लिए अनुवाद पर क्लिक करें।
  4. पेज पर संबंधित वीडियो एलिमेंट को हाइलाइट करने के लिए आइटम पर हॉवर करें।

एक्सटेंशन क्यों इस्तेमाल करें?

  • Intercepts network requests at the browser level — catches streams that DOM scanning misses
  • Automatic quality selection: groups variants by video ID and picks the best quality
  • Referer header injection for playing streams that require authentication
  • Badge counter shows detected media count per tab at a glance

💻 कमांड-लाइन इंटरफ़ेस पावर यूज़र्स

ऑटोमेशन, बैच प्रोसेसिंग और स्क्रिप्टिंग

CLI टर्मिनल से सभी डाउनलोड और अनुवाद सुविधाओं तक सीधी पहुँच प्रदान करता है। यह उन पावर यूज़र्स के लिए डिज़ाइन किया गया है जिन्हें कई वीडियो प्रोसेस करने, वर्कफ़्लो ऑटोमेट करने, या अन्य टूल्स के साथ इंटीग्रेट करने की ज़रूरत है।

CLI क्यों इस्तेमाल करें?

  • Batch processing: translate hundreds of videos with a single command
  • Scriptable: integrate into shell scripts, cron jobs, or CI/CD pipelines
  • Full control over models: choose Whisper model size, translation engine, denoising mode
  • No GUI overhead: ideal for servers, headless machines, or remote SSH sessions
  • Supports both serial (memory-efficient) and parallel (fast) processing modes

उपलब्ध कमांड:

# एक स्थानीय वीडियो फ़ाइल को चीनी उपशीर्षक में अनुवाद करें
resources\backend\backend.exe --cli translate video.mp4 --target zh

# पूरे फ़ोल्डर का बैच अनुवाद करें
resources\backend\backend.exe --cli translate C:\Videos\

# सभी विकल्प: स्रोत भाषा, Whisper मॉडल, अनुवाद इंजन, शोर हटाना, प्रोसेसिंग मोड
resources\backend\backend.exe --cli translate video.mp4 --source auto --target ja --whisper distil-large-v3 --translation qwen3-8b --denoise vocal --mode parallel

# एक रिमोट m3u8 या MP4 डाउनलोड करें
resources\backend\backend.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# एक ही चरण में डाउनलोड और अनुवाद करें
resources\backend\backend.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# एक मौजूदा SRT फ़ाइल का अनुवाद करें
resources\backend\backend.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

Parameter reference:

--source, -s      स्रोत भाषा या "auto" (डिफ़ॉल्ट: auto)
--target, -t      लक्ष्य भाषा (डिफ़ॉल्ट: zh)
--whisper, -w     tiny|base|small|medium|distil-large-v3|large-v3
--translation, -m opus-mt|nllb-distilled-600M|nllb-1.3B|nllb-3.3B|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal (डिफ़ॉल्ट: off)
--mode            serial|parallel (डिफ़ॉल्ट: serial)
--output, -o      आउटपुट फ़ाइल पथ
--url             मीडिया URL (m3u8 / MP4)
--referer         Referer हेडर
