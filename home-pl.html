#0Czym jest EchoShortsPlayer
  • ✦ Tlumaczenie w czasie rzeczywistym podczas ogladania wideo online oraz tlumaczenie wsadowe filmow offline.
  • ✦ Obsluguje ponad 10 000 witryn; pobieranie lub nagrywanie jednym kliknieciem przez rozszerzenie przegladarki.
  • ✦ Nie rejestruje ani nie zbiera danych uzytkownika, dbajac o prywatnosc.
  • ✦ Obsluguje ponad 99 jezykow i wiele duzych modeli.

#1 Features

🎤

Speech Recognition

Powered by OpenAI Whisper. Supports 99 languages with automatic language detection. Multiple model sizes from tiny (fast) to large-v3 (highest accuracy).

🌐

AI Translation

Multiple translation engines:

  • Opus-MT — fast, 9 languages
  • Qwen — best quality, CJK-optimized
📶

Media Detection

Supports 10,000+ websites and automatically detects m3u8/HLS streams and MP4 video links. Download or translate with one click via browser extension.

⚡

Real-time Subtitles

Stream translation mode: subtitles appear in real-time as you watch. No need to wait for the full video to download first. SRT subtitle files are saved locally for future use.

🔒

100% Offline & Private

All processing happens locally. No data is sent to external servers. No accounts, no tracking, no ads. Your content stays on your device.

💻

Hardware Requirements

NVIDIA GPU with 8 GB+ VRAM and CUDA drivers installed. Supports GPU-accelerated speech recognition and translation for optimal performance.

#2 How to Use

📥 Install EchoShortsPlayer Required

Desktop application — the core engine for all features

EchoShortsPlayer is the desktop application that runs the AI models locally. The browser extension and CLI depend on it. Install it first before using any of the methods below.

Pobierz z Windows Store

System requirements: Windows 10/11, NVIDIA GPU with 8 GB+ VRAM, CUDA drivers installed.

After installation, launch the application. It starts a local backend server at localhost:18632 that the extension and CLI communicate with.

🔌 Chrome Extension (Video Sniffing) Strongly recommended

Deep network-level media interception

The Chrome extension uses the webRequest API to intercept all network requests at the browser level, detecting m3u8/HLS streams, MP4 files, and other media formats. It also scans the page DOM for video elements and download links.

Download Extension (.zip)

Instalacja (tryb deweloperski):

  1. Pobierz plik zip rozszerzenia powyżej i rozpakuj go do folderu.
  2. Otwórz Chrome i przejdź do chrome://extensions/.
  3. Włącz Tryb deweloperski (przełącznik w prawym górnym rogu).
  4. Kliknij Wczytaj rozpakowane i wybierz folder echoshorts-extension.
  5. Ikona rozszerzenia pojawia się na pasku narzędzi z odznaką pokazującą liczbę wykrytych mediów.

Użycie:

  1. Otwórz dowolną stronę z treścią wideo.
  2. Kliknij ikonę rozszerzenia, aby zobaczyć wykryte strumienie m3u8/MP4.
  3. Kliknij Pobierz, aby zapisać lokalnie jako MP4, lub Tłumacz, aby rozpocząć generowanie napisów.
  4. Kliknij Nagraj, odtwórz wideo w przeglądarce, po zakończeniu kliknij Zatrzymaj — rozszerzenie automatycznie zapisuje obejrzane filmy na tej karcie.
  5. Najedź kursorem na pozycje, aby podświetlić odpowiedni element wideo na stronie.

Czy rozszerzenie jest bezpieczne?

  • W pełni open source — możesz przejrzeć kod. Komunikuje się tylko z aplikacją desktopową na Twoim komputerze; nie otrzymujemy historii przeglądania.
  • Rozszerzenie i EchoShortsPlayer nie zbierają danych osobowych ani nie prowadzą śledzenia zachowań ani reklam.
  • Poza aktywacją licencji typowa aktywność sieci ogranicza się do pobierania wybranych strumieni wideo.
  • Możesz samodzielnie sprawdzić żądania wychodzące, by upewnić się, że poza aktywacją i pobieraniem mediów nie ma nieoczekiwanych przesyłów.

💻 Command-Line Interface Power Users

Automation, batch processing, and scripting

The CLI provides direct access to all download and translation features from the terminal. It's designed for power users who need to process multiple videos, automate workflows, or integrate with other tools.

Po co używać CLI?

  • Przetwarzanie wsadowe: tłumacz setki filmów jednym poleceniem
  • Skryptowalne: integracja ze skryptami shell, zadaniami cron lub pipeline'ami CI/CD
  • Pełna kontrola nad modelami: wybierz rozmiar modelu Whisper, silnik tłumaczenia, tryb odszumiania
  • Brak narzutu GUI: idealne dla serwerów, maszyn bezgłowych lub zdalnych sesji SSH
  • Obsługuje zarówno tryb przetwarzania szeregowy (oszczędny pamięciowo), jak i równoległy (szybki)

Available commands:

# Translate a local video file to Chinese subtitles
resources\backend\backend.exe --cli translate video.mp4 --target zh

# Batch translate an entire folder
resources\backend\backend.exe --cli translate C:\Videos\

# Full options: source language, whisper model, translation engine, denoising, processing mode
resources\backend\backend.exe --cli translate video.mp4 --source auto --target ja --whisper distil-large-v3 --translation qwen3-8b --denoise vocal --mode parallel

# Download a remote m3u8 or MP4
resources\backend\backend.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# Download and translate in one step
resources\backend\backend.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# Translate an existing SRT file
resources\backend\backend.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

Odniesienie do parametrów:

--source, -s      Source language or "auto" (default: auto)
--target, -t      Target language (default: zh)
--whisper, -w     tiny|base|small|medium|distil-large-v3|large-v3
--translation, -m opus-mt|nllb-distilled-600M|nllb-1.3B|nllb-3.3B|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal (default: off)
--mode            serial|parallel (default: serial)
--output, -o      Output file path
--url             Media URL (m3u8 / MP4)
--referer         Referer header

Zobacz pełną listę obsługiwanych kodów języków dla --source i --target: Kody języków

W sprawie wsparcia technicznego napisz na supports@echoshorts.win.

#3 Polityka prywatności i zastrzeżenia

Lokalne przetwarzanie danych

Wszystkie kluczowe funkcje EchoShortsPlayer — w tym rozpoznawanie mowy, tłumaczenie i pobieranie mediów — działają w całości na Twoim urządzeniu lokalnym, zasilane przez lokalny serwer zaplecza (127.0.0.1:18632).

Nie zbieramy, nie przechowujemy, nie przesyłamy ani nie analizujemy żadnych danych użytkownika, w tym między innymi: oglądanych treści wideo, rozpoznanego tekstu napisów, wyników tłumaczenia, historii przeglądania ani żadnych informacji osobowych.

Brak transmisji danych w sieci

Aplikacja nie wysyła danych użytkownika na zewnętrzne serwery podczas normalnego użytkowania. Całe przetwarzanie audio i tłumaczenie tekstu odbywa się lokalnie. Modele AI są pobierane z publicznych źródeł (HuggingFace) przy pierwszym użyciu i mogą następnie działać w pełni offline.

Rozszerzenie przeglądarki komunikuje się wyłącznie z lokalnym zapleczem pod adresem localhost:18632. Żadne dane nie są przesyłane na zdalne serwery obsługiwane przez deweloperów.

Bez reklam, śledzenia i rekomendacji

Ta aplikacja nie zawiera systemów reklamowych, kodu śledzenia zachowań użytkownika, analityki ani mechanizmów rekomendacji danych. Nie udostępniamy danych użytkowników stronom trzecim ani nie tworzymy profili ani treści na podstawie zachowań.

Bezpieczna przystań i odpowiedzialność użytkownika

EchoShortsPlayer to ogólnego przeznaczenia narzędzie techniczne zaprojektowane wyłącznie w celu pomocy w zrozumieniu treści wideo. Zgodnie z doktryną bezpiecznej przystani deweloperzy i wydawcy nie ponoszą odpowiedzialności prawnej za naruszenie praw autorskich lub inne w związku z treściami, do których użytkownik uzyskuje dostęp, które tłumaczy lub przetwarza.

Użytkownik musi zapewnić zgodność użytkowania z lokalnymi przepisami i regulaminami platform. Cała odpowiedzialność prawna wynikająca z dostępu do treści chronionych prawem autorskim, naruszenia zasad platform lub działalności nielegalnej spoczywa wyłącznie na użytkowniku.

Aplikacja nie ocenia ani nie gwarantuje legalności treści, do których użytkownik uzyskuje dostęp, ani nie ponosi odpowiedzialności za bezpośrednie lub pośrednie straty wynikające z jej użytkowania.

Przewidywane użycie

Aplikacja została zaprojektowana jako narzędzie pomocnicze do osobistego lokalnego użytku przez osoby niesłyszące, uczących się języków lub potrzebujących rozumieć filmy w językach obcych. Inne zastosowania są wyłączną odpowiedzialnością użytkownika.

Ograniczenia techniczne

Aplikacja obsługuje analizę publicznie dostępnych treści wideo niechronionych przez DRM. Z powodu protokołów ochrony (np. Widevine, PlayReady) strumienie audio z treści DRM mogą być niemożliwe do wyodrębnienia, co uniemożliwia generowanie napisów.

Dla plików MP4 bez kodowania «fast-start» (atom moov na końcu pliku) wymagane jest pełne pobranie przed rozpoczęciem tłumaczenia. MP4 fast-start umożliwia tłumaczenie strumieniowe podczas pobierania.

Zastrzeżenie odpowiedzialności

Aplikacja jest dostarczana «tak jak jest» bez jakichkolwiek wyraźnych lub dorozumianych gwarancji. Deweloper nie gwarantuje poprawnego działania we wszystkich środowiskach ani nie ponosi odpowiedzialności za straty, utratę danych lub problemy z urządzeniem spowodowane użytkowaniem. Użytkowanie oznacza akceptację powyższych warunków.

Napisy i tłumaczenia są generowane automatycznie przez maszynę i służą wyłącznie jako informacja pomocnicza. Brak gwarancji co do dokładności, kompletności lub przydatności treści tłumaczonych maszynowo oraz brak odpowiedzialności za konsekwencje polegania na takich tłumaczeniach.

Aktualizacje polityki

Niniejsza polityka prywatności może być aktualizowana w nowych wersjach. Istotne zmiany będą komunikowane przez dziennik aktualizacji aplikacji. Kontynuacja użytkowania oznacza akceptację najnowszej wersji polityki prywatności.
