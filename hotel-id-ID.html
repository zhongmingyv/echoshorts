Sistem
Manajemen Hotel Lokal

Dirancang untuk cabang hotel, menyediakan solusi lokal terpadu untuk reservasi kamar, pendaftaran masuk, manajemen keuangan, dan kontrol izin.

Akun Standar & Izin

admin (123456)

Administrator super. Izin tertinggi (menu, departemen, izin).

boss (123456)

Pemilik hotel. Semua izin kecuali menambahkan menu sistem.

manager (123456)

Manajer hotel. Semua izin operasi. Hanya bisa menambah pengguna di departemennya.

receptionist (123456)

Resepsionis. Hanya izin masuk kamar dan pemesanan.

⚠️ Catatan Penting Saat Login Pertama

Setelah login admin pertama, segera ubah sandi untuk semua akun standar dan ingat sandi admin dengan aman!

Kebijakan Privasi & Penolakan

Eksekusi Lokal, Tanpa Internet

Perangkat lunak ini berjalan sepenuhnya lokal. Ia tidak pernah mengumpulkan, atau membagikan data bisnis Anda.

Keamanan Data dan Tanggung Jawab Pengguna

Tidak ada sinkronisasi cloud yang diberikan. Anda sepenuhnya bertanggung jawab atas keamanan data.

Cadangan Data (Penting)

  • Cadangan Rutin: Sering pergi ke halaman "Cadangkan dan Impor" untuk mencadangkan data.
  • Multi-cadangan: Rekomendasi untuk menyimpan cadangan ke drive USB eksternal atau cloud.
  • Sebelum Perubahan Sistem: SEBELUM menginstal ulang OS atau mencadangkan, Anda HARUS mencadangkan dan mengekspor data.
  • Kegagalan mencadangkan mengakibatkan kehilangan informasi pelanggan dan log keuangan secara permanen.

Penafian

Pengembang tidak menanggung tanggung jawab hukum maupun keuangan untuk kerusakan perangkat keras, virus, ransomware, atau kegagalan untuk melakukan cadangan rutin.
