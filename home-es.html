EchoShortsPlayer

Traducción de Video & Subtítulos con IA
Transmite, Traduce, Descarga — Todo Sin Conexión

EchoShortsPlayer traduce videos en línea en tiempo real mientras los miras: los subtítulos aparecen mientras se reproduce el video, sin esperas. Descarga videos de acceso público para verlos sin conexión. Todo el reconocimiento de voz y la traducción se ejecutan 100% localmente en tu dispositivo: sin internet, sin cuentas, ningún dato sale de tu computadora. Compatible con más de 99 idiomas, transmisiones m3u8 y archivos MP4.

#1 Características

🎤

Reconocimiento de Voz

Impulsado por OpenAI Whisper. Compatible con 99 idiomas con detección automática de idioma. Múltiples tamaños de modelo desde tiny (rápido) hasta large-v3 (máxima precisión).

🌐

Traducción con IA

Múltiples motores de traducción:

  • Opus-MT — rápido, 9 idiomas
  • NLLB — más de 32 idiomas, cualquier combinación
  • Qwen — mejor calidad, optimizado para CJK
📶

Detección de Medios

Detecta automáticamente transmisiones m3u8/HLS y enlaces de video MP4 en cualquier página web. Descarga o traduce con un solo clic mediante la extensión del navegador.

⚡

Subtítulos en Tiempo Real

Modo de traducción en streaming: los subtítulos aparecen en tiempo real mientras miras. No necesitas esperar a que se descargue el video completo. Los archivos de subtítulos SRT se guardan localmente para uso futuro.

🔒

100% Sin Conexión & Privado

Todo el procesamiento ocurre localmente. No se envían datos a servidores externos. Sin cuentas, sin rastreo, sin anuncios. Tu contenido permanece en tu dispositivo.

💻

Requisitos de Hardware

GPU NVIDIA con 8 GB o más de VRAM y controladores CUDA instalados. Compatible con reconocimiento de voz y traducción acelerados por GPU para un rendimiento óptimo.

#2 Cómo Usar

📥 Install EchoShortsPlayer Required

Desktop application — the core engine for all features

EchoShortsPlayer is the desktop application that runs the AI models locally. The browser extension and CLI depend on it. Install it first before using any of the methods below.

Download EchoShortsPlayer

System requirements: Windows 10/11, NVIDIA GPU with 8 GB+ VRAM, CUDA drivers installed.

After installation, launch the application. It starts a local backend server at localhost:18632 that the extension and CLI communicate with.

🔌 Extensión de Chrome Recomendado

Intercepción profunda de medios a nivel de red

La extensión de Chrome usa la API webRequest para interceptar todas las solicitudes de red a nivel del navegador, detectando transmisiones m3u8/HLS, archivos MP4 y otros formatos multimedia. También escanea el DOM de la página en busca de elementos de video y enlaces de descarga.

Descargar Extensión (.zip)

Instalación (modo desarrollador):

  1. Descarga el zip de la extensión de arriba y extráelo en una carpeta.
  2. Abre Chrome y navega a chrome://extensions/.
  3. Activa el Modo desarrollador (interruptor en la esquina superior derecha).
  4. Haz clic en Cargar descomprimida y selecciona la carpeta m3u8-extension.
  5. El icono de la extensión aparece en la barra de herramientas con una insignia que muestra el número de medios detectados.

Uso:

  1. Navega a cualquier página con contenido de video.
  2. Haz clic en el icono de la extensión para ver las transmisiones m3u8/MP4 detectadas.
  3. Haz clic en Descargar para guardar como MP4 local, o Traducir para iniciar la generación de subtítulos.
  4. Pasa el cursor sobre los elementos para resaltar el elemento de video correspondiente en la página.

¿Por qué usar la extensión?

  • Intercepta solicitudes de red a nivel del navegador — captura transmisiones que el escaneo DOM no detecta
  • Selección automática de calidad: agrupa variantes por ID de video y elige la mejor calidad
  • Inyección de encabezado Referer para reproducir transmisiones que requieren autenticación
  • El contador de insignia muestra el número de medios detectados por pestaña de un vistazo

💻 Interfaz de Línea de Comandos Usuarios Avanzados

Automatización, procesamiento por lotes y scripting

La CLI proporciona acceso directo a todas las funciones de descarga y traducción desde la terminal. Está diseñada para usuarios avanzados que necesitan procesar múltiples videos, automatizar flujos de trabajo o integrarse con otras herramientas.

¿Por qué usar la CLI?

  • Procesamiento por lotes: traduce cientos de videos con un solo comando
  • Scriptable: integra en scripts de shell, trabajos cron o pipelines CI/CD
  • Control total sobre los modelos: elige el tamaño del modelo Whisper, motor de traducción, modo de eliminación de ruido
  • Sin sobrecarga de GUI: ideal para servidores, máquinas sin pantalla o sesiones SSH remotas
  • Compatible con modos de procesamiento en serie (eficiente en memoria) y paralelo (rápido)

Comandos disponibles:

# Traducir un archivo de video local a subtítulos en chino
EchoShortsPlayer.exe --cli translate video.mp4 --target zh

# Traducir una carpeta completa por lotes
EchoShortsPlayer.exe --cli translate C:\Videos\

# Todas las opciones: idioma de origen, modelo Whisper, motor de traducción, reducción de ruido, modo de procesamiento
EchoShortsPlayer.exe --cli translate video.mp4 --source auto --target ja --whisper large-v3-turbo --translation qwen3-8b --denoise vocal --mode parallel

# Descargar un m3u8 o MP4 remoto
EchoShortsPlayer.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# Descargar y traducir en un solo paso
EchoShortsPlayer.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# Traducir un archivo SRT existente
EchoShortsPlayer.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

Referencia de parámetros:

--source, -s      Idioma de origen o "auto" (predeterminado: auto)
--target, -t      Idioma de destino (predeterminado: zh)
--whisper, -w     tiny|base|small|medium|large-v3-turbo|large-v3
--translation, -m opus-mt|nllb-*|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal (predeterminado: off)
--mode            serial|parallel (predeterminado: serial)
--output, -o      Ruta de archivo de salida
--url             URL de medios (m3u8 / MP4)
--referer         Encabezado Referer

      
Ver la lista completa de códigos de idioma compatibles con --source y --target: Referencia de códigos de idioma

#3 Política de Privacidad y Descargo de Responsabilidad

Procesamiento Local de Datos

Todas las funciones principales de EchoShortsPlayer — incluyendo reconocimiento de voz, traducción y descarga de medios — se ejecutan completamente en su dispositivo local, mediante un servidor backend local (127.0.0.1:18632).

No recopilamos, almacenamos, transmitimos ni analizamos ningún dato de usuario, incluyendo pero no limitado a: contenido de video que visualiza, texto de subtítulos reconocido, resultados de traducción, historial de navegación o cualquier información personal.

Sin Transmisión de Datos por Red

Esta aplicación no envía datos de usuario a servidores externos durante el uso normal. Todo el procesamiento de audio y la traducción de texto se completan localmente. Los modelos de IA se descargan de fuentes públicas (HuggingFace) en el primer uso y pueden funcionar completamente sin conexión a partir de entonces.

La extensión del navegador se comunica únicamente con el backend local en localhost:18632. No se transmiten datos a ningún servidor remoto operado por los desarrolladores.

Para archivos MP4 que no están codificados con "fast-start" (átomo moov al final del archivo), la aplicación requiere una descarga completa antes de que pueda comenzar la traducción. Los archivos MP4 fast-start admiten traducción en streaming mientras se descargan.
