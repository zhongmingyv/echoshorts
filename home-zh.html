EchoShortsPlayer

AI 视频翻译与字幕
边播边译、下载、全程离线

EchoShortsPlayer 支持在线视频边播放边实时翻译——字幕随视频同步显示，无需等待。可下载公开可访问的视频供离线观看。所有语音识别和翻译 100% 在本地设备运行：无需网络、无需账号、数据绝不离开您的电脑。支持 99+ 种语言、m3u8 流和 MP4 文件。

#1 功能特性

🎤

语音识别

基于 OpenAI Whisper。支持 99 种语言，自动语言检测。多种模型大小可选，从 tiny（快速）到 large-v3（最高精度）。

🌐

AI 翻译

多种翻译引擎：

  • Opus-MT — 快速，9 种语言
  • NLLB — 32+ 种语言，任意互译
  • Qwen — 最高质量，CJK 优化
📶

媒体检测

自动检测网页上的 m3u8/HLS 流和 MP4 视频链接。通过浏览器扩展或油猴脚本一键下载或翻译。

⚡

实时字幕

流式翻译模式：字幕在观看时实时显示。无需等待整个视频下载完成。SRT 字幕文件保存在本地供后续使用。

🔒

100% 离线 & 隐私

所有处理都在本地完成。不向外部服务器发送任何数据。无需账号、无跟踪、无广告。您的内容留在您的设备上。

💻

硬件要求

NVIDIA 显卡，8 GB+ 显存，并安装 CUDA 驱动。支持 GPU 加速的语音识别和翻译，获得最佳性能。

#2 使用方式

📥 安装 EchoShortsPlayer 必需

桌面应用——所有功能的核心引擎

EchoShortsPlayer 是在本地运行 AI 模型的桌面应用。浏览器扩展、油猴脚本和 CLI 都依赖它。请先安装后再使用下列任何方式。

下载 EchoShortsPlayer

系统要求：Windows 10/11，NVIDIA 显卡 8 GB+ 显存，已安装 CUDA 驱动。

安装后启动应用。它会在 localhost:18632 启动本地后端服务器，扩展、油猴脚本和 CLI 都通过它通信。

步骤 4：访问任何视频页面。浮动面板（右下角）会自动检测媒体。点击 下载 或 翻译。

为什么使用油猴脚本？

  • 适用于所有支持 Tampermonkey 的浏览器（Chrome、Firefox、Edge、Safari、Opera）
  • 无需安装 Chrome 扩展——适合扩展受限的环境
  • 轻量：单个文件，易于检查和修改
  • 通过 Tampermonkey 内置机制自动更新
  • 同时检测 m3u8/HLS 流和 MP4 直链

🔌 Chrome 扩展 推荐

深度网络级媒体拦截

Chrome 扩展使用 webRequest API 在浏览器层面拦截所有网络请求，检测 m3u8/HLS 流、MP4 文件和其他媒体格式。还会扫描页面 DOM 中的视频元素和下载链接。

下载扩展 (.zip)

安装（开发者模式）：

  1. 下载上方的扩展 zip 文件并解压到一个文件夹中。
  2. 打开 Chrome，导航到 chrome://extensions/。
  3. 启用 开发者模式（右上角开关）。
  4. 点击 加载已解压的扩展程序，选择 m3u8-extension 文件夹。
  5. 扩展图标出现在工具栏中，徽章显示检测到的媒体数量。

使用方法：

  1. 浏览包含视频内容的页面。
  2. 点击扩展图标查看检测到的 m3u8/MP4 流。
  3. 点击 下载 保存为本地 MP4，或点击 翻译 开始生成字幕。
  4. 悬停在项目上可高亮页面中对应的视频元素。

为什么使用扩展？

  • 在浏览器层面拦截网络请求——捕获 DOM 扫描遗漏的流
  • 自动质量选择：按视频 ID 分组并选择最佳质量
  • Referer 头注入，播放需要认证的流
  • 徽章计数器一目了然显示每个标签页检测到的媒体数量
  • 比油猴脚本更深度的检测：hook fetch、XHR、MediaSource 和响应体扫描

💻 命令行工具 高级用户

自动化、批处理和脚本集成

CLI 提供从终端直接访问所有下载和翻译功能。专为需要批量处理视频、自动化工作流或与其他工具集成的高级用户设计。

为什么使用 CLI？

  • 批量处理：一条命令翻译数百个视频
  • 可脚本化：集成到 shell 脚本、定时任务或 CI/CD 管道
  • 完全控制模型：选择 Whisper 模型大小、翻译引擎、降噪模式
  • 无 GUI 开销：适合服务器、无头设备或远程 SSH 会话
  • 支持串行（省内存）和并行（快速）处理模式

可用命令：

# 将本地视频翻译为中文字幕
EchoShortsPlayer.exe --cli translate video.mp4 --target zh

# 批量翻译整个文件夹
EchoShortsPlayer.exe --cli translate C:\Videos\

# 全部参数：源语言、Whisper 模型、翻译引擎、降噪、处理模式
EchoShortsPlayer.exe --cli translate video.mp4 --source auto --target ja --whisper large-v3-turbo --translation qwen3-8b --denoise vocal --mode parallel

# 下载远程 m3u8 或 MP4
EchoShortsPlayer.exe --cli download --url "https://example.com/video.m3u8" --referer "https://example.com/"

# 一步完成下载和翻译
EchoShortsPlayer.exe --cli download-and-translate --url "https://example.com/video.mp4" --referer "https://example.com/" --target zh --whisper base --translation opus-mt

# 翻译已有的 SRT 文件
EchoShortsPlayer.exe --cli translate-srt video.en.srt --target ja --translation qwen3-8b

参数参考：

--source, -s      源语言或 "auto"（默认：auto）
--target, -t      目标语言（默认：zh）
--whisper, -w     tiny|base|small|medium|large-v3-turbo|large-v3
--translation, -m opus-mt|nllb-*|qwen2.5-3b|qwen3-8b
--denoise, -d     off|light|vocal（默认：off）
--mode            serial|parallel（默认：serial）
--output, -o      输出文件路径
--url             媒体 URL（m3u8 / MP4）
--referer         Referer 请求头
